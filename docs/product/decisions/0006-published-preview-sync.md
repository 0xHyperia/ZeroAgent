# ADR 0006：显式同步已发布的预发布版本

- 状态：已采纳，用于用户指定的 v2.0.0-beta.20 本地集成
- 范围：同步治理、来源校验、更新通道

## 决策

用户明确要求同步的预发布版本可以进入隔离集成分支。目标必须是 GitHub 已发布且非 draft
的精确 Release，并校验 peeled commit 与本地独立 ref。不得用 main、未发布 tag 或更高版本
替代。元数据同时记录 `channel: preview`、`prerelease: true`、Release URL 与发布时间。

扩展校验以接受合法 SemVer 预发布标签，同时继续验证来源、提交、祖先和产品契约。此决策
不改变生产更新通道，也不授权推送、远程合并、打标签、发布或部署。

## 迁移与回滚

既有 v1.2.6 稳定版同步记录保持有效；真实集成完成后才能推进同步基线。回滚保留旧基线和
精确目标的记录，不将 preview 重标为 stable。校验测试覆盖来源不符、浮动 ref、缺少发布
证据及 preview 伪装为 stable 的拒绝。
