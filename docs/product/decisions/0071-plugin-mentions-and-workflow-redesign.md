# ADR 0071：按插件提及、行内引用和中文工作流重设计

- 日期：2026-11-05。
- 状态：用户通过三张参考图及三项要求授权本地实施，不提交或发布。
- 范围：CloudChat 的 @、共享引用展示、四个内置能力及其指令。

@按用户要使用的插件/独立技能列一个主入口，不展开包内全部技能；/仍可显式选择具体技能。
CloudChat向共享MentionComposer显式提供候选与资料动作，设备原有应用/文件/会话模式保持。
候选仅来自当前账户实际安装且主技能启用的目录。查看目录和加入引用不授予工具权限。
资料动作只移除本次查询，再交给原控制器；忙碌时不可用的项目动作不进入候选，不隐式发送。

引用采用普通行内文字、16px图标及3px图文间隔。正文默认16px/26px、400字重，引用标签500字重，
共享字体及用户偏好保持。图标独立居中，不能将图像和文字放在同一个baseline flex布局中。
新@选择在没有后续空白时加一个可编辑的词间空格，原有草稿重建不插入新字符。
普通CloudChat粘贴与文本恢复不猜测@文件身份；结构化剪贴板仍能恢复合法引用。
插件选择、结构化粘贴及原子删除绕过浏览器编辑管线时，显式发出冒泡input事件，复用宿主草稿保存。
setDraft/setText加载和临时语音更新不发出该通知；选择或粘贴后不继续输入也必须能刷新恢复。

四个内置能力改为小尺寸清楚的原创平面标识；详情使用统一容器与真实图片背景。
中文用途、起步提示和指令按四类任务重新组织，产品设计的具体工作流也中文化。
指令仍只使用已公告工具，不声明可自动安装、创建外部连接、公开发布或执行Gateway主机脚本。

指令内容变化使用新的内部发布定义。原始发布的全部文件单独嵌入保留，既有固定引用仍得到原始内容；
这不是旧应用回退或数据迁移，界面不增加版本管理。插件主入口的固定发布同时约束包内辅助技能，
同一包不同技能的冲突发布引用拒绝混用。现有数据库、安装选择、草稿和运行快照保持。
嵌入指令在Git中禁用换行转换，归档发布用固定SHA-256检查，防止不同平台检出改变旧引用的指令字节。

剪贴板可接受当前仍启用的同包同名技能的旧固定引用，保留原skillFile；拒绝未来发布、其他包、
未安装或已停用候选。服务端继续校验发布是否存在，不把旧引用自动改成当前发布。

验证包括@一包一项及别名、资料动作和文字保留、键盘/粘贴/删除、旧引用与整个包的一致读取，
完整Go回归、真实PostgreSQL CAS、桌面/手机/浅深截图及源码构建。未调用真实收费模型或外部应用授权。
设计和验收详见 `docs/design/cloudchat-extensions-ux.md`、根目录 `design-qa.md`。
