# ADR 0067：CloudChat 的 Product Design 与 ImageGen

- 日期：2026-11-04
- 状态：接受
- 范围：账户 CloudChat、响应式 Web 与嵌入移动端；设备 Agent 的图像工作台保持原执行边界。

用户要求在会话中完成设计探索、生图和参考图修改。采用 ZeroAgent 自己的内置工作流与工具，
不连接或宣称复刻 ChatGPT 的私有插件服务。完整流程及布局见
`docs/design/cloudchat-visual-creation.md`。复用当前 Run、工具日志、资料空间、预览器及共享 UI，
不增加独立对话循环。Product Design 指导任务分析、视觉方案、组件实现与核验；ImageGen 调用
真实图像接口，不能用工程演示或虚构图片代替结果。

默认生图模型独立保存于账户 PostgreSQL 偏好表，包含托管分组密钥 ID、模型 ID、版本与时间，
不保存真实密钥、第三方服务地址，也不改变当前聊天模型。保存采用比较版本更新；运行时重新
校验平台目录与密钥归属。无默认模型时返回可展示的配置需求，由会话直达设置，保留草稿。
当前接入固定 USA-Zero 的 OpenAI Images 兼容生成/编辑接口；选择的分组必须实际支持该接口。

一次工具调用只生成一张图。供应商请求使用持久化操作 ID，未知结果不自动重试。返回内容仅接受
有界、可解码的 PNG/JPEG bytes，不抓取供应商返回 URL；JPEG 规范化为 PNG。成果按账户配额、
命名空间及摘要写入现有对象存储，只有 ready 结果才展示为已保存。编辑引用已授权原件或成果，
创建不可变新版本，禁止覆盖原件或隐式分享。存储在真实请求前预检，最终原子预留仍为准；
生成成功但保存未确认必须如实标记未知，不能再次自动收费。

共享图像画廊不持有账户凭据；宿主提供授权读取、编辑回调和任务状态。切号/切会话终止读取并
释放 Blob URL。单图、主图/缩略图、触屏操作、减少动态与失败反馈使用同一组件。取消仍沿用
Run 取消，离开页面不等于取消服务端任务。

这是新增表与工具，不迁移或清除已有数据。正常备份按现有 schema 全表快照包含新偏好；回退代码
可忽略该表及新资源投影，已生成图片仍保留于成果库。部署需同步更新 Gateway 与 Web 包。

验证覆盖 PostgreSQL 并发偏好、HTTP 权限与跨站写入、真实字节验证、生成与参考编辑、不可变
版本、账户隔离、未知不重发，以及共享画廊/配置引导/读取生命周期。受控供应商测试和真实外部
模型验收分别记录；本地测试不推定外部平台支持所有模型。
