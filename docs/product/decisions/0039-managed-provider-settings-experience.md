# ADR 0039：按分组管理托管模型与高级设置

- 日期：2026-10-26（Asia/Hong_Kong）
- 状态：按用户五项截图反馈调整 Desktop 与 WebUI

托管供应商页共用 `ManagedProvidersView`，按分组展示现有密钥和每份密钥的模型配置。
已有可用密钥的分组不再出现在可连接列表；失效密钥保留，所属分组可以重新连接。
一次连接一个明确的分组，确认名称后创建专用密钥，保留原有多份密钥及其模型偏好。
连续提交在首个请求结束前被拒绝；创建成功而后续模型同步失败时保留已创建密钥，
提示刷新，不再次创建。分组名称、协议、倍率及服务端说明在确认前可见。

分组列表与逐项连接分别参考 [Rows](https://mobbin.com/screens/a84dd376-0f86-4b5a-9cc5-9f249b8b01a9)
和 [Vercel](https://mobbin.com/screens/6cf10946-059f-4b49-b0b6-392d4b8e9863) 的结构，
使用项目现有按钮、对话框和主题，不引入设计依赖。

全局高级设置直接复用上游 `ProviderSettingsDialog`，包含生成模型、澄清提示词、上下文展示、
重试错误和同协议故障转移。供应商高级设置开放已有缓存及流式重试，并将重试策略纳入
托管模型保存投影；平台 URL、发现地址、凭据、自定义请求头、代理及独立计费接口仍不可编辑。
模型列表、缓存区和参数区使用明确间距及独立边界，保持现有模型参数和保存流程。
桌面设备菜单收窄并与触发器左侧对齐，不改变设备授权或切换确认。

不迁移、覆盖或删除既有密钥及账号数据。撤销只恢复先前界面和高级设置入口，新增的
重试策略仍属于上游已有配置格式。验证包括三端类型检查、相关回归、创建去重测试，
以及独立真实 K-brain 中重试策略写入和停启回读。真人视觉、新建密钥与设置交互由用户验收。
