# ADR 0065：阅读导航、批注请求和真实版本恢复

- 日期：2026-11-01。
- 状态：已实施并完成本轮验收；不提交、不推送。
- 依据：用户的 13 项阅读器反馈、当前 ChatGPT PC 与手机标签页，以及体验规范第 18 节。

## 阅读与交互

阅读及聊天工具悬浮于各自画布，取消固定色块页头。标题 hover 限于真实胶囊；缩放使用
共享菜单。详情、历史、目录使用内缩圆角卡片。页码浮于画布底部，批注出现时向上避让。
PPT 单页、网格、演示共享同一原件与页码，演示由共享 Dialog 承载，不重新请求原件。

Word 的语义目录、页缩略图在纸张之外渲染，不随缩放缩小。桌面有真实目录时默认展开；
手机默认收起。缩略图来自浏览器实际排版 section，最多 80 项、总计 6000 复制节点，
不声称等同于 Office 原生分页。PDF 页面按可见范围解码，使用 PDF.js 自带 TextLayer
提供真实文本选区，保留原件校验、像素预算和释放机制。

## 最小文档交互桥

此决定取代 ADR 0064 中 Word 永远 scriptless 的限制。只有 Word 主阅读 iframe 使用
`sandbox="allow-scripts"`，不授予同源、表单、弹窗、下载或顶层导航。HTML、SVG、封面
和缩略图仍是无任何权限的 scriptless iframe。文档脚本/事件/外链/表单/嵌入对象先移除，
只允许一个由应用源码生成的随机 nonce 脚本；CSP 继续禁止网络、外部子资源和 base。

父页面验证 iframe 窗口、opaque origin、随机通道及消息字段；选区必须命中父页面已知的
原文块及字符范围，坐标与文本有界。桥只允许本文件内定位、显示批注标记和报告选区，
没有账户、请求客户端、执行工具或发布能力。重开或退休后旧窗口/通道立即失效。

批注绑定账户阅读寿命及不可变文件描述：页码、块、字符范围、原文与用户修改要求。
队列最多 20 项、单项原文及要求各 2000 字符，支持定位、编辑、移除和取消。只有用户
点击发送才交给宿主；CloudChat 重新校验引用并复用当前模型、项目、草稿、待发送队列
和未知提交保护。原草稿附加批注，不覆盖；发送失败保留草稿和批注。阅读桥不能发送。

## 用户版本恢复

恢复使用独立的用户写入路径，不能获得或伪造运行租约，也不放宽原模型产物发布规则。
请求含确切源版本、用户看到的家族头版本及幂等 ID。在账户/家族事务锁内检查所有权、
源版本 ready、头版本 CAS、删除标记、总空间和版本数量；按现有配额预留一个新版本。

旧对象经元数据、长度及 SHA-256 校验后复制至新版本自己的规范对象键，并写入新版本
绑定的对象元数据。持久化 PUT 开始日志后才写对象，回读校验后才 ready。旧对象不覆盖，
每个版本正常计费。原件复制中删除家族，晚到的已确认对象清理，未知写入继续保留回执
及清理保护；不得重新暴露已删除的文件。

网络丢失后使用原请求 ID 只读核对；按钮内显示忙状态，不自动换 ID 重发。当前版本禁止
重复恢复。普通上传没有虚构历史。站点 ZIP 需要额外站点清单/发布事务，本次不把单纯
复制 ZIP 伪装为站点恢复，暂不开放其恢复按钮。

继续沿用原数据库表及私有 journal，新增 restore 意图，不修改已有版本、旧对象键或
账户数据。列表与公开响应不暴露 journal、对象键或工具操作身份。

## 验证边界

验证包含内存和独立 PostgreSQL schema 的事务合同、真实对象 HTTP 复制、幂等、账户
隔离、过时头版本、未验证对象禁止 ready、复制中删除，以及按钮忙态/未知结果只读查询。
浏览器使用本地合成文档；440px 独立宿主页中的真实应用 iframe 用于响应式检查，不改动
用户 ChatGPT 两个标签页的 PC/手机视口。该检查不等同于 Android 原生或触屏设备验收。

原生 Windows 截图工具在本轮返回黑屏/捕获超时，因此操作系统文件拖入仍需实际复验。
不得把合成 DOM 拖拽事件回归或组件构建成功写成真实 OS 拖入验收完成。

本地真实 UI 恢复合成 Word 的 v1 成功生成 v3，旧版本不覆盖；实际 PDF/Word 选区、
PPT 网格和演示、手机批注菜单与取消已验证。后续真实模型/E2B 改稿沿用合成文档家族，
成功保存 v4；下载后对比 ZIP 部件，仅 document.xml 的指定标题变化，其余内容及部件
不变。正常发送入口的草稿/模型/项目和切换边界另有宿主回归保护。实际浏览器批注列表、
编辑/取消及 PDF 文字标记随缩放已核对；操作系统拖拽仍保留手工复验项。
源实现与构建验收记录见体验规范第 18 节。

2026-11-01 用户完成真实资源管理器到本地 ZeroAgent 页面的拖入，并确认“提示持续，
松开后已添加”，补齐上述 OS 拖拽复验项。此项证据来自用户手工操作；跨 Portal/iframe、
单次接收、取消和草稿保护仍沿用事件及宿主回归，不宣称用户逐一手测这些边界。
