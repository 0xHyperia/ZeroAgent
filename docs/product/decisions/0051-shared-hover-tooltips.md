# ADR 0051：共享悬停提示组件

- 日期：2026-10-29。
- 状态：用户要求设计并封装统一的悬停组件；本地实现，不推送。
- 范围：共享 UI、CloudChat Web 与嵌入 Web 的 Android；Desktop 共享控件随同复用。

扩展现有 Base UI Tooltip，不维护第二个浮层定位或鼠标事件引擎。共享 TooltipContent 使用深色中性
语义表面、统一字体/间距/阴影、视口避让及降低动态效果支持；`LabelTooltip` 保留受控和触屏契约。
用 `TooltipButton` 显式接入常用导航和操作，移除这些控件的原生 DOM title，避免两套气泡重叠。
普通 Button 不自动更改行为。菜单打开时提示让位；真实按钮、事件与 ref 不被多余 DOM 包裹改变。

当前固定 Base UI 的原语没有自动提供完整描述关联，因此组合层补齐 role、稳定内容 ID、当前触发器
描述和受控单触发器 ID。既有描述 ID、复制反馈与上下文用量环的点击所有权保留。
提示内容只展示用户可见文案，不承接表单、授权或执行逻辑，不将秘密作为提示内容。

不修改账户、模型连接、Go 执行、数据格式或持久化，不迁移或清理用户数据。撤销只恢复提示展示。
验证覆盖鼠标延迟/离开、键盘/Escape、菜单复合、ref/点击、首次复制反馈、受控触屏，以及共享/两宿主
类型检查、Web/GUI 回归和实际浏览器的浅深主题与边缘定位。
