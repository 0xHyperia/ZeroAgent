# ADR 0050：CloudChat 双层导航与统一输入体验

- 日期：2026-10-29。
- 状态：用户选择设计方向 2，并要求接近 ChatGPT 的质感；本地实施，不推送。
- 范围：CloudChat Web 与嵌入该界面的 Android；共享组件提供可选扩展，既有 Desktop/设备工作台保持。

采用窄应用导航轨、上下文会话侧栏和主画布。新对话将问候、同一输入框及两个轻量建议组合，
已有消息时输入回到底部。`ChatComposerBar` 保持单一实例、草稿及附件所有者；“对话/工作”只改变
提示和上下文工具栏，不更换模型、会话、Run、账户或设备权限，不自动启用联网。

资料库与项目具有固定入口。文件、成果、来源和项目继续复用既有控制器、账户守卫及资源组件，
通过共享展示上下文切换完整页面/侧面板；不为页面再造数据权威。文件名称筛选明确限定已加载页，
不冒充全库搜索。宽屏资源面板保持非模态，窄屏保留共享 Sheet、遮罩、焦点和关闭行为。

项目导航仅显示当前账户的真实项目；旧账户迟到结果不得进入新导航。项目表单未保存时，离开、
切换项目和页面刷新受到草稿保护；待确认导航绑定原账户，切换账户后不再执行。资源入口统一互斥，
不叠开多个上下文面板。新对话继续是操作，不恢复持续选中态。

复用 ZeroAgent 图标资源、共享图标集、按钮、输入、菜单、模型选择器和语义主题，未复制 ChatGPT
的品牌资产，也不引入 LibreChat 样式或状态框架。公共基础能力仍按 ADR0034、0049 维护。

2026-10-29 细化应用导航四态：未选中为灰色描边、透明底；鼠标悬停为深色描边、浅灰圆角底；
选中为实心图标、同一浅灰底，选中悬停保持此状态并显示共享提示。深色主题使用对应中性色。
共享导航接收可选 activeIcon；对话和资料库采用 Heroicons 成对的描边/实心资源，保留同一轮廓，
不对描边路径强行填色。悬停/聚焦不改变当前页面，只有点击或键盘激活才执行原导航动作。

2026-10-29 用户按截图进一步指定：桌面导航轨底部使用账户头像，设置移入头像菜单，
不保留独立齿轮，也不在会话侧栏重复显示账户条。账户菜单采用右侧展开/底部对齐的可选 rail
变体，保留真实账号、设置、退出与原刷新逻辑；不新增截图中尚未接入的产品动作或订阅声明。
手机没有导航轨，单一受控实例在抽屉底部使用原 sidebar 变体；禁止两个实例同时响应 open。
布局/账号变化关闭旧菜单；设置入口继续是现有页面，桌面不因点击设置收起会话侧栏。
该调整没有账号/权限/存储迁移；默认设备工作台的原账户菜单行为保持。

不改变 USA OAuth、托管模型连接、Go 编排、公开研究主题确认、文件/成果持久化或设备租约。
不迁移、清理、重写或导出用户数据。撤销本轮展示扩展可恢复旧布局，不涉及数据回滚。

验证包括 Web 完整回归、共享与 Desktop 类型检查、侧栏/输入专项、边界与产品契约、生产构建、
实际浏览器的模式/资料返回草稿、菜单、项目未保存保护、已有消息、深色及窄屏。
外部模型、E2B、真实附件端到端及 Android 真机不以本轮视觉验收替代；证据见根目录 `design-qa.md`。
