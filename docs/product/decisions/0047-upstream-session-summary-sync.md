# ADR 0047：采用上游会话摘要同步，保留账号选择边界

日期：2026-10-29。状态：accepted。

采用 LiveAgent beta.24 的共享侧栏、不可变快照、十进制字符串水位、增量变更、
主窗口发布入口、分页恢复、丢帧重同步和资源拥有期。不维护第二套摘要同步器。
Go 后端固定到 `51c827d3d56533550e67bc4f78ff7673fa7bd9a3`。

上游提供同一 Store 的完整投影；ZeroAgent 仍须落实账号、设备与工作空间的选择权限。
Native 发布源必须匹配当前已验证后端的数据根，旧 profile 的迟到发布拒绝执行。
Gateway 广播与重连回放只投递选中设备，快照先过滤再分页，工作目录和总数来自同一投影。
范围外的增量行以及范围内无法判断原目录的删除，通过既有重同步状态推进消费者水位，
不返回范围外的标题、路径或会话 ID。退出、过期、撤销仍由发送前的选择验证拦截。
账户会话路由目录从已接受的摘要快照及变更更新，重复和旧序号不更新目录。

保留现有 `zeroagent-managed-kbrain:<storageId>` 映射和端口轮换后的身份，采用上游
批量写入、存储不可写时的内存缓存与删除别名上限。拒绝把无数据根身份的旧托管映射
自动归入当前账号，也不恢复缺失映射时的隐式历史导入。ADR0035 的显式只读导入保持。

采用新的上游资源回收规则后撤销 `0005-image-unknown-history-deletion.patch`；未知结果
删除、活跃 worker lease 与幂等收据由上游实现及回归覆盖。保留另外八项补丁；其中 0009
追加现有 CLI 压缩夹具的显式缓存模式，原缓存键断言保持，其余七项字节保持。

验证包含真实固定后端 HTTP 会话变更和重连、真实账号选择 WebSocket、Native 发布源
边界、完整桌面/WebUI 回归与打包浏览器工厂运行。详细结果以 beta.24 同步报告为准。
上游交互式诊断脚本保留来源参考；其 token-only 流程不代表 ZeroAgent 账号验收。
