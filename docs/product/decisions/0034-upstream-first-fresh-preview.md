# ADR 0034：以上游维护为主的新安装预览版

- 日期：2026-10-25
- 状态：用户通过当前线程目标明确授权；实现与发布验收进行中
- 范围：ZeroAgent v2.0.0-beta.20 集成分支，本地重构、验证和打包

2026-10-26 补充：用户按 [ADR 0035](0035-platform-model-settings-and-history-import.md) 恢复
显式旧 ZeroAgent 会话导入，并开放平台内模型参数设置；本记录对应限制仅在这两项上被替代。
其余新配置、旧供应商/密钥/MCP配置迁移退出、安全与上游优先边界继续有效。

## 决策

公共能力优先由固定上游 Release 维护，保留 usa0 账号、权益、托管模型与密钥、设备授权与路由、账户隔离、Cloud Chat 边界、品牌、Android 及发布体系。实现顺序为上游原生能力、配置/扩展入口、独立定制模块、必要的最小补丁。内部命名和目录保持上游，品牌改动集中在用户可见内容与应用/发布身份。

本轮采用独立新配置，不提供旧数据迁移、旧版本回退、旧服务商归档或额外历史协议容错。原有用户数据留在原位置，不自动读取、迁移、覆盖或清除。此决策替代 ADR 0010、0015 及后续文档中仅为旧版升级与归档提出的要求；不取消新版正常保存、持久化、备份或失败恢复保护。

旧自建 LLM Provider 不进入新版可执行配置。当前账户只使用 USA-Zero 托管模型。MCP 自定义服务器是独立能力，使用同一 Go manager 与官方 SDK；已展示的标准 SSE 能力可用最小接线修复，退出显式历史 messageUrl 覆盖、端点猜测和私有 runtime 管理协议。Native 凭据桥、授权归属及已复现的进程/取消清理修复保留；每项补丁记录上游缺口及等价修复后的撤销条件。

## 实施边界

- 先撤无消费者的私有接口及其专属测试，再合并重复适配；上游本身保留的闲置实现不为减少总代码行数而另造删除差异。
- 旧导入 IPC/UI、自动归档、旧备份格式与旧 WebDAV fallback 退出；新版备份格式明确标识并拒绝旧格式。单一新版读写布局，不添加双写、自动搬迁或兼容回退。
- 配置私有字段保护、并发写入冲突、当前操作失败后的补偿与设备落盘 ACK 继续保留。失败补偿属于新版写入正确性，不属于旧版本回退。
- 不通过删功能、放宽权限或削弱测试断言隐藏发布阻塞问题。通过且来源不变的证据可复用，历史索引不能覆盖较新的运行回执。
- 源码合并保持精确 Release 的 Git 祖先；只有进入实际集成历史后才更新同步元数据。当前授权不包含推送、外部发布或部署。

## 验证与交付

第一个里程碑是可安装 Windows 候选及登录、托管模型对话、工具审批/执行、设备连接、切号、退出撤销和重启的实际证据。随后完成现有其他支持端、Gateway、签名、打包及发布准备检查。

完整完成条件为安装包、来源匹配的验证报告、剩余本地差异清单与发布说明，且无未解决发布阻塞问题。缺设备、凭据或签名环境的检查明确列为待验证；继续其他独立工作，不能将编译或窄专项当作完整产品验收。
