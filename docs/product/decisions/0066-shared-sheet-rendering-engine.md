# ADR 0066：共享表格阅读器的完整格式引擎

- 日期：2026-11-01
- 状态：接受
- 范围：只读 XLSX 阅读与输入框封面，承接 ADR 0060、0064、0065。

用户要求补齐条件格式、嵌入图片和图表。简化单元格画布无法完整呈现这些内容，采用固定版本 MIT 的 `@extend-ai/react-xlsx`（0.19.0）与其 MIT WASM 依赖 `@dukelib/sheets-wasm`。ZeroAgent 保留格式阅读器外层、宿主授权、不可变版本、账户生命周期、阅读状态、原件下载和恢复逻辑。

完整阅读和封面使用同一实际虚拟化表格与绘图层，覆盖绘图层。库自带的 thumbnail hook 不包含图表，故不采用。无新增编辑、自动发送、服务器转码或第三方文档服务。所有代码、字体、WASM、地图数据随应用本地打包。

上游默认加载重算与产品只读契约冲突，使用可复现 pnpm patch 在带 reparse 的加载计算路径直接保留工作簿缓存。原件和版本不改动。外部关系在内存预览副本中移除，活动 SVG 拒绝预览；宏无执行入口。解析前沿用可终止 Worker 的 ZIP 实际体积/路径检查和有界网格检查；超限、旧 XLS 和 CSV/TSV 保留已有受限兼容路径。

该引擎只承诺经验证的格式呈现，不宣称替代 Excel 或支持宏、外部数据刷新、在线编辑。兼容性缺陷通过真实文件回归及明确错误反馈处理，不能静默丢失内容。依赖 MIT/ISC/OFL 许可随打包保留，更新依赖时复核补丁、安全边界、取消及多端构建。

实现细节：使用虚拟 DOM 网格适配公共 ScrollArea，避免第三方 Canvas 表头与自定义滚动容器的坐标错位。WASM、OOXML、条件格式和图表数据在专属 Worker 读取；LinkeDOM 仅作为 Worker XML DOM 的本地实现，补齐命名空间/localName 与通配标签查找。为只读 Worker 补全条件格式与迷你图所需的有界数字快照（总计不超过 100000 个输入），解决上游仅在主线程绘制这些装饰的缺口。重型数据不存入阅读状态。

可复现补丁还固定表头/列宽度量、默认图标集与阈值顺序，并支持常见单元格比较条件表达式；不使用 eval 或加载公式计算引擎。完整 Excel 条件公式语言、外部链接刷新、ActiveX/宏、旧二进制 XLS 的绘图对象不在只读查看器承诺内。固定版本升级必须复核这些差异及真实 Worker 回归；禁止静默回到主线程自动重算。

当前引擎仍有呈现边界：单元格内富文本段落样式未完整保留，跨冻结区域的绘图可能被冻结层裁切，复杂图表与特殊对象需要继续以真实文件核验。这些差异必须写入验收说明，不能将已覆盖的能力类别表述为对 Excel 全对象的无损兼容。

2026-11-02 反向滚动修复：React 滚动插槽与 Preact 虚拟行共同更新时，条件移除 gap 行会残留高占位节点，回到顶部后正文被推到视口下方。ESM/CJS 补丁保持每个虚拟行片段内的占位节点稳定，零高度时使用 display:none；继续沿用原虚拟范围和几何计算，不加载整张表、不重建文件控制器。真实 Worker、实际 React/Preact 查看器和公共 ScrollArea 的长表往返滚动加入回归，浏览器另验同一用户文件。

验收资源由 `scripts/generate-sheet-preview-fixtures.py` 生成，测试保存无用户数据的小型 XLSX。正文和封面都用同一引擎；实际回归包含数据条/色阶/图标/表达式、六个迷你图、九类经典图表、PNG/文本形状、冻结/隐藏/合并/空表、缓存公式，及恶意 XML、外链和资源边界。
