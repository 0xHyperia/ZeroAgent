# 0021：独立持久化界面偏好

- 状态：部分实施；桌面 UI 偏好存储与迁移已接线并通过定向验证，设备 Native 提交入口见 ADR 0022，真实设备端到端验收仍待完成
- 关联：ADR 0018、0019、0020

主题、语言、聊天显示选项、自定义界面设置、更新偏好、错误重试偏好和关闭窗口行为保存到当前 profile 的 Native SQLite 表。首次读取时将该 profile 的旧 WebView 缓存迁移一次；此后 Native 值优先，清理 WebView 缓存不再丢失这些偏好。模型选择继续以 Go settings 为准，不把旧缓存中的模型注册为可执行模型。

UI 偏好使用独立的 za-ui-v1 读取版本。它不推进七张配置表的原生版本，也不进入 Go 配置的全局版本。桌面一次复合编辑分别提交规范配置和 UI 偏好，并等待所有任务结束；规范配置被拒绝或进入待核对状态时，独立 UI 写入仍可提交。UI 写入不依赖运行中的 Go 连接，不要求配置协调器处于一致状态，但仍要求有效 profile、托管凭据检查和 SQLite IMMEDIATE 事务。旧窗口必须使用自己的读取版本，连续排队编辑只有在完整 UI 基线匹配本窗口上一笔成功结果时才能继承版本。

Native 工作副本允许显式 uiPreferences 更新，携带独立 expectedRevision。最终 SQL 事务同时重查 Native 与 UI 版本，提交相关表并返回两个新版本；准备后出现的另一连接 UI 写入会拒绝整笔更新，后期 SQL 失败会回滚全部 Native 与 UI 字段。设备混合更新现通过 ADR 0022 的 Native 提交入口使用此能力，持久化后才生成成功回执；真实设备验收仍待完成。

UI 表不包含模型选择、账号令牌、连接权限或自动化配置，不加入可移植备份。WebView 缓存保留为即时显示和旧版迁移来源；浏览器宿主仍使用原有浏览器偏好存储。设备同步快照现从此 Native 存储读取，已提交通知只要求界面重读，不再次保存。

全局技能选择以 Go 规范文档为准；旧 Native skills 字段仅保留缓存兼容。其规范保存和补偿见 ADR 0022。
