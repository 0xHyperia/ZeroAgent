# ADR 0045：缓存提示默认值、模型继承与实际请求

- 日期：2026-10-27（Asia/Hong_Kong）
- 状态：用户明确授权对齐上游、补齐执行链、测试并构建运行；不推送

托管 OpenAI 供应商缺省使用 `auto`，模型缺省不覆盖供应商。保留已有明确模式及旧的
`promptCachingEnabled:false`（解释为 `none`）；历史值没有操作来源，不能猜测它是用户
选择还是旧默认而批量开启。刷新、保存无关设置和重启不能重置已有配置。

沿用 LiveAgent 在切换 Go 执行器前的最后一版 `codexPromptCache.ts` 规则
（`7cfd13da^`，祖先提交 `5a368b6d` / `0bec627b` / `4f6bf848`）：模型覆盖优先，
缺省继承供应商；Responses 的自动模式发送会话缓存键，Chat Completions 自动模式
按真实解析后的主机识别官方 OpenAI/OpenRouter（含其子域），其他主机不附加提示。
手动 OpenAI 模式发送缓存键，OpenRouter 模式只发送 `x-session-id`，none 不发送提示。
已有端点能力显式限制继续生效，不承诺服务端命中率或节省费用。

固定 K-brain 版本已有缓存传输器和能力配置，但模式枚举未参与执行、模型字段未接入。
新增可撤销的第九补丁，复用现有模型元数据、设置事务、保存格式投影与路由，不复制 Agent
执行循环。覆盖字段写入、读取、重启、普通路由和同协议故障转移；共享模型 ID 的覆盖保持
供应商隔离。传输中空模式表示清除覆盖，持久数据缺省仍表示继承。此用户授权替代 ADR0035
和 ADR0041 中“后端未支持前隐藏模型覆盖、暂不扩展 schema”的对应限制。

Desktop、设备 WebUI/Android 保留上游编辑器和模型级继承入口，撤销不支持字段的丢弃。
Native 模型代理仅额外转发受控 `x-session-id`，固定平台地址、凭据保护、账号/profile、
配置版本与回执边界保持。没有外部供应商入口、数据清理、收费模型测试或缓存性能宣称。

等价上游 Go 实现通过同组测试后撤除第九补丁。此次新增模型字段为可选扩展，未承诺旧
后端可直接读取新配置；不执行自动迁移或旧版回退。源码撤销前需保留当前数据。

验证需覆盖共享真实表单、双端默认值/刷新、设置传输和远程投影，Go 设置校验/落盘重开、
模型/供应商覆盖与出站载荷/请求头，以及真实准备后端经 Native facade/broker 的运行时。
构建内嵌前端 Windows 客户端并检查侧车来源；人工视觉由用户操作，不等待或操作桌面 UI。
