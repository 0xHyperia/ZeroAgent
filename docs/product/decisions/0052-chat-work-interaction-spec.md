# ADR 0052：对话/工作连续切换与体验规范

- 日期：2026-10-29。
- 状态：用户要求完整参考 ChatGPT 的对话/工作前端体验并形成规范；本地实施，不推送。
- 范围：CloudChat Web、嵌入的 Android；共享 UI 仅增加显式 opt-in 展示能力。

采用单一编辑器的自适应单行/多行布局、稳定输入框锚点、滑动模式指示、可反向高度动画、
上下文工具栏及建议。手机将输入放在底部，工作工具栏上移，建议横滑，快捷资源使用共享 Sheet。
沿用原字体、主题、Tooltip、Popover、Dialog/Sheet、模型状态、Android 键盘与安全区桥。

项目和文件快捷选择复用既有账户客户端，不引入另一套资源存储。项目按当前服务器关联版本
保存，更新中阻止重复选择与发送；新草稿首次选项目创建一次会话，恢复完整结构化草稿与引用。
会话/账户守卫阻止迟到结果更新新视图。建议追加已有草稿，不自动发送或启动外部执行。
用户进一步明确：“新对话”是本地空白草稿导航，不直接创建数据库记录或空侧栏项。
首次实际发送仍按已有链路创建一次会话；其他明确保存上下文的操作不借此扩大改动。
重复点击清空当前待发送内容与引用；离开执行中的会话仅断开页面订阅，不取消任务或清除历史。

“对话/工作”本身仍是呈现选择，不切换模型、设备、权限、联网或服务端 Run。
用户随后明确：切换只属于首条消息发送前的新会话；已有消息、历史加载、首次发送准备及
生成时隐藏，生成结束后仍隐藏，新建空对话再显示。保留已选输入呈现，不增加后端模式或执行权威。
参考的插件位置按目前真实能力显示“工具”；不伪造尚未接入的第三方连接、相机或语音。
语音仍不列为本次开发条件。公开研究仍走明确主题确认，不把私有草稿转交搜索。

共享 ChatComposerBar 保留标准布局，inline 仅适用于显式选择的 Web text 模式；Desktop、
Agent 命令安全、Git、队列和语音默认行为保持。没有迁移、清理或重写用户数据。
撤销展示扩展不需要数据回滚；用户已显式保存的项目关联继续是合法当前数据。

规范见 `docs/design/cloudchat-chat-work-ux.md`。验证须覆盖编辑器/选择范围/模型实例保持、快速
反向与减少动态、移动选择层焦点、分页/重试/晚到隔离、项目 CAS/首次会话与草稿引用、已有
任务及研究确认回归、首次发送/已有历史/未知提交时隐藏模式切换及新对话恢复、三端类型、
生产构建和真实浏览器对照。真机和外部能力验收单独记录。
