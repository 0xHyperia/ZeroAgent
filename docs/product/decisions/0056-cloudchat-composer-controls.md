# ADR 0056：CloudChat 模型定位与输入操作体验

- 日期：2026-10-30。
- 状态：按用户要求及 2026-10-30 登录界面实测修订后本地实施，不推送。
- 范围：CloudChat inline 输入区、共享模型列表的可选定位能力、共享 tooltip 以及云端环境显示名称。

CloudChat 显式使用 ComposerInlineModelControls；默认 ComposerModelControls 保留原设备/桌面呈现。
宿主仍是唯一模型、分组与运行参数来源；新增状态仅限弹层页面和尚未提交的滑条预览。
常态一个视觉胶囊显示厂商图标、模型和思考短标签；两个直接操作区域分别打开模型列表与离散滑条。
各区域有独立焦点和可访问名称，共用同一个 312px 弹层与整个胶囊锚点，不增加第二套配置状态。
弹层内部可互相导航；导航后原区域仍能直接到达其对应页面。模型选择完成即关闭，保留原保存链路。
显式 `/model` 或不支持调节思考时直接打开模型列表。受控打开区分普通触发与显式外部请求。

模型列表传入 revealSelected；此 opt-in 覆盖 ADR0040 在 CloudChat 打开时“全部折叠”的行为。
默认设备与设置选择器不变。定位只展开当前分组并滚动列表自身；手动折叠不被重渲染覆盖，
厂商视图仍须明确选择具体路由，不静默换分组/密钥。厂商图标复用 ProviderBrandIcon 及已有库资产。

滑条沿用宿主传入的参数选项，遵守 thinkingAlwaysOn、禁用和原保存链路。不新增模型能力表或自动改写参数。
拖动预览、松手提交，
键盘调节松键提交，失焦提交，Escape 取消预览；恢复默认使用 DEFAULT_CHAT_RUNTIME_CONTROLS 的真实默认档。
预览与原模型绑定，模型变化时丢弃，迟到的失焦/松手不修改新模型。
所有思考档位保持蓝色，不用紫色 max 冒充独立的 Ultra 协作策略；不新增 Fast、跨模型推荐或后台能力。
左侧问号实际控制按需说明，恢复按钮提示真实默认档；配置编辑入口仍在设置及默认选择器，日常 CloudChat 列表不重复放置。
两页宽度和锚点相同，180ms 仅过渡高度，打断后连续反向；减少动态时立即切换，文字不缩放。
手机两个区域、面板内模型导航、说明/恢复和滑条至少 44px 高；触屏模型列表不自动聚焦搜索。

模式选中块高于底轨，hover 只提亮文字。tooltip 保持共享组件、短标签胶囊、清楚字重与快捷键底面；
淡入不缩放文字，说明/结构化统计保持阅读空间。统一尺寸、层级与描述关联，而不复制另一套提示系统。

发送/停止复用 ChatComposerBar 的同一真实按钮和原队列/停止判定；发送圆形主操作转为有文字的停止胶囊。
加号沿用 Base UI 菜单、原资源动作及焦点所有权，紧凑锚定菜单只改变呈现。
保留草稿、单编辑器、首发后模式隐藏、手机安全区、默认设备执行及命令安全/Git/语音契约。

服务端云端环境名称与 Web 展示统一为“云端对话”；runtime_kind=web_chat、授权和协议保持。
不做数据迁移/清理，不调用外部模型或改变账户范围。撤销展示扩展时已保存的模型/思考值仍由宿主持有。

验收包括分组/厂商定位、手动折叠、明确路由、受控入口、离散滑条提交/取消、固定思考/触屏焦点、
单按钮停止不发送、编辑器保持、默认设备/设置回归、类型/构建/边界/契约以及桌面/手机/深色实测；
证据见 design-qa.md。

本次参考区分观察与解释：ChatGPT 的 Max 在实测中为蓝色，Ultra 为独立紫色策略，默认推荐组合还能跨模型。
ZeroAgent 沿用现有明确模型与分组授权，因此采用直接操作区域减少换模型步骤，保持设置语义明确，
不把参考中的推荐/协作视觉直接映射到现有 reasoning=max。完整观察见
`.codex-artifacts/chatgpt-model-study-20261030/study.json`，体验规范 v1.8。

2026-10-30 交互修订（规范v1.9）：删除重复实现说明；原生range保留键盘/提交契约，
使用手型光标与独立视觉滑块实现换档过渡和Hover/按压反馈，拖动时直接跟手。
模型视图切换原子更新展开项、绘制前定位，避免先折叠后展开的闪烁；加载期间保留已有结果，
无结果时使用骨架，刷新复用共享RefreshButton反馈。不增加请求、模型参数或路由状态。

连续滑块修订（规范v1.10）：独立ReasoningSlider持有连续指针位置和单点Hover状态，参数仍只预览/提交真实档位。
原生range使用step=any，键盘显式整档；视觉圆钮和填充使用独立transform轨道，拖动跟手、松手吸附。
轨道/圆钮/点按实测采用24/28/4px，单个悬停点放大至8px。保留取消、失焦提交和模型隔离，不新增执行能力。
