# ADR 0070：能力中文展示与品牌一致性

- 日期：2026-11-05。
- 状态：用户通过录屏对照及中文/图标要求授权本地实施，不推送。
- 范围：共享展示层与CloudChat实际能力入口。

四个内置能力默认以产品设计、生成图像、创建插件、创建技能显示。展示注册表集中管理中文名称、
原名/标识搜索别名与同源品牌资产，目录、详情、管理、阅读、添加菜单和输入引用消费同一份定义。
个人内容保留用户名称，未登记的能力不猜测身份。显示标签和搜索不能重命名内部包/技能、创建修订、
替换固定版本引用或改写已有普通草稿文字；老的已识别引用可在呈现时显示新中文标签。

内置标识为本轮生成的原创资产，遵循ZeroAgent银白立体质感、统一圆角/光向/重量和克制识别色。
第三方接入应使用其真实且可用的品牌资产；个人无资产使用中性回退。操作按钮仍用共享操作图标，
品牌身份与操作含义不混用，不新增远程图像来源或任意HTML。

上传包改为先暂存、再明确确认。取消和预览不写入；确认沿用既有账户CAS与有界ZIP验证，
失败保留文件，未知结果禁止重发并提供只读刷新核对。接入新的展示资产不扩大ZIP支持或执行权限。
快捷菜单从真实已安装目录生成，查看详情与加入当前引用是分开的动作；目录往返继续经过既有离开保护。

录屏中的外部服务目录及MCP/OAuth连接仍需真实服务后端与单独验收，不能由图标、空表单或复制品牌名替代。
详细差异、设计与证据见 `docs/design/cloudchat-extensions-ux.md` 和 `design-qa.md`。
