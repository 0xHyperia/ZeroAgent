# ADR 0042：ZeroAgent 对外命名与当前数据保留

- 日期：2026-10-27（Asia/Hong_Kong）
- 状态：用户明确授权修改、测试、构建运行；不推送

用户可见文案、公开环境变量和应用拥有的存储名称统一为 ZeroAgent。内部包名、Go module、
协议标识、上游资源约定和来源记录继续保持上游。应用环境变量只公开 `ZEROAGENT_*`（前端应用变量为 `VITE_ZEROAGENT_*`；平台与第三方
工具变量保持各自契约）；上游后端必需的私有变量仅在子进程启动边界注入，不改变协议。
开发/部署/CI/发布脚本与当前配置示例一并更新，不长期提供两套公开变量。

本决策补充 ADR 0034 的命名范围，并授权保留当前 v2 数据的受限目录切换。账号后端数据
从同一已验证 profile 的 `kbrain` 子目录切到 `engine`，保持账号摘要、配置、会话、图片及
凭据内容。仅处理 ZeroAgent 自己的当前 profile，不扫描其他产品，不恢复旧供应商迁移。
旧路径有数据且新路径不存在时在后端启动前原子改名；两边同时存在时明确拒绝启动，避免
合并、覆盖或悄悄采用空目录。异常不删除来源。现有设置根、OS vault 服务名、会话标识和
浏览器持久键保持，已有工作树/附件的绝对引用及显式旧会话导入来源继续可读。

仓库构建缓存使用 `.zeroagent`。已有缓存只作为受校验的构建来源，不删除原缓存。主配置
和账号应用数据已使用 ZeroAgent 根目录，不为命名再次改变它们。UI 路径提示与真实路径
保持一致；后台内部错误通过对外展示层描述为 ZeroAgent 后端，原始诊断仍可保留来源名称。

验证要求包括目录切换及冲突拒绝、账号隔离、已有真实数据的内容核对、环境变量/私有后端
边界、公开文案、两端前端测试/类型/构建、Native 完整库及真实后端夹具、Gateway 与脚本
检查。只检查本地运行环境，不提交真实收费请求、不操作桌面 UI、不等待人工验收。


新建子代理工作树及分支改为 `.zeroagent-subagents` / `zeroagent/subagent/`，清理入口继续
精确识别既有 `liveagent/subagent/` 与 `.liveagent-subagents`，不会搬动或清除旧 checkout。
文档预览、zsh 与沙箱临时目录使用 ZeroAgent 命名；既有 Windows 沙箱 SID/Profile 名是持久
安全身份而非显示名称，继续保持，只修改显示说明。容器数据根为 `/var/lib/zeroagent`，
UID 仍为 10001；已有部署需复用原卷来源，不在本次执行部署或数据卷改动。

名称，现同样使用 ZeroAgent。既有语言与主题存储键、启动唤醒与性能标记保持；JSDOM
实际执行内联脚本，覆盖默认、zh-CN、en、en-US，不只检查应用翻译表。
