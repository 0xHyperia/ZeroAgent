# ADR 0059：共享工作台组合与宿主能力适配

- 日期：2026-10-30。
- 状态：用户明确授权本地实施与验证，不推送。
- 范围：桌面本机、桌面远程、Web CloudChat、设备 WebUI 和嵌入 Android。

在 ADR0058 的共享组件之上收敛工作台骨架、导航定义、品牌资源引用、设置外壳与输入栏呈现契约。
三类业务入口保留现有账户、执行目标、控制器、历史、任务和资源协议。桌面远程继续按 ADR0046
独立构建和释放 WebUI 工厂，不合并 GUI/Web aliases，不引入新的全局客户端或执行器。

WorkbenchShell/WorkbenchBody/WorkbenchCanvas 负责布局与表面，采用 panels、stacked-panels 和 page
三种显式组合。各宿主仍提供窗口控件、原生留白、应用更新、账户菜单及资源面板。导航元数据由共享
定义生成轨道和功能侧栏；真实目的地、可见范围、离开守卫和回调由宿主提供。悬停不导航或改变执行目标。

输入栏 presentation 仅决定画布几何和高度测量；capabilities 明确声明执行控件、Git 与本机目录选择
支持范围。宿主可按当前状态进一步收窄入口，不能通过布局或 visibility 放大支持范围。此声明仅用于
前端呈现，不能授予执行权限或代替 Native/服务端认证。保留上游 surface 调用的默认几何，不引入旧数据
或协议兼容；产品入口全部显式注入新参数。发送、停止、队列、语音、审批和草稿仍走既有控制器。

设置使用同一外壳，允许拥有者将原应用轨通过展示 Portal 移入，或保留在外部。Portal 模式保持后台
几何占位；外部轨道模式不复制账户菜单。原会话树隐藏并 inert，仍保持挂载。品牌标记统一引用两种
应用产物均携带的资源，宿主可提供显式资源 URL；不读取执行目标的任意资源路径。

共享边界检查阻止业务入口重新复制工作台、设置外壳或平台分支布局。验证覆盖真实 React 中编辑器、
选择范围与模型实例保持，导航预览与手机抽屉，能力收窄、发送/停止、设置离开守卫、切号与远程卸载；
Web、GUI、embedded-mobile、embedded-desktop 分别构建。纯 UI 以 Web 宽窄视口验收；原生桥的已有
隔离回归继续运行，浏览器夹具不替代真实平台或真实在线设备验收。

本次不更改持久数据结构、数据目录、账户映射、租约、配置写入、后端授权或发布流程。
撤销改动仅涉及前端组合及适配接线，正常持久化的数据和各运行控制器保持。
