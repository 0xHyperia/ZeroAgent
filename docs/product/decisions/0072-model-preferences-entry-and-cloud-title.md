# ADR 0072：统一模型高级入口与云端标题配置

- 日期：2026-11-05。
- 状态：用户授权本地实施。
- 设计：`docs/design/model-preferences-ux.md`。

聊天模型浮层底部提供“高级设置”，关闭模型浮层后在当前工作区上方打开弹窗。按用户后续纠正，设置侧栏不增加“图像创作”或“模型与高级设置”分类。桌面、设备网页和云端网页共用修改前的高级设置弹窗样式：设备端两列卡片、独立滚动，云端单列任务偏好；原有间距和头尾关闭按钮保持，手机为全屏弹窗和单列滚动。供应商和图像入口打开同一弹窗，关闭后保留原工作区、模型、草稿和来源焦点。

本机与连接设备继续使用既有配置、自动保存、同步和备份；标题、提交说明、澄清的模型消费者保持。新增默认生图目标用于新图像草稿，保留已恢复草稿、任务及其参数。修改默认值不重建控制器或取消正在执行的请求。高级设置移除目标与参数编辑入口；生图模型复用共享模型字段。候选来自服务端有效目标（包括供应商派生模型），默认未配置，不回退第一个可用模型；既有草稿和任务保持。

CloudChat 使用独立账户 CAS 资源保存标题配置，默认关闭以保留现有费用行为。用户可选账户分组内的模型，或跟随本次对话模型；界面不再提供额外推理参数表单，已有合法值保持。模型下架不会阻止关闭功能；再次启用时重新验证归属与目录。首次对话完成且原始标题未被用户管理时才尝试一次辅助请求。请求最多 20 秒，只发送有界的首条用户纯文本，不暴露文件、对话历史或工具。使用现有固定平台和账户密钥归属校验，注销会取消辅助请求。

辅助请求在对话任务终态成功持久化后启动，不阻塞回答或延迟终态。失败、截断、秘密反射、超时、进程退出或结果不明时保留截取标题；不重放、不自动重试。写回比较原标题、更新时间、管理版本和生成设置版本；手动命名（即使文字相同）、新消息、删除或配置变化均阻止覆盖，不改变会话列表排序。网页仅执行有界、可取消的只读刷新。

云端与设备共用生成模型卡片、字段、生图选择器和默认空值；宿主适配目录与保存。云端按相同任务顺序使用单列弹窗，不复制设备专属协议或显示额外模型参数表单。标题设置显式保存，编辑草稿按账户保存在浏览器会话存储。迟到响应受账户与请求取消保护；保存不确定或冲突后，先只读重新获取并核对，不自动重发写入。生图继续使用已有账户生图资源，不建立第二个默认值。

设备 Git、澄清、请求重试和协议故障转移不能冒充云端执行能力。云端表明配置范围，设备网页可配置所连设备。当前没有视频执行链路，本轮显示不可用；不提供只保存但不消费的视频模型字段。视频实际生成是后续独立能力接入范围。

验证包括真实 PostgreSQL 隔离 schema 的 CAS、账户隔离、CSRF、模型归属、受控供应商执行、改名/新消息/注销等写回竞争、未知写入核对、图像草稿与控制器保持，以及实际桌面和手机设置流程。不使用真实收费模型完成验证。

模型页底部统一为紧凑工具栏：高级设置、设备执行方式和设备联网；思考页不重复工具栏。生图卡片无常驻刷新行，目录操作复用选择器工具栏，错误处保留只读核对恢复。
