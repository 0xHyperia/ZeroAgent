# ADR 0002：Cloud Chat 与设备 Agent 是不同运行模式

- 状态：已采纳
- 范围：Desktop、WebUI、Gateway

## 决策

Cloud Chat 是托管对话运行模式。设备 Agent 是用户明确选择且经过认证的桌面设备，可以执行
本地工具并访问工作区。两者可以复用共享 UI，但必须分别声明能力，设置界面也必须遵循能力
边界。Cloud Chat 不得显示依赖桌面运行时且实际不可用的控制项。

## 重新评估条件

当能力协商协议可以在不依赖固定运行模式名称的情况下表达同等安全和体验边界时，可以重新
评估。迁移必须证明 Cloud Chat 无法调用本地能力。
