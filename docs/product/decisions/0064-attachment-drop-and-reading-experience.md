# ADR 0064：附件拖拽、封面与阅读体验

- 日期：2026-11-01。
- 状态：按用户提供的豆包、ChatGPT 截图实施；不推送。
- 范围：共享拖拽提示、附件卡片与预览器，CloudChat 的上传和文件/成果阅读接线。

拖拽提示采用退让背景、居中图形和清晰主次文字。浏览器拖拽生命周期和桌面原生路由分别
保留，只复用 FileDropPrompt 的视觉；不会截获文本、工作区路径或既有会话拖拽。容量、格式
和权限以宿主与服务端为准，放下文件只上传并加入草稿，不自动发送、创建空会话或执行模型。

上传中的文件立即显示独立状态卡；仅规范上传响应可以成为可发送引用。附件名称、状态和
版本分别显示，移除按钮只删除草稿引用，不删除原件或成果。鼠标 hover/键盘焦点显示角标，
触屏常显。点击整个卡片打开同一阅读器，移除和预览为独立目标，不使用嵌套按钮。

缩略图复用 ResourcePreview 的原件读取、摘要与格式校验，浏览器在视野内才读取/解析，
离开视野或宿主退休时取消。缩略图单件最多 4 MiB，超出或不支持时显示格式卡；完整预览
维持既有 32 MiB 上限。Word 缩略图只保留真实首页，不以假缩略图或模型摘要代替原件。
所有缩略图 inert，不能导航或执行文档内容；预览可用不等于 AI 已完成隔离解析。

900px 以上可用画布支持并排聊天/阅读，窄屏进入单一阅读面板。文件标题使用共享菜单，
详情侧栏显示真实类型、大小、时间、状态与来源；较窄阅读面板采用内缩详情卡，Escape
先关闭详情，再按原面板规则处理。Word 缩放只改变同一 iframe 的展示几何，不重读文件。
元数据刷新使用内容摘要维持原件预览身份，处理状态变化不重置正在阅读的同一文件。

成果历史使用实际不可变版本列表，展示版本、保存时间与状态，支持切换预览、下载及
引用选定版本继续工作。普通上传原件不伪造历史版本，也不提供不存在的“恢复版本”写入。
删除原件或整个成果家族使用共享确认弹窗，说明引用影响；失败、未知删除结果和后端
清理回执沿用原协议，不假称已释放容量或已永久清理。

不更改数据库、对象键、账户隔离、保存/发送/取消、配额、解析或发布授权；回退仅撤销
前端呈现与接线，不清理用户数据。验证覆盖拖拽生命周期与原生路由、独立草稿引用、
缩略图读取/取消/体积限制、预览字节安全、版本切换、删除确认与宽窄屏实际布局。

资料空间的上传可携带客户端生成的随机请求编号。Gateway 按账户与编号派生文件标识，沿用原件保存和配额检查。已占用的标识拒绝再次写入。只读核对按当前账户查找该次上传，并沿用原件可用性与权限判断。浏览器只在当前账户和窗口保存待核对的编号、文件名、剩余数量与目的地提示。核对原件与核对文件夹放置分别呈现。

2026-11-01 后续按用户截图整体调整：拖拽边界提升到 CloudChat 应用外壳，提示通过 Portal
覆盖轨道、侧栏、对话与阅读区；保留当前场景和阻断条件，内部资源拖拽仍只传身份。
打开阅读时复用既有 DividerLayer 调整左右宽度，限制聊天/阅读最小尺寸，保存当前页面内
的比例，支持悬停、指针捕获、方向键和双击均分。缩窄或展开阅读只隐藏原聊天，不重建。

阅读采用安静的灰色画布、独立白纸/图片/幻灯片以及单一顶部工具区；缩放和格式相关工具
由原阅读器 Portal 到同一页头，状态仍归原阅读器。文件菜单和加载状态使用已有统一格式
图标，加载仅提供轻呼吸和扫光，不伪造进度。Word 保持纸张比例，以真实排版页生成有界
导航，原生片段定位不添加脚本或同源权限。表格仍明确只读与格式限制，音视频沿用原件
播放器，未实现的分享、编辑或版本恢复不展示为可用功能。

桌面前端构建通过，Biome、产品契约和 UI 边界检查通过。Edge 实际验证原有合成会话的
Word 侧读与单一工具栏，保留原草稿；独立真实组件样板验证指针分栏 44%→52%、PDF、
幻灯片、类型加载态及全视口拖拽。窄屏隐藏而不卸载聊天、键盘调整与均分由回归覆盖。
