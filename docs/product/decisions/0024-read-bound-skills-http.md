# 0024：技能 HTTP 读取版本绑定全局与工作区

- 状态：Native viewer 与资源适配器已实施；新增原生/前端回归通过，完整平台与真实账号/设备验收仍待完成
- 关联：ADR 0018、0019、0020、0022

技能 Hub 的全局开关和选择已经通过主设置的 Native 规范批量提交。单独的 /v1/skills/settings 是另一个公开 HTTP 写入口，资源适配器保留该能力；当前没有额外的独立技能设置表单需要重新创建。

Native viewer 的 GET/HEAD /v1/skills 现签发实际文档的 ETag，绑定当前 profile、全局规范版本、原始 workdir 范围及完整技能资源文档。工作区版本不能用于全局或另一工作区。完整文档包含发现列表，安装或删除后的列表变化不能错误返回 304。PUT 缺少 If-Match 返回 428，过期或跨范围版本返回 412；共享 profile 边界保证同一版本的两个 Native 写入最多一个成功。技能 manage、文件读取和商店下载维持原传输路径。

该端点一次写入 Go 自己原子保存的技能文件，不把工作区选择塞进只表示全局技能的规范批量字段。保留上游 inherit、custom、off 与 skillNames 语义，工作区更新不覆盖全局选择。写前的私有恢复记录保留实际所属技能设置文件、原始存在状态及所属根内相对路径，从而区分“没有工作区覆盖”和“自定义列表恰好与全局相同”。原始文件版本与读取文档不符会拒绝提交；目录或文件越过当前空间、文件为符号链接或超过大小上限时也拒绝。恢复资料仍限 Native 当前空间，保留最近 20 份；恢复界面和跨进程原子性仍未完成。

成功回执的 ETag 必须对应返回的重新读取完整资源。已知写入成功而后续读取失败，返回已保存警告且不签发新版本；旧版本不能借给下一次编辑。请求中断、服务端失败或无效保存回执沿用待核对状态，阻止后续规范写入，不盲目补偿已知或未知状态。

资源适配器把版本作为当前文档的只读、不可枚举元数据，settings 调用显式传入该基线；不会先读取最新文档再把其版本套在旧正文。没有 Native 扩展声明的独立 Go 后端保持原有无版本请求和响应。此改变不替代真实 Native/Gateway/账号/设备 RPC 端到端验收，也不推进发布或同步元数据。
