# ADR 0012：二次密码校验保留 OAuth 会话

- 状态：已采纳，实施与验收中
- 范围：Desktop、WebUI、Android 嵌入 WebUI；关联 ADR 0001、0004、0009

托管密钥操作前的密码校验不能调用会写入登录状态的客户端登录函数。旧实现会让桌面端保存
临时密码登录 token，或让 WebUI 替换当前 HttpOnly Cookie，改变 OAuth 会话及设备连接归属。

桌面校验绑定当前 token、认证类型、OAuth 客户端及 current-user，临时校验结果不写入会话。
验证期间身份变化、邮箱不符或完整登录结果的用户 ID 不符时拒绝通过；密码错误不撤销当前
有效会话。WebUI 使用独立的已认证校验接口，由 Gateway 绑定当前 Cookie 账号；接口不创建
ZeroAgent 会话，不返回上游 token，不设置 Cookie，完成前再次确认原会话仍有效。

这里保留 ADR 0004 的“重新验证密码”含义。上游返回有效的待 2FA challenge 只表明密码已
被接受，不表明多因素登录完成；不会据此建立登录会话。此修复不替代全部托管密钥流转、
原生显示/复制授权、近期授权期限及真实账号的后续验收，也不声称前端尚无原始密钥流转。
