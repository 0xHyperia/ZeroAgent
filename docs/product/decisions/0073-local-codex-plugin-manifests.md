# ADR 0073：本机 Codex 定义分析与显式技能入口

- 日期：2026-11-05。
- 状态：用户要求直接分析本机插件与技能并实施。
- 分析：`docs/design/local-codex-plugin-analysis.md`。

Product Design 对齐本机 0.1.56 的 10 个设计流程，Plugin Creator 对齐 0.1.28 的 3 个流程；创建技能不属于产品设计。生成图像、创建技能按本机系统目录的定义作为独立技能。保留内置包 ID、安装状态、中文名称和原创图标；界面不增加内部发布版本的设计。

当前内置包改用 manifest、`skills/<name>/SKILL.md` 入口与 `references` 辅助资料。导入支持根 `plugin.json` 和兼容 `.codex-plugin/plugin.json` 的有界 UTF-8 指令包，读取显式技能目录和单层 SKILL.md；普通 Markdown、参考文档及多层辅助目录不注册成技能。拒绝重复技能、无效主入口、逃逸目录和不受支持的可执行连接声明。manifest 不能授予 MCP、OAuth、应用视图或主机执行能力。

原定义按精确字节归档，不修改已发布指令。当前别名保留旧技能启停选择；旧固定发布及其中已移出当前目录的技能仍可按原引用读取。当前详情、/ 和 @ 不发现已移除的成员。剪贴板只通过服务端目录列出的归档引用恢复改名或移除的旧技能，不把未来发布、其他包或未启用的目录变成有效引用。主入口引用仍固定整个包的指令发布。

本机 OpenAI 插件的流程和封装方式用于分析，ZeroAgent 指令为中文适配实现；不拷贝专有插件源码或品牌资产，不修改用户本机 Codex 安装。Figma、Mobbin、Sites 等专用服务工具不因本次分析自动成为 ZeroAgent 的连接。

验证包括 10/3/1/1 成员关系、独立技能分类、辅助文件不注册、manifest 安全导入、旧停用别名和精确归档 SHA-256、旧剪贴板固定身份，以及真实产品目录和详情。
