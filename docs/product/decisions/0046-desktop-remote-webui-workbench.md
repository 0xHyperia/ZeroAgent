# ADR 0046：桌面远程设备复用完整 WebUI 工作台

- 日期：2026-10-27（Asia/Hong_Kong）。
- 状态：用户明确授权改造、自动化及运行时测试、重建当前内网 Windows 安装包；不推送。

移除桌面独立的简化 `RemoteDeviceChatPage`，远程设备使用既有完整 WebUI `GatewayApp`、
共享 `agent-ui` 和 WebUI 远程适配器。桌面继续管理账号、设备选择、授权及窗口控制。
不新增 Agent 循环、协议或 iframe；上游固定 Release 与九个 Go 补丁均保持。

WebUI 与 GUI 的 `@liveagent/app` / adapters 指向不同宿主，直接放进同一个 Vite 模块图会
让远程页面调用本机适配器。桌面构建因此独立生成单文件 WebUI 模块，再将其内部模块初始化
封装成可创建和释放的运行时工厂。每次远程挂载拥有自己的 React、客户端、资源宿主及模块
状态；ESM 只缓存工厂代码，不为每次切换创建永久缓存的模块 URL。标准 Worker URL 保持。
头部设备开关与 Windows 控件通过 DOM 插槽使用原桌面 React 上下文，普通布局插槽不进入
弹窗层级。卸载回收远程 React、样式、连接和 handler，恢复桌面根标记。

账号和真实 token 仍由 Native 持有。账号、托管密钥列表/创建、复制及退出复用现有 Native
遮罩与密码证明，不能从 WebUI Cookie 代理取得原始密钥。原始 Cookie 和一次性 handoff code
不进入渲染层；新增 Native bridge 只在内存保留临时 Gateway 会话，固定来源和设备，供标准
status 与文件/目录上传使用。沿用当前已部署 handoff、Cookie 和 lease 协议，不要求更新远端
Gateway。请求边界校验来源、路由、设备、体积与当前会话，关闭/切号取消在途请求并尝试注销
临时会话；不透传 Set-Cookie。

远程模型发现和设置保存仅在绑定缺失时，按已验证 Native 账号补齐全量有效托管密钥的绑定，
保留已有能力及其他模型。模型配置继续固定平台来源并通过原 CAS/落盘链路；不会向控制端
返回原始密钥，也不允许调用方 URL/凭据覆盖。新建密钥的远端补齐需要目标设备运行包含本次
接线的客户端；旧客户端仍按既有凭据边界拒绝未注册绑定。

设备、账号、Gateway 命名空间隔离远程设置、会话选择和草稿。所有请求捕获当前宿主；失效
或卸载后的旧闭包明确拒绝请求，不能借用下一设备或降级到本机/Cloud Chat。租约到期采用
原服务器明确返回的有效期，临时 handoff 新 lease 不延长 UI 控制期限。列表失败/设备撤销
仍保留原远程选择，明确显示不可用；用户重新选择设备后恢复。退出失败保留当前页面与身份
以便重试，成功才结束 Native 会话。设备管理读取实时目录，手动改名和多端修改不被初始快照
覆盖。既有持久数据不搬迁、覆盖或清理。

安装版反馈后的补充修复：初始化加载、Native 连接、样式或挂载失败不再清除父级租约，保留
原始错误（包括 Tauri 字符串异常）；授权明确失效时将原因与原租约一起标记为不可复用，
旧连接回调不能废弃新租约。用户“重新连接”显式获取新租约，真实到期仍关闭运行时和 Native
桥。设备确认统一复用共享 Dialog 的顶层 Portal、遮罩和焦点管理，不在头部层叠上下文内
手写弹窗。Gateway handoff 与既有 WebSocket 复用同一已验证账号及固定有效期校验，避免
token 刷新改变控制端 ID 后误拒绝尚未到期的选择；跨账号及过期主体继续拒绝。这一服务端
修复需要更新实际运行的 Gateway，不通过桌面增加历史协议容错。

审批变更丢失回执后改为返回未知/失败，不自动重复提交；普通聊天沿用既有固定 request ID
的幂等恢复，读取接口保持原重连策略。未改变 Go 端执行和审批语义。远程功能按 WebUI 和
目标设备已支持的能力显示；现有账号模式图像服务未提供的能力不伪造本机替代。

验证要求包括两端完整前端和类型检查、真实完整 bundle 的 React DOM 挂载、生产二进制
Gateway 客户端的模型/CAS/流式/审批及丢 ACK、双设备/租约/断线/切号、Native HTTP 与真实
固定 Go 后端的新密钥绑定/保存、完整 Native 与 Gateway 回归和 Windows 打包来源检查。
不操作桌面 UI、不使用真实收费模型，也不把本地合成服务验证当作真人登录或其他平台验收。
