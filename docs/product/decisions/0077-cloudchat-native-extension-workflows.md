# ADR 0077：CloudChat 内置能力使用 ZeroAgent 工具

- 日期：2026-11-05
- 范围：CloudChat 及其响应式 WebUI

四个内置包使用新的 ZeroAgent 工作流发布。以实际完成任务为目标，保留原有包身份、归类和
历史固定引用。ADR 0076 的原包继续用于本机存档。正常部署从内置文件载入 ZeroAgent 工作流。

会话工具可拟定个人技能或插件，经现有包边界校验后存入私有操作回执。模型拿到草稿引用，
用户通过回复的产物卡片进入现有编辑器审阅和提交。保存仍走账户 CAS，同一新建草稿只保存为一个包。
更新只可针对当时拥有的个人包和明确的
基础修订，保留未修改的文件。草稿读取使用账户归属和工具完成状态，暂存不注册技能或连接。

设计用既有隔离工作区、受限的公开研究与私有站点成果。站点阅读支持固定宽度的真实浏览器
预览和批注。原型模板是 ZeroAgent 自有的离线文件。图像透明请求沿用固定供应商与操作回执，
保存前检查实际像素。未知请求不自动重发。外部设计应用、第三方 MCP 和自动浏览器核验仍按
宿主已提供的能力处理。产品流程与布局见 `docs/design/cloudchat-extensions-ux.md`。
不迁移账户数据。若回退工作流代码，已保存的个人包仍使用现有目录协议，未保存草稿回执随 Run 保留。

2026-11-06 补充。Product Design 的 Design QA 要求实际可比的参考与实现、关键状态和视口、
问题分级与复验。证据缺失或仍有可处理的严重问题时标记为阻塞。交付技能读取同一发布的 QA
流程。旧固定引用继续读取其原始正文。技能阅读区默认打开所选正文，包内资料通过菜单浏览。
