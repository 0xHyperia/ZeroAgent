# 0029：旧 Native MCP 入口的 Go 运行时控制适配

- 状态：Native 管理转接及诊断用途专项已验证；完整兼容、跨进程和平台矩阵未完成
- 范围：Native 到 Go 的私有 MCP 诊断与运行时控制

旧 Native list/call/status/stop/test/restart 曾拥有独立传输和客户端缓存。
迁移时先补齐 Go 所需能力，再替换调用点，避免静默丢失草稿诊断、停止和重启、
取消、图片及结构化工具结果。模型服务商的归档策略不限制用户配置 MCP 服务器。

增加 `zeroagent.mcp-runtime.v1`，通过 `POST /_zeroagent/mcp/runtime` 接受窄操作。
该命名空间要求非空的 Go 进程能力，在浏览器 CORS、预检和公开分享路由之前处理。
拒绝 Origin/Cookie（包括空值）、查询参数、编码路径、错误协议、额外字段、
多段 JSON 和超出 4 MiB 的请求。Native 公开代理只放行 `/v1/` 及受限分享路径，
不能转发此私有命名空间；不向 renderer 或设备公开 Go 的进程能力。

list/call 仅使用 Go 已保存的 ID 和配置，检查启用状态、选择范围和工作区。
调用必须匹配实际公布的工具；策略沿用完整工具名及通配规则。私有原始调用在
`ask` 时返回明确的审批需求，不能利用缺少会话审批上下文而默许执行。需要审批的
实际客户端调用流使用当前 Go 会话。旧 Native list/call 入口直接返回
`MCP_EXECUTION_OWNED_BY_KBRAIN`，不接收 renderer 参数建立连接或执行工具。
取消 Native Manager 的应用注册；旧传输实现暂留作兼容基准，等待兼容用例迁移后删除。

stop/restart 只改变当前运行时，不写保存配置；停用配置不能通过 restart 启用。
每次建立会话创建独立的调用 context。停止、重连、移除和关闭先取消该会话的调用，
等待这些调用完成取消通知并退出后，再进入 SDK 的优雅关闭。调用注册与取消使用同一
会话锁，等待不持该锁；在队列中等待的调用不能迁移到重启后的新会话。SDK 的取消
通知和 HTTP DELETE 清理单独限制为一秒，不改变正常初始化与工具调用预算。
普通 Agent 路径保留既有扁平输出语义，私有调用单独返回完整 SDK CallToolResult，
保留 content、图片、structuredContent 和 isError。凭据历史过滤在返回之前再应用；
schema 编码或过滤失败时不回退到原始 schema。运行时重载和关闭后拒绝旧结果。

草稿诊断使用临时 Manager，不保存草稿、不进入已保存服务器缓存。最多并行四项，
受请求和根 context 取消控制；LiveManager 关闭时取消并等待全部诊断回收，
注册与关闭共用状态锁，网络和等待不持有该锁。远端是否中止任务取决于其取消协议；
本地取消不等于外部副作用已撤销。SDK 无状态 HTTP 夹具明确启用请求取消传播选项，
远端取消断言在该能力约定下执行。操作上限一分钟，在换算 duration 前
限制输入，避免整数溢出。只对相同已保存远端及 OAuth 身份恢复隐藏请求头和引用；
改变 URL、scope、client ID 或服务器 ID 时不继承凭据。

基础阶段 MCP 90 个顶层及 20 个子项通过，两项既有自托管条件用例跳过；四项 backend
MCP/CORS 用例及 18 个子项通过。更广 backend 全包曾失败并触发原期限，单独保留。
0004 增量已在精确锁定提交依次应用四项补丁验证，改动的十份文件匹配复验来源。

当前 host 始终启用 Go 模式，旧前端工具注册表显式拒绝构建；静态调用检索未发现
其外部调用点。Native status/stop/test/restart 已转接私有协议，不回退到旧运行时。
操作捕获当前资料目录及原始后端连接，在发送前、读取期间和返回后验证账户租约、
目录、storage ID、监听地址及能力。连接通知及 50 ms 租约检查取消旧请求；
响应设限并检查协议、目标 ID 及已知私有凭据。缺少协议能力时提示后端需更新。
`test` 始终为临时草稿；`restart` 默认只重启保存的 ID，`persist=false` 为临时诊断。
两者均不保存 renderer 草稿。保留现有参数形状，OAuth 状态只按规范绑定读取。

临时 Go 诊断仅在其私有凭据桥闭包中加入 `purpose=probe`，普通运行时省略该字段。
Native 诊断授权允许保存配置的 enabled=false，仍逐项校验保存目标、身份和摘要，
不改写 enabled、不开放普通运行时授权。未知用途或非布尔 enabled 拒绝。
诊断刷新也使用相同用途、修订和目标绑定复验，沿用已有轮换恢复机制。
