# 0019：桌面规范配置快照与跨域保存

- 状态：部分实施；桌面读取与批量 IPC 已接线，Native viewer HTTP 版本协议见 ADR 0020；设备 Native 提交入口见 ADR 0022；真实设备、恢复界面及跨平台验收仍待完成
- 关联：ADR 0010、0015、0017、0018

桌面配置读取在 profile 共享边界内取得 Go settings、MCP、完整 prompts 文档和同一 SQLite 读取事务中的原生偏好。configurationRevision 绑定这些实际文档、私有 MCP 摘要、原生偏好版本、协调器命名空间和变更计数。运行状态、渲染后的指令文件不进入版本。计数防止配置改回原值后旧页面继续覆盖，命名空间防止过期页面借用另一个进程或 profile 的版本。

桌面保存使用一次 settings_save_canonical_batch。先验证期望版本并在工作副本验证原生偏好，再保存私有恢复副本，按顺序应用服务商、MCP、全局模板和项目提示词，最后提交 SQLite。Go 失败时在同一边界内补偿已尝试的域；SQLite 仍保持原值。它不是跨进程的 ACID 事务，也没有跨崩溃原子性。传输中断、无效响应或服务端错误无法证明未提交时，禁止继续读写配置并保留恢复副本，提示重启核对；不盲目发送可能覆盖迟到提交的补偿。

恢复副本属于当前 profile 的私有 settings 目录，保留最近 20 份，包含恢复服务商、MCP 私有字段与所有项目提示词所需的原值。它不是可移植导出。可移植备份继续排除机器专属工作区绝对路径和项目提示词；全局模板、非托管 MCP 配置和原生可移植偏好沿用原有约定。旧自建服务商仍只归档用于导出和回退，不注册为可选模型。

Go 的 MCP GET 会隐藏 env、headers 和 credentialRef，而 Replace 不保留这些值。Native 从当前后端根目录读取私有 MCP 文件，并核对它与运行时公开元数据一致。旧版主配置按锁定后端的 JSONC 格式和 mcp 字段读取，不能把新格式的 sidecar 当成唯一来源。公开 IPC 仅返回空值及已配置的键名；未修改的空值由 Native 按服务器 ID 与目标身份恢复。删除键或提交空对象可移除；更改 URL、命令等目标身份时不得借用旧隐藏值。未由桌面表单编辑的 workspaceRoots 与工具 policy 在相同目标的元数据编辑中保留，新服务或重命名后缺少私有值时明确拒绝。OAuth 引用只在目标及授权元数据一致时保留。此机制不代表 MCP OAuth 认证链路已经完成。

编辑器保留实际读取的版本。排队编辑只有在完整配置基线等于本窗口上一笔成功提交的预期快照时才可继承其版本，不能借用全局最新版本。失败后清除该继承关系并重读当前配置；界面偏好仍独立保存。STT 使用同一规范版本与批量入口，接收已提交结果后不再重复保存。

Native viewer HTTP 现按 ADR 0020 使用读取版本和同一规范写入服务；远程 Gateway 配置走 ADR 0022 的带版本 WebSocket RPC，实际设备端到端验收仍待完成。设备一般设置的 WebView 转存与提前 ACK 路径已由 ADR 0022 替换；真实 Native/Gateway/账号端到端验收仍待完成。多实例目录所有权、未知结果恢复、完整设备与真实 Native 验收继续待完成，不能据此宣称统一配置事务或同步发布已完成。
