# ADR 0078 工作台执行目标与定时触发

2026-11-06。桌面、设备 WebUI、CloudChat 与 Android。

2026-11-08 按用户要求收窄前端组合。环境切换回到工作台顶栏，新对话继承当前环境。桌面云端模式使用独立的 CloudChat 宿主，资料、自定义和云端计划在该宿主内打开。设备保留自身计划和权限。下面的跨环境组合记录保留为实现历史。现有计划、账户数据、设备租约、定时执行和回执协议沿用原存储，回退只需恢复前端入口。

同日移除桌面和 Web 应用轨、手机抽屉及悬停预览的「设备」入口。顶栏继续负责环境切换，设备管理从设置进入。此变更只涉及导航，回退可恢复入口，现有设置地址、设备数据与租约协议沿用原结构。

同一工作台导航组织账户资料、自定义、计划和设备。会话在首次发送后固定目标。桌面标题栏切换设备，计划表单选择执行位置。桌面定时任务直接复用任务页和原生本机调度接口，账户任务请求经 Native 传输。账户内容继续复用现有 CloudChat 组件，由 Native 保持账户和访问凭据。设备通过原接口与选择租约工作。

桌面账户工作台由 Native 携带当前桌面访问令牌直连 Gateway，Gateway 用 USA-Zero 账户接口验证令牌、桌面客户端与账户归属。桌面和 Web 以同一账户 ID 读取计划、Cloud Run 及结果。云端计划复用已登录的 Gateway 账户会话。仅有桌面登录时，Gateway 通过 USA-Zero 的桌面云端令牌交换接口自动取得该登录的服务端会话。Native 的刷新凭据留在客户端。用于续期的服务端会话受原应用登录的撤销、范围和有效期约束。

桌面页面重载时由 Native 释放上一页面的账户连接和响应流。迟到的授权结果在登记连接前核对页面代次，不能占用新页面的连接额度。

定时任务只负责计划与触发，实际执行沿用设备调度器或 Cloud Run。Gateway 持久化云计划与触发记录，用普通 Cloud Run 的私有会话引用定位当前账户执行身份。到点检查账户和资源权限。计划确认的公开主题在每次触发时作为不可变请求输入，不能把私有上下文作为公开检索输入。保留原结果核对及外部操作语义。

既有会话和设备计划保留原存储及标识。云计划采用增量数据库变更。回退关闭入口和新的触发准入，保留已产生的计划、记录和成果。验收覆盖多实例、重启、租约、切号、撤销、时区和宽窄布局，真实服务验收与本地测试分别记录。

桌面直连需要配套的 Gateway 和桌面客户端。完成 Web OAuth 和持久化存储检查后，可通过 `ZEROAGENT_CLOUD_SCHEDULES_ENABLED=true` 开启云端触发。桌面独立登录需要 USA-Zero 支持 `urn:zeroagent:grant:desktop-cloud`，已有 Web 账户会话可直接复用。关闭开关后仍可读取既有计划及结果。公开网页调研沿用 Cloud Run 的网络工具开关。

## 工作台跨端操作

已注册到当前账户且在线的设备可以提供只读计划摘要。Gateway 对每台设备复用 Cron 协议，只返回任务标识、名称、状态和下次运行时间。查看完整记录和写操作继续要求该设备的控制租约。设备离线或未响应时单独标明状态，不阻塞云端或其他设备。

桌面本机与已取得控制租约的设备 WebUI 使用同一任务页、设备编辑器及当前账户的 K-brain 调度器。Gateway 的设备摘要也读取这个调度器。常用频率编译为原调度器的 Cron 表达式，复杂表达式原样保留。写入基于设备快照版本，编辑只更新已改字段，并发扣减的次数保留。新建使用稳定的任务标识核对重复提交。

设备工作台保存前通过同一控制授权请求只读预览。调用只传草稿表达式与剩余次数，K-brain 按设备时区与实际调度器的匹配规则返回未来时间和 UTC 偏移。预览不读写任务或占用运行额度。前端绑定规则、次数和设备来源，未确认的结果不能启用保存，旧设备显示更新提示。新建需要未来匹配，已有计划可以在确认没有后续运行后继续编辑。移除适配仅撤回预览入口，已有任务存储及写入协议保持原样。

从统一任务表单切到另一设备时，现有控制授权完成后打开所选设备的新建编辑器。名称和说明通过同一窗口内的一次性意图保留，只有同账户、同设备且已读到该设备任务快照的内容页可以接收。设备时区、模型、资料和批准要求仍在各自宿主确认。此交接不写任务或产生运行。回退只取消草稿接收，已有计划和调度状态不受影响。

工作台的设备立即运行在提交前固定执行标识。设备调度器按该任务与标识持久化原有运行记录，重复准入返回同一记录。提交结果不明时仅按原标识读取，继续使用当前账户与设备的授权。设备重启后可在原运行记录保留期间查询。旧设备提示更新，回退仍可读取既有运行历史。

云端立即运行的回执通过现有账户鉴权，以任务和原提交编号只读核对。读取不准入、不扣减计划次数，也不依赖历史列表的页数。不存在匹配记录时保留提交编号，工作台仅在用户明确结束核对后解除。旧 Gateway 不支持核对时保留待查状态，不以重新提交作为兼容回退。

运行正文定位使用计划与记录的标识向原调度器读取。K-brain 只返回该计划已保存运行所对应的检查点消息标识。WebUI 沿用已选设备控制租约请求此标识。无法从当前会话核对消息时保留单次输出。

设备计划记录仍保存 K-brain 会话标识。WebUI 读取结果历史时使用设备返回的桌面对话标识承接事件、发送和队列，任务地址与草稿仍以原计划会话为键。Gateway 确认入队后由设备推进队列，运行结束和空闲入队都可触发下一轮。设备队列在取出等待项前使用引擎的会话准入状态，计划运行期间保留等待项。设备计划的停止操作按单次运行标识提交。

桌面和设备 WebUI 在原任务对话中显示本次已准入的用户消息和生成中的正文。引擎按计划和单次运行标识读取有上限的用户消息与可见助手正文，WebUI 沿用设备控制租约，断线后从最后一次成功读取的位置继续。用户消息使用准入日志与最终历史共享的标识，结果对话按该标识避免重复显示，读回正式历史后接替预览。

移除账户连接页和计划专用 OAuth 入口。新建、恢复或手动运行直接使用当前登录。增加按账户记录 Cloud Run 会话引用的表，无需复制计划、历史或成果。计划始终使用共享账户会话。会话失效时暂停并允许正常登录后恢复。预览期的计划专用会话不能作为普通登录或执行身份。

计划可以开启逐次审批。Gateway 保存待审批的冻结请求，用户可批准或拒绝该次执行。批准只适用于该次，账户与资料权限仍在实际运行前核对。等待审批不占用执行额度，也不消耗计划次数。

审批回执以账户、计划和单次运行标识读取，与已记录的决定一起保留。核对接口不会准入运行。重复提交已记录的相同决定只确认原决定，冲突决定以先记录的为准。审批决定与后来运行状态分别读取，即使批准后执行需要处理，原批准记录仍可核对。

云端计划可以选择账户项目。Gateway 在保存与触发时验证项目归属，并在同一事务内创建和关联结果会话。改选项目为后续结果选用对应的专属会话，已有会话由原入口管理。项目被删除或已关联的专属会话被移出时，计划暂停等待处理。选中每次新建对话后，可归档成功的结果会话。归档依据冻结的单次运行选项，与成功状态一同持久化，保留任务链接和成果。公开调研阶段继续只发送已确认的公开主题。

云端任务页区分启动运行与定位记录。复用同一结果对话时，收到手动运行回执后保留正文与输入区，标题栏显示等待状态直至关联 Cloud Run。手动运行结束时保留阅读位置。显式定位通过 Cloud Run 保存的用户消息标识，在当前结果对话中读取需要的较早历史，并保持当前实时订阅。无法读取原消息时保留运行记录和单次输出。

资料交接通过「发送到工作区」选择设备与该设备公布的工作区。确认页显示原件或固定成果版本和目的地。使用既有账户下载与工作区租约，原生宿主在操作专用目录发布原始字节，防止覆盖。回执显示相对路径。结果待核对时手动复用原操作编号。源资料、对话及其原执行目标保留。

浏览器和桌面远程交接均用现有的工作区选择接口。桌面原生桥核对一次性 handoff 返回的设备和工作区，将该连接限制为同一工作区的交接请求。Gateway 不接受设备级租约作为远程复制授权。桌面本机写入继续核对当前账户和设备项目。升级时 Gateway 和桌面应配套更新。旧设备控制租约、对话及工作区原有文件保持原样。

回执核对使用同一账户、设备、工作区和操作编号，通过只读请求检查设备的原操作目录。核对请求不携带文件名或内容。旧设备即使忽略新增查询标志，也会在写入前拒绝空文件名。没有匹配回执时不把操作记成失败，因为原请求可能仍在完成。用户明确重试复制时才读取原件，沿用原操作编号和原生防覆盖逻辑。

工作区 ID 在资料传输期间可能指向新目录。资料交接使用可识别的受保护地址传递确认路径，Gateway 在读取请求与发送前核对设备目录，设备以同一会话声明的能力接收并核对当前项目路径。桌面本机使用同一设备校验。确定未执行的目标变更与已发送后回执不明分别处理。交接只接受带确认路径的当前地址。能力不足的设备不接收传输，已保存的源资料和文件保持原位。回归覆盖目录改绑、能力不足、权限与当前格式的回执恢复。

上游维护只保留会话能力检查和路径校验所需的协议补丁。上游能等价验证工作区路径、在同一目标会话上阻止能力降级，并按原操作编号核对未知回执时，可移除对应补丁。以 Gateway 回环和 Windows 原生工作区测试核对这些条件。

创建交互更新。Web 打开账户任务表单，桌面默认打开此电脑表单，已连接设备工作台沿用当前目标。执行位置在高级设置，切换目标保留说明和名称。详情摘要使用同一工作台组件。复制任务链接沿用账户及设备鉴权，链接不扩大查看权限。布局改动不改变计划和回执存储，回退可直接恢复原入口。回归覆盖首次聚焦、目标切换、状态折叠、运行和跨端详情。
