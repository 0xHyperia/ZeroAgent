# ADR 0061：精简 CloudChat 会话菜单

- 日期：2026-10-31。
- 状态：按用户截图与明确要求本地实施，不推送。
- 范围：CloudChat Web 与嵌入移动视图。

移除对话页头右侧的“资料”菜单，以及“模型参数”和 Markdown/JSON 导出入口及其页内处理。
对话选项只保留重命名、置顶/取消置顶、归档/取消归档、删除、移至项目。此要求替代早期
CloudChat 页头资源聚合入口的展示决策；左侧资料空间、输入资料选择、回复成果和来源引用
仍复用原有认证资源工作区。已有账户模型参数继续用于新请求，不修改已保存数据或后端协议。

重命名复用标题行内编辑，菜单关闭不抢回输入焦点。置顶和归档复用规范会话元数据及版本检查。
删除先展示具体会话和确认框，生成期间禁用，不删除资料空间中的原件和成果。项目子菜单
显示当前账户的项目、当前归属、加载/失败/分页状态和新建项目；移动使用现有项目关联 CAS。
新建成功但移动失败时复用已创建项目重试，不重复创建；创建结果未知时阻止盲目再次创建。
所有异步结果仍受账户、当前会话和组件生命周期守卫约束。

最近会话折叠由 CloudChat 宿主显式提供状态和变更回调，按当前账户隔离；折叠不修改会话、
草稿、运行任务或服务端目录，重新展开保留当前选择和阅读状态。共享侧栏默认行为不变。

无数据迁移或清理。撤销仅恢复前端入口和呈现，用户主动保存的重命名、项目关联、置顶和
归档仍保留。验证覆盖宽窄视口菜单、行内编辑焦点、项目分页/新建后重试、删除确认取消、
最近会话折叠往返、原有 Page/请求回归、类型、设计边界和前端构建。
