# ADR 0075 复用 LiveAgent 公开模型目录

- 日期 2026-11-05
- 状态 用户确认使用上游公开目录
- 范围 桌面、WebUI、Gateway、K-brain 已有模型配置

运行期目录以 LiveAgent 定时发布的公开数据为默认来源。桌面直接请求公开 JSON，WebUI 优先访问同源 Gateway 代理，失败再访问公开地址。两端在离线或校验失败时继续使用可用缓存或内置快照。ZeroAgent 保留离线快照的 PR 更新流程。目录发布由 LiveAgent 维护。

代理仅向部署配置指定的目录地址发出公开请求。浏览器和代理均不向目录上游发送账户凭据。客户端沿用日期、结构、SHA-256 和条目校验。目录只补充模型能力与限额，模型发现、启停和调用权益仍由 USA-Zero 管理。

用户设置优先于供应商声明，之后依次为运行时目录、内置快照和供应商兜底。K-brain 只更新目录或兜底来源的限额及缺失的输入模态，走已有带读版本的配置事务。保留选中模型、模型成员、排序、启停、请求参数和账户边界。缓存和数据结构沿用当前版本，无需迁移。关闭代理时客户端仍可直读公开目录和使用本地兜底。
