# ADR 0060：本地 SeaweedFS 与完整资料空间

- 日期：2026-10-30。
- 状态：用户目标授权实施与验证；不推送、发布或部署生产。
- 目标：采用 SeaweedFS 与各类文件在线预览，完成个人资料空间的存储、整理、AI 使用、成果交付及站点闭环。

用户明确选择服务器本地磁盘，替换 R2 为默认部署方案。使用独立 SeaweedFS S3 服务和持久数据盘，
沿用 Gateway 的对象存储接口、正式文件/成果版本、认证归属、配额与备份契约。不自建另一套对象协议，
不把存储服务暴露给浏览器或 E2B；服务凭据不得进入预览器、模型、日志和公开产物。

本机部署优先采用共享私有网络命名空间内的数值 loopback 监听，保持现有明文 HTTP 的受限 opt-in，
不放宽为任意内网 HTTP。远程存储仍使用经验证的 TLS。生产配置固定审核后的镜像 digest，
持久卷独立于代码与容器可写层。启动、重建和备份必须明确覆盖该 sidecar。

正式切换以前，真实 SeaweedFS 必须验证签名拒绝、大小/摘要与元数据、重启持久性、并发条件写、
账户隔离和备份恢复。既有 R2 对象保持原位；不能仅修改已有服务的 endpoint 使原件失联，
也不能自动删除源对象。当前数据的存储迁移须具备明确清单、全量摘要验证及原引用保持，
独立测试环境可以直接采用新的 SeaweedFS 数据目录。

预览优先在浏览器完成：文本/代码/Markdown、图片、PDF、DOCX、PPTX、表格、音视频及归档目录。
旧二进制 Office、加密、损坏或不支持格式必须给出真实说明与下载入口，不能以空白页面伪报支持。
复杂版式的服务端转换为可选、受限队列，不能默认对全部上传转换。AI 阅读、解析状态和用户预览分离，
原件保存成功后即使尚未解析，也可按能力进行原始预览；不将前端预览当作模型可用正文。

公共 ResourcePreview 归 agent-ui，只接收资源描述、受控字节读取与宿主动作。Gateway/Native 客户端、
账户守卫和临时 URL 的所有权仍由宿主提供。读请求绑定资源 ID、明确版本与账户代次；取消、切号或关闭
后不得安装迟到结果。解压、页数、像素、DOM 和读取有明确上限；不执行文档宏或任意脚本，
不加载文档外链及模型构造的远端依赖。HTML/SVG 使用独立受限呈现边界，不能访问主站会话。

资料空间保留现有上传、名称搜索、筛选、列表/网格、文件夹、收藏、移动、回收站、容量及版本引用。
面向扩大容量改为数据库有界查询及稳定分页，不靠取消所有限额或无限读入快照。文件/成果仍是内容权威，
空间元数据只组织资源；不新增重复正文或另一份任务状态。多端继续使用 ADR0058/0059 的组件与适配。

生产列表使用数据库投影和每页 50 项的游标，游标绑定账户、筛选排序和事务代次。资料在翻页期间变化时要求刷新，
不保留长期数据库事务，也不把两个代次的列表静默拼接。重命名、移动和回收站按目标查询，不把整个账户读入 Gateway。
默认容量和数量维持现值，使用新的完整额度配置显式扩容；原有只配置总额的记录不自动扩大分类上限。
额度仅由持有部署数据库权限的运维命令修改，不开放浏览器或模型提额入口。额度调整与原件/成果预留共用锁，
降低限额保留既有对象、版本和引用；未知写结果先只读核对。配置和游标代次包含在正常备份恢复范围内。

站点采用账户内源码/目录成果、不可变构建包、私人预览、显式分享与发布。保存成果不自动公开。
访问授权只授予选定成果/发布版本，不能授予整个空间；发布检查清单并固化选定资源，
不把整个 E2B 工作区作为发布包。已有单文件成果与旧会话引用保持。正式托管独立于 E2B 生命周期，
不执行用户生成的后端代码到 Gateway 进程。动态站点后端能力不以静态预览冒充。

站点清单引用现有成果 ZIP 的不可变版本和 SHA-256，不复制存储对象或另外绕过额度。每个逻辑站点使用独立来源；
生产内容域与主站必须属于不同的可注册域，Gateway 内容监听只绑定数字环回，由受控反向代理提供 HTTPS。
开发 HTTP 仅接受明确启用的 localhost 场景。内容入口没有账户 API，不接受主站 cookie、Authorization 或转发 Host 作为授权。
私人预览使用短期、绑定现有会话的能力链接；分享为用户明确创建的选定版本链接，可设有效期并用版本号撤销。
链接包含受限访问能力，不写入模型上下文或日志；公开访问不因后续版本而改变目标，撤销与原件删除在缓存命中时仍生效。
静态构建包必须自带资源并使用相对基址；宏、服务器脚本、隐藏配置、node_modules 和不受支持资源不能进入发布清单。
浏览器可执行该站点的客户端脚本，但不能访问主站、远端依赖、嵌套页面或注册可跨预览持续生效的 Service Worker。
保存成果、私人预览、创建分享分开，AI 没有公共分享接口；站点源码构建及完整 AI 交付仍须单独验收。

AI 使用单独的 publish_site 工具选择已构建子目录，不能提交整个工作区、对象密钥或共享授权。
执行器固定打包源码遵守已有 VM 归属/网络/标准输入和操作日志边界，服务器重新校验构建包。
站点清单在正式成果 ready 前以同一账户、版本 CAS 和执行租约持久化，暂存清单不构成访问权限。
未知打包/对象/数据库写结果不重复执行或改换请求标识，旧单文件成果的请求指纹保持不变。

站点分类仍以现有成果家族为整理单位，从已验证的不可变版本派生私人预览目标，不增加新的正文或容量记录。
空间查询携带可用站点版本；更新暂存/失败期间保留前一可用版本。站点清单变化纳入分页代次，
账户、收藏、目录和回收站继续采用已有元数据边界，分享记录不变成资料空间的执行权威。

验收以真实 SeaweedFS、真实文件字节、生产前端的宽窄屏及全链路为准，分别记录自动测试、
浏览器与外部 E2B/模型证据。所有承诺以目标验收清单逐项核对；未完成项目不能以较小里程碑替代。
不清除或重写原用户数据；新增 schema 不要求撤销源码时删除，失败/未知写结果保留核对路径。

原件、不可变成果和桌面工作区共用现代 Office、PDF、表格及媒体查看器，读取授权仍由宿主负责；
原生缓存指纹不充当对象摘要。取消、目标/账户退休及迟到的读取或另存结果不能覆盖新目标的状态。
桌面图片高级操作、相对 Markdown、本地交互 HTML 和旧 DOC/RTF 适配保留，云端脚本边界不因此放宽。
