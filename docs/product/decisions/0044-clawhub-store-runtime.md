# ADR 0044：补齐 ClawHub 商店的当前后端接入

- 日期：2026-10-27（Asia/Hong_Kong）
- 状态：用户授权修复、自动化及运行时验证、构建运行；不推送

固定 Go 后端将所有商店请求发送到空关键词搜索，忽略目录排序、游标、数量并丢失当前
ClawHub 的嵌套版本和统计信息。页面已有浏览、搜索、缓存、分页和安装任务，不另建商店。

第八补丁仅补齐 Skills manager 和现有资源 HTTP 路由：无关键词使用公开目录，有关键词
使用搜索，保留官方排序和目录游标；搜索仍采用官方相关度及无游标语义。限制响应大小，
沿用 nonSuspiciousOnly，保留发布者身份、版本、分类、统计和更新时间。限流和审核拒绝
明确报错，不自动重试或绕过。官方过滤可能产生空页，有游标时仍允许继续。

安装沿用同一异步任务、临时落位、校验、冲突备份和内置技能保护。已选择的公开版本使用
version 参数，缺版本使用 latest 标签；发布者及 slug 构造规范下载地址，不采用卡片提供的
任意下载地址。公开 GitHub handoff 仅接受指定仓库的完整提交 SHA 和对应官方 archive URL，
只取描述中的技能子目录，继续执行现有路径/链接/体积校验。contentHash 检查格式，不将它
描述为已独立验证的目录摘要；实际内容绑定 GitHub 提交。失败和取消回收本次临时下载。

前端只调整规范来源链接、安装时的版本参数，不重做上游 UI、缓存、执行器或协议。Desktop
和设备 WebUI 复用同一 Go 能力；Cloud Chat 的本地工具限制、账户隔离和凭据边界保持。
当前和旧用户数据不迁移、不删除，测试安装仅进入可销毁的测试账号目录，第三方技能不调用。

验证包含本地 TLS 注册表的目录/搜索/排序/分页/元数据、版本下载、真实 ZIP 安装、异步进度、
取消、限流/审核错误、不完整响应及固定 GitHub 子目录。另显式启动 Native profile manager、
公开 facade 与实际两端资源适配器，对公开 ClawHub 验证下载安装、重启和第二账号隔离。
网络项明确 opt-in，不能用离线跳过替代本轮实际结果。

本项分类为 adapt。上游固定版本具备同等官方契约和运行时保证、同组回归通过后撤销该
补丁，优先复用上游实现；不为本项更新依赖 pin 或同步未发布分支。
