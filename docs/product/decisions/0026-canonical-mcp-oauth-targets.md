# 0026：OAuth 凭据绑定 Go 规范 MCP 目标

- 状态：Native 目标解析、提交边界与兼容记录已接线；Go 凭据桥接及完整执行验收未完成
- 范围：ADR 0025 的授权与状态命令，不替换 Go 的 MCP 执行器

前端传入的服务器只作为读取时的目标声明。Native 从当前 profile 的 Go `/v1/mcp` 读取
实际服务器，复用规范配置的私有文件读取及运行状态一致性校验。目标必须是唯一的已保存
ID、HTTP transport 和 OAuth 鉴权；URL、scope、Client ID 与声明不符即拒绝。当前锁定 Go
只接受字面值 `http`/`stdio`；这里不把旧 Native `sse` 值冒充已支持的新配置。
SSE 迁移与 Go HTTP transport 的实际兼容能力继续属于执行桥接验收。

操作捕获实际 URL、scope、Client ID、私有 credentialRef 和请求头。凭据完成换码后，
最终目标复查与凭据版本保存共用 profile 配置锁，配置写入不能插入二者之间。浏览器
等待和 token HTTP 不持该锁。所有通过规范 Native 客户端发起的 MCP 配置修改尝试递增
独立代次；等待期间即使改完再改回，原操作也不能提交。该代次有意覆盖整个 MCP 文档，
所以等待期间编辑另一个 MCP 或显示描述也会要求重试；无关设置修改不会取消授权。

新凭据增加可选的 `target_binding`，摘要绑定稳定 storage ID 和实际目标，不包含监听
端口或后端运行令牌。原 keyring 服务、条目 ID、文件位置与旧记录字段保持兼容。缺少摘要
的旧记录仍保留供回退及重新授权复用 client 信息，不能据此显示为 v2 目标已授权。
修改 scope、Client ID、URL、credentialRef 或请求头后，旧记录同样保留并要求重新授权。
已完成凭据的摘要不依赖描述、启用开关或当前操作代次，正常重新读取不会因显示元数据
改变而失效。真实启用与工具执行仍需尚未接通的 Go 桥接，不能用摘要相等替代执行证据。

状态只返回元数据；token/client secret 的直接反射即使位于 issuer/scope 字段也被去除。
目标错误使用固定标记与可读提示，不输出 URL、私有引用、请求头或凭据。断开授权仍按
捕获的 profile/server ID 清理，允许删除服务器后清除残留凭据；它也取得配置锁，并由
条目版本使等待中的授权失效。

回归结合锁定 Go、实际私有 MCP 文件及本机 OAuth 发现/回调/token 端点，覆盖过期前端
目标拒绝、旧记录保留、新摘要保存、状态脱敏、无关设置不取消、MCP 修改代次、私有引用
修改、换码期间 URL/scope/Client ID/引用/请求头修改、删除以及目标改回。所有凭据均为
临时文件夹具。独立进程绕过、真实 OS keyring、注销与保存的最终提交线性化、未知结果
恢复、Go 凭据桥接及完整过期/401/SSE/浏览器取消链路继续待完成。
