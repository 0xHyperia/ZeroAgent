# 0025：MCP OAuth 操作绑定 profile 与凭据版本

- 状态：Native 存储与操作生命周期已接线；Go 执行桥接和完整验收未完成
- 范围：桌面 MCP 授权、状态、断开授权与 Native 刷新服务

既有 MCP OAuth keyring/cache ID 已包含 profile 目录与 server ID，继续保持其 SHA-256
派生和 `ZeroAgent MCP OAuth` 服务名。授权开始、浏览器回调和刷新保存不能分别读取当前
profile，也不能让同一 profile 的两个服务通过文件读改写覆盖彼此的凭据。

Native 命令在进入阻塞任务前捕获 profile 存储句柄与当前执行后端连接。捕获目录时使用
profile 激活的同一把锁；打开浏览器、换码前和保存前重新检查 profile 权限及连接。句柄
的后续读写只使用捕获目录，不能因切号改写另一个 profile。授权互斥、可疑 client 标记
和刷新单飞也使用原有 profile/server 身份，不再仅按 server ID 共享。

同一进程、同一 profile 的存储读改写使用共享短锁。浏览器等待和网络请求不持该锁。
每次保存必须匹配操作开始时捕获的条目版本；断开授权、并发保存以及失败的保存尝试
都会使旧操作失效，迟到回调或刷新不能重新建立已删除的凭据。主动刷新失败后的回退
重新读取当前记录，不能直接返回局部变量中已被断开授权的旧 token。状态中的存储类型
来自当前条目，避免被另一个 profile 的最近一次访问改变。

文件降级仍只位于该 profile 的私有设置目录。读写设置 8 MiB 上限；读取或解析失败不会
解释为空表。保存通过同目录临时文件、同步和原子替换发布；Unix 发布前设置 0600，
Windows 继续依赖 profile 目录 ACL。删除失败向调用方报告，不缓存为删除成功。
这些改动不修改旧凭据内容，不导入其他产品凭据，也不把 token 放入设置或备份。

读取优先采用存在的 keyring 条目；keyring 不可用或恢复后没有该条目时，继续读取当前
profile 的降级文件，不能把后者误当作未授权。有 keyring 条目时不读取损坏的降级文件；
没有条目且降级文件损坏时仍报告错误、保留原文件。后续成功写入 keyring 再清理降级条目。

回归使用临时目录及真实 loopback 发现、回调和 token 端点，覆盖换码后权限失效、刷新时
清除、并发刷新只消费一次 grant、同名服务器的双 profile 隔离、并发文件保存、陈旧版本
拒写、损坏文件保留及原子替换失败。它们不等同于真实 OS keyring 或浏览器验收。
Windows 夹具显式把接受的套接字切回阻塞模式后使用原有有限读写期限，避免继承监听
器的非阻塞模式。工作线程失败仍使测试失败；已有断言正在展开时，清理不再触发第二次
panic，以免中止整个测试进程并丢失原始失败。

后续另以独立合成条目显式运行 Windows keyring 存储回归，覆盖真实无条目读取、降级文件
恢复、迁入 keyring、清除缓存后重读、删除及确认无条目。它不读取真实用户凭据；此项是
正常存储路径的 OS API 验证，不能替代 keyring 故障、真实账号或浏览器授权的验收。

后续 Native 目标绑定见 [ADR 0026](0026-canonical-mcp-oauth-targets.md)：前端目标参数现在
只是声明，授权和状态先解析 Go 实际目标，最终目标检查与保存共用配置锁。
锁定 Go CLI 尚未接入 Native 凭据桥接，不能据此称 v2 OAuth MCP 已可执行。
跨进程存储协调、真实 keyring 故障、refresh 轮换后持久化失败恢复、注销与保存最终
提交的线性化、取消浏览器等待及完整 401/过期链路继续列入后续验收。
