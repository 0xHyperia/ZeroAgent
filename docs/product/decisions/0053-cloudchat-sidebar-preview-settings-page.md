# ADR 0053：折叠侧栏预览与设置页面

- 日期：2026-10-29。
- 状态：按用户要求本地实施，不推送。
- 范围：CloudChat；共享 Sidebar / SettingsShell 增加显式可选展示参数，默认设备与 Desktop 行为保持。

用户要求折叠后的侧栏可以像 ChatGPT 一样悬停出现，设置参考当前 ChatGPT 的页面形式。
实际参考页 `/settings/general-settings` 保留应用轨，以设置分类替换聊天侧栏，右侧显示内容。
因此替换 ADR0050 沿用全内容区设置覆盖层的展示实现，改为编辑宿主内的正常页面布局。

侧栏固定展开仍由原 SidebarProvider 管理并持久化；悬停预览是当前账户的临时状态。
预览复用同一历史实例和零宽侧栏占位，不改变画布宽度或 sidebar_state。
鼠标进入首页按钮、侧栏边缘或展开按钮区域后短延迟显示；离开后延迟收起。
允许移入侧栏、键盘操作、会话菜单与搜索窗口；Escape 先由内层处理。
预览内点击展开按钮才固定。触屏沿用 Sheet，不模拟 hover；固定/账户/设置/布局变化清理旧预览。

设置时聊天树继续挂载但隐藏并 inert；编辑器、草稿和运行订阅保留。
应用轨和单一账户菜单继续可达；设置分类复用真实注册表、搜索及权限边界。
浏览器后退可离开设置，分类变化更新既有 settings 查询参数，深链接继续有效。
手机使用分类列表/详情单列页面，返回分类与返回对话分开，避免横向挤压。
没有新增后台执行、权限、模型模式、用户配置迁移或清理。

2026-10-30 按用户要求统一 CloudChat 设置侧栏风格：与聊天/资料库共用页面背景、272px 宽度、
标题字号以及导航项的间距、圆角、hover/选中/焦点规则；搜索保留独立的轻底输入表面。
修改限定在 CloudChat 宿主样式，不改变默认 Desktop/设备设置外壳、分类权限和手机列表/详情交互。
没有持久化或数据变更；回退仅需撤销这一组宿主样式，验证既有设置导航和宽窄屏呈现。

验收包括预览移入/移出、菜单与 Escape、触屏不触发、状态/账户重置、同一 DOM 与持久化不变；
设置正常流布局、手机分类返回、浏览器后退、草稿与已有 Run 不重建/不取消；
共享默认行为、三端类型、契约/边界、生产构建以及真实浏览器视觉验收。
具体已运行项和限制记录于根 `design-qa.md`，不替代移动真机或外部执行验收。
