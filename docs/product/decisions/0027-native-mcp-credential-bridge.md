# 0027：Native 与 Go 的 MCP 凭据桥接

- 状态：Native 宿主、进程接线和 Go 源码适配已通过本机候选跨进程回归；发布启用及完整平台验收待完成
- 范围：锁定 K-brain 源码 1f27ade557fe268c76853f83f4fb7aa32d078eac 的窄适配

继续由 Go 执行 MCP 和 Agent，不恢复第二套 Native 或前端执行循环。Go 在构建服务器时
捕获实际目标，在每次 HTTP 请求前向 Native 私有宿主取得 Bearer；401 只重试一次，携带
被拒绝 token 的 SHA-256，重用已经轮换的并发结果。重试保留 RPC 正文与 ID，不重放没有
GetBody 的非重放请求。宿主错误不进入工具结果；请求取消保持取消语义并释放未发送正文。

私有协议为 zeroagent.mcp-credentials.v1，固定 POST /v1/mcp/credential。目标含 ID、
transport、URL、scope、clientId、credentialRef 和保存的请求头，不含配置目录或账户参数。
宿主单独监听数字 loopback，使用独立随机能力，拒绝浏览器 Origin/Cookie、错误协议、
非绑定目标和失效 profile。Go 从环境读取能力后，在初始化工具和 stdio 子进程前清除环境。
普通后端能力或设备/Gateway 凭据不能访问该宿主。

Native 从固定 profile 的实际私有 MCP 文件核对目标与已完成凭据摘要，要求该服务器启用；
不回读 Go HTTP，也不重入可能由 Go 配置替换持有的配置锁。它检查 MCP 修改代次、profile
权限、运行状态、条目版本及最终记录。刷新不弹浏览器，不返回未成功保存的轮换结果。
并发请求有有限槽位；退出停止监听并撤销等待中的权限，AS 请求返回后再次检查权限。
保存失败的刷新轮换由 Native 有界内存表持有并优先重试保存，见 [0028](0028-retained-mcp-refresh-rotation.md)。
最终持久化与账户注销的完整线性化和跨进程协调仍需继续验收和适配。

Go 的宿主客户端不走代理或跟随重定向，校验协议、响应大小和 Bearer 字节。MCP 请求
限制为配置的同源地址，适配客户端不跟随重定向。已知 Bearer 在响应状态、头及流式正文
中脱敏，包含跨分片和 JSON 转义；该过滤不是任意编码秘密的识别器。Streamable HTTP
的 JSON 和 SSE 响应使用同一机制。后续 0003 增加 LiveManager 生命周期内的有界凭据
历史，跨请求、重连和配置重载保留；4096 个值或计入原值/模式的 8 MiB 达到上限时，
在发送新 Bearer 前拒绝并要求重启后端，不驱逐旧值。流式读取不持网络等待锁；复制给
消费者前重新检查全部未发布原始字节，按完整匹配区间的并集遮蔽前缀及重叠 token。
SDK 解码后的工具结果在截断前再次过滤，工具描述、schema、错误和指令也过滤已知值。

旧字面值 sse 现在由 Go SDK 的实际 GET/POST SSE transport 适配；初始化仍保留原期限，
GET 的生命周期由连接关闭管理，不能被初始化函数返回时取消的短期 context 提前终止。
专项 SDK 回归覆盖 POST 401 时已打开的 GET、刷新后输出、重载、清除后拒绝、所有权
取消、跨源 endpoint/重定向拒绝及启动挂起取消。此项已通过 Go SDK 专项，
完整 Go MCP 包已通过 82 个顶层及 5 个子用例，两项显式自托管用例此前单独通过。
0002/0003 已加入本地候选构建清单。新候选的 Native 跨进程旧 SSE 用例通过，覆盖
Native 401 刷新、旧新凭据脱敏、重启复用、清除后不转发和进程退出后关闭 GET。
Native 目标摘要保留实际 http/sse 协议，拒绝跨协议复用；授权绑定 4 项回归通过。
备份恢复和设备设置已原样保留旧 sse 协议，候选补验覆盖备份往返、设备提交和公开快照脱敏；应用内置 sidecar
尚未替换，发布路径与完整平台验收仍待完成。

Native 只有在编译时捕获的适配产物能力记录与实际二进制 SHA-256 相符时才注入宿主能力。
未适配的锁定下载不接收新能力。宿主随后端停止或崩溃回收；能力进入原有 Native 私有
授权守卫历史，不增加公开 IPC。stdout 读取线程独立持有撤销守卫，EOF、读取失败或线程展开
即撤销宿主，不等待 manager 再次查询。实际候选回归覆盖强制终止后端后宿主拒绝访问。
当前工作区仍使用原锁定下载，候选只在隔离目录构建、准备及执行，尚未装入应用。

源码补丁和清单位于 patches/kbrain/，保留精确基准、补丁 SHA、能力协议和不同的产物来源
zeroagent-patched-source。构建先验证并快照补丁字节，再向独立精确 checkout 应用，避免
校验后源文件变化。准备器要求相同显式清单，保存完整来源，不把适配产物标为 locked-download。
包装验证同样要求显式清单并校验实际补丁字节、完整来源回执和二进制摘要，结果保留补丁
来源，拒绝把适配记录伪装为下载来源。发布/CI 的适配启用尚未配置，现阶段只允许显式候选构建和准备。

OAuth 的 AS 错误只输出数值状态、白名单错误码与固定提示，不回显描述、正文、端点或
解析值；响应读取上限 1 MiB，出站不跟随重定向。此项覆盖授权管理的错误通道，不能替代
真实 OS vault、浏览器、设备和所有秘密绕过入口的完整验收。

验证分别记录 Native 宿主、本机 AS、Go MCP SDK、源码产物及真实跨进程回归。既有显式
条件测试保持可见，候选专用 Native 回归单独运行，不用旧二进制或跳过计数证明桥接完成。
本机候选已覆盖启用 OAuth 服务器启动、首次 401 刷新、实际工具调用、结果脱敏、清除后拒绝
及异常退出撤销；后续增加主动过期刷新与持久化后重启复用。整批存在 READY 超时，单项
同预算复验通过，Windows 稳定性仍待解决，详见同步报告。测试使用临时 profile 和本机授权端点，不代表真实账户、OS vault、浏览器
或已打包桌面应用的验收。
