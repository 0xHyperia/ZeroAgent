# ADR 0082 桌面文件工具统一按需安装

- 日期 2026-11-26
- 范围 Windows x64、macOS Intel / Apple Silicon、Linux x64 桌面发布与设备文件工具
- 延续 ADR 0081 的安装、停用、诊断、重装和移除契约

主应用携带固定版本和架构的工具清单。各目标的发布流程从锁定的来源构建一个独立文件工具 ZIP。用户从「系统设置 → 工作区工具」或原阅读器提示进入准备流程。Beta 和正式版可以从设置下载，Alpha 和 RC 通过当前发行版的 ZIP 导入。用户准备期间继续阅读和编辑批注。设置和窄窗沿用同一控件。其他客户端按已授权执行设备展示就绪状态。

Native 在应用私有目录内校验包大小、SHA-256、目标和逐文件清单。POSIX 归档仅恢复用户的普通执行位。新版本通过自检后等待重启启用，安装失败保留可用版本。停用保留工具，移除只清理应用管理的工具目录和部分下载。既有配置、项目、批注和用户选入的包继续保留。应用回退可使用已验证的旧包或重新选择旧 Release 的匹配包。

验收要求逐目标验证独立 ZIP 的离线 Word 改稿、PDF 改稿与导出，确认主应用载荷省略工具目录，校验更新签名并检查本机、浏览器和远程桌面共用的就绪与批注流程。发布候选必须通过同一提交的 CI。
