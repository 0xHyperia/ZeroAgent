# ADR 0074 编辑重发在当前会话生效

- 日期 2026-11-05
- 状态 用户授权实施
- 范围 Windows/macOS/Linux 桌面、设备 WebUI、Cloud Chat WebUI

用户选择编辑重发时，替换稳定消息引用所指的用户消息，并从该位置移除后续会话历史。用户可从消息菜单另行创建分支。编辑器在提交按钮旁说明截断效果。当前会话 ID、此前消息及 ID、项目关联和独立输入草稿继续有效。

桌面及设备 WebUI 使用 LiveAgent v2.0.8 的 K-brain 历史替换和发送前置流程。Cloud Chat 在既有任务准入事务中比较用户所见的最后一条消息，并在账户、会话和任务状态校验后，原子提交历史截断、替换消息、任务及其回执。重复请求命中原回执，过期历史、冲突、排队失败和请求回滚保留原历史。已结束任务的执行回执及资料库中已交付的独立成果照常保留。

该决定更新 ADR 0048 的编辑重发规则。分支接口只接受显式分支请求。
