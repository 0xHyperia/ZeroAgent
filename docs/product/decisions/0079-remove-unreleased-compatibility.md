# ADR 0079 清理未发布版本的过渡代码

以 ZeroAgent v0.3.23 为正式发布基线。此后尚未正式发布的实现可以直接收敛到当前格式。记录产品变更时同步维护根目录的 CHANGELOG.md，正式发布前的变更归入 `[Unreleased]`。

本次按需要单独回归的行为或存储边界统计了 20 项。

| 范围 | 数量 | 清理项 |
| --- | ---: | --- |
| Web 与桌面账户页面 | 1 | 临时对话、设置、资料和技能 URL 别名 |
| 资料交接 | 2 | 无目录确认的旧 HTTP 地址。只保存编号或缺少确认路径的回执格式 |
| 云端执行和对话 | 3 | 定时任务专用会话与授权表。运行正文的临时分块补接。编辑和重试的分支提交路径 |
| Gateway 数据库 | 5 | 文件、项目、运行、定时任务和资料限额试验表的中间列升级脚本 |
| 插件和技能 | 4 | 内置包的未发布定义。内置成员的旧名称别名。独立技能的成员开关。未指定类型时的包分类推断 |
| 研究来源 | 2 | 来源快照的页面列表、正文和删除接口。带行号的会话引用及任务链接 |
| 桌面运行时 | 3 | K-brain 早期会话映射。未接入运行时的供应商导入辅助代码。未接入运行时的 MCP 导入辅助代码 |

桌面与 Web 使用当前路由、确认路径和账户登录。公开来源只在对应对话或任务提供原网页入口。Gateway 直接创建新增表的当前结构。v0.3.23 正式会话、公开接口、显式会话导入与正式设备协议继续适用。个人技能的固定修订仍用于当前执行和阅读。

既有数据留在原存储。只创建过中间结构的预览数据库不在升级路径内，应在独立开发库验证当前结构。继续运行现有调度需要当前账户的有效执行会话。旧专用授权不能作为浏览器登录或执行凭据，交接继续核对账户、设备、工作区及确认路径。

回归覆盖当前路由、会话分支、来源归属、回执恢复、扩展启停、计划准入及当前内置工作流。正式数据库的新增列及账户授权校验仍按现有产品契约验证。
