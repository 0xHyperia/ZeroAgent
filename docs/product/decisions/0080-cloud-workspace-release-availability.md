# ADR 0080 公开版云端工作区开放状态

## 决策

桌面、Web 和 Android 使用同一套原有云端工作台组件、导航、顶栏及执行位置菜单。每次进入停用的云端工作区显示一次通知，页面切换继续使用原有导航。插件和技能通过原目录展示内置元数据，可搜索、筛选并查看公开简介。直达详情的链接打开目录，完整内容和操作仍停用。停用状态不读取账户的云端内容。用户通过设备菜单切换到本机或已授权的电脑。保留云端代码、路由、账户资料和已有草稿。

公开 Gateway 默认关闭云端，通过不可缓存的开放状态告知各端。只有显式配置 `ZEROAGENT_CLOUD_WORKSPACE_ENABLED=true` 才注册云端数据与操作接口，并启动云端执行、计划、文件解析和站点服务。关闭时拒绝旧客户端申请的云端执行租约，也不接受既有的云端租约。登录、设备发现和控制沿用各自的鉴权与租约；账户凭据操作仍可用于设备设置。

开放状态接口不可用或未返回有效的公开目录时，客户端以随构建提供的内置插件和技能清单显示公开简介，云端保持关闭。

停用状态允许切换空白会话的「对话／工作」布局，并保留导航、设备选择和桌面窗口控制。桌面客户端选取「此电脑」时返回原本机工作区。

## 验收

用关闭和显式开放两种配置核对 Gateway 的接口、租约和设备发现。从桌面、Web 和 Android 检查进入与重返云端的通知、目录搜索筛选、公开简介、详情直达地址及设备切换。Android 断网时也不得从缓存恢复可操作的云端页面。

Gateway 回归覆盖关闭时的云端读写、旧云端租约、技能详情，以及已授权设备的发现和选取。Chromium 使用本地 Gateway 和模拟账户，在 1440px 核对进入提示、原工作台导航、目录搜索和公开简介，在 390px 核对进入提示和设备选择。独立回归验证打开简介不读取完整正文。原生桌面、Web 和 Android 使用同一台真实设备的联验待补。

开放状态接口返回 HTTP 404 时，同一工作树的桌面前端和 Web 构建通过。Chromium 用该 Gateway 响应和模拟登录，在 1440px 从「自定义」打开插件与技能并搜索，在 390px 查看技能简介并选择设备。两种布局都未请求账户的云端内容。

同一场景在 1440px 用鼠标、390px 用触控切换到「对话」，再用方向键切回「工作」，焦点跟随选中的按钮。桌面组件回归验证云端页内挂载的设备菜单可选择「此电脑」，窗口控制回调仍可触发。

「自定义」和「定时任务」在 1440px、390px Chromium 均只显示一个当前页顶栏设备入口。Android 15 x86_64 调试版已覆盖安装至模拟器，在 412px 原生 WebView 用内存中的模拟账户点按两页的 44×44 CSS px 设备按钮，均打开设备列表，返回事件关闭列表。模拟器原用户的加密会话状态无法解析，保留原数据并在核验后恢复正常启动入口。

改用对话顶栏后，480px Chromium 内嵌桌面构建在对话、自定义和定时任务保持设备按钮位置和尺寸一致，每页只有一行顶栏。独立 Web 构建在 390px 和 1440px 复验三个入口。模拟器安装正常登录的调试版并确认显示登录页，账号验证由用户完成。原先损坏的加密会话文件已移入应用私有备份目录。
