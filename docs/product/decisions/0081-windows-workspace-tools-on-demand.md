# ADR 0081 Windows 工作区工具按需准备

- 日期 2026-11-25
- 范围 Windows x64 桌面安装包、便携包和设备文件工具

Windows x64 把文件工具从主安装包移到独立交付包。基本应用、登录和只读预览可在安装后使用。用户从系统设置或缺少工具的文件任务进入准备流程。准备完成并启用后，本机文件处理继续支持离线执行。Windows 沙箱与应用权限沿用各自的原生入口。

发布清单随对应的签名应用构建，固定目标架构、运行时版本、下载地址、大小和内容摘要。Native 负责从固定来源下载或从明确选中的离线包读取，验证成立后在本机私有目录完成初始化。安装失败时保留上一个可用版本。应用使用单一版本的文件工具绑定，用户经既有退出流程重启后启用新版本。移除软件或回退应用时不迁移或删除账户、项目、草稿和用户文件。

本机 Windows 设置可启用、停用、诊断、重新安装和移除。停用保留已安装版本，工具绑定在重启时生效。确认移除后原生宿主持久化待处理状态，重启时在安装锁和运行使用锁的保护下清除托管版本与部分下载，完成后保持停用。清理失败可在下次启动重试。清理范围以应用管理目录为限，拒绝重解析点和受保护的名称。原本的离线包、用户文件及账户数据会保留。

Windows 包的 Python、Office、PDF 与 OCR 依赖由受审核的独立上游取得并锁定。新包通过现有文件工具提供 Word、PDF 和标准表格与演示文稿操作。要求 Artifact Tool 专有接口的功能按当前绑定判断。现有完整运行时仍能提供先前能力，macOS、Linux 和 CloudChat 沿用各自的工具交付。设置与阅读器按实际执行设备显示状态，设备 WebUI 沿用租约内的只读查询。

发布验收从干净的 Windows x64 安装开始，记录包大小、首次准备、错误恢复和实际 Word 与 PDF 操作。另用断网验收核对初始化后的工具和之前版本的可用性。三入口复验记录同一台电脑、会话和文件，检查草稿、焦点、切换设备及租约撤销。任何本地真实组件解包需使用单独授权的隔离环境。
