# ADR 0068：CloudChat 自定义工作区与账户技能

- 日期：2026-11-05（Asia/Hong_Kong）
- 状态：用户已在前一开发会话授权实施；本地实现及验收，不推送或发布。
- 范围：CloudChat Web、Android 所嵌入的响应式 Web；共享展示组件。

## 用户流程与范围

按照 `docs/design/cloudchat-extensions-ux.md` 建立“自定义 → 目录 → 详情/管理 →
技能文件 → 原对话草稿”的连续流程。账户可创建、编辑、上传、下载、启停和卸载指令技能。
Product Design 与 ImageGen 使用真实内置工作流及既有云端工具，不连接 ChatGPT 私有插件服务。
Product Design 分为研究、审查、方向探索、实现、验证、分享与技能创建等具体指令。

本次实现前两阶段及工作流指令拆分。第三方 MCP/OAuth 连接、含工具依赖的插件包安装更新、
设备 Hub 的统一界面及真实外部服务全闭环仍是后续工作，不能宣称全部插件能力或多端行为等价。
原有设备 Skills/MCP 入口、执行器、凭据、审批与设备授权保持。

## 存储、版本与执行

新增 `zeroagent_cloud_extensions`，以账户 ID 为主键，文档版本通过 PostgreSQL CAS 更新。
本轮只支持小型 UTF-8 指令包，文件直接存入有界 JSONB，不增加另一套对象服务：最多 100 个
持久包记录、每包 20 个不可变修订、64 个文件、每文件 64 KiB、每修订 256 KiB、账户文档 8 MiB。
ZIP 在内存校验，不解压到服务器目录、不自动执行文件；拒绝越界路径、链接、重复路径、二进制和超限。
卸载仅撤销后续可用性，保留修订、历史、草稿与成果；记录仍占上述存储上限。

引用使用 `zeroagent-skill:PACKAGE/VERSION/NAME`，不从同名技能猜测包。更新不替换草稿和历史
中的旧版本。多个同名包或相互冲突的固定版本明确拒绝；版本不存在时不静默使用新版。
内置包的版本是应用拥有的发布定义，修改其内容时必须维护版本定义，不能保持同一版本号冒充旧内容。

既有 Go Run 仍是唯一云端工具循环。每次执行读取账户安装状态并保留执行期间的目录快照，
只向模型提供名称、说明、包 ID 和版本；正文与附属文本通过 `read_skill` 按需读取。
技能不授予新工具、任意外部披露或本机权限。ImageGen 的安装/启用状态同时约束工具公告与实际调用；
目录读取失败不回退到默认启用工具。固定 USA-Zero 生图模型、未知不重发及不可变成果沿用 ADR0067。

## 界面与失败恢复

自定义工作区按需加载，进入后保持聊天树、编辑器、运行和原草稿挂载。共享展示组件仅依赖宿主适配器；
账户 API 使用当前账户守卫，切号清理读取，旧响应不能回填新账户。试用只准备引用/文字，不自动发送，
延迟回填绑定点击时的原会话。同一技能已有固定版本时不插入另一个版本。

桌面采用上下文侧栏、双列目录与文件阅读窗口；手机为单列目录、全高阅读、44px 文件菜单及底部
会话选择面板。技能正文独立滚动，不覆盖底部操作。目录、搜索、已选勾选与移除复用同一结构化草稿。

保存/上传的网络失败、5xx 或无效成功回执视为结果未确认，禁止继续写入，直到成功刷新目录。
在未知写入前启动的旧读取不能解除限制。编辑内容保持；更新冲突可比较最新版本，新建冲突先检查
目录中已创建的技能，再明确准备新建，不自动重复请求。4xx 明确拒绝可修正后提交。

## 数据与验证边界

不迁移、不清除已有数据；正常数据库全表备份包含新表。撤销源码不主动删除包或修订。
验证分别覆盖 Memory/PostgreSQL CAS、账户隔离、HTTP/跨站拒绝、上传校验、固定版本解析、
启停及直接工具调用、未知写入限制、编辑失败保留和实际 Web 桌面/手机操作。
本地合成技能验收不代表真实第三方连接、Android 原生输入法或全部设计工具执行已通过。
实际证据和全量回归遗留问题记录在 `design-qa.md`。
