# ADR 0063：项目设置弹窗替代整页管理

- 日期：2026-11-01。
- 状态：按用户截图与明确要求本地实施，不推送。
- 范围：CloudChat Web 与共用前端的移动视图。

移除旧 CloudChatProjectsPanel 及项目管理整页路由组合。项目行末设置入口直接打开项目设置
弹窗，项目标题/查看全部入口打开可搜索、分页的项目目录弹窗，选择后进入同一设置弹窗。
底层对话、阅读位置、草稿和 Run 不因打开设置改变，不再用资源页包裹项目表单。

复用共享 Dialog、Popover、AlertDialog、Input 和按钮规范。设置包含名称、图标/颜色、项目
说明和项目指令；说明与指令仍分别保存，不合并或覆盖已有内容。图标和颜色使用有限目录，
可搜索和键盘操作，在服务端按账户与项目 CAS 保存；遗漏外观字段的现有调用保留已存值。
PostgreSQL 只添加带默认值的 icon/color 列，现有项目默认文件夹/默认色，无数据清理或旧版
配置迁移。内存存储执行相同验证，外观不改变模型权限、项目指令执行或资源访问范围。

项目资料在同一弹窗的独立内容区管理，保留受认证的资料列举、分页、关联/解除关联和统一
预览入口。解除关联不删除资料原件，项目删除需明确确认，仅解除会话归属并保留会话原件。
保存失败保留编辑；409 后显式重新读取版本，仍保留本地输入。关闭、预览跳转和移动端返回
遇到未保存修改时要求明确放弃；提交中不关闭或重复提交。过期账户、组件或项目读取结果
不能写入新上下文。移动端返回先关闭图标菜单/删除确认，再处理设置与未保存确认。

不展示未实现的项目记忆策略或资料空间权限开关；既有显式全局记忆不变。该决定替代早期
项目浏览整页的呈现方式，保留项目持久化、资料引用和会话归属协议。回归包括保存/CAS、
旧调用保留外观、账户隔离、资料原件保留、移动端返回、对话草稿/任务不变及宽窄屏弹窗。
