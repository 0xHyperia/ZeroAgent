# ADR 0041：beta.23 记忆、生图与显式导入适配

- 日期：2026-10-27（Asia/Hong_Kong）
- 状态：用户授权本地合并 LiveAgent v2.0.0-beta.23；不包含推送或发布

采用 beta.22、beta.23 的记忆总开关、生图模型开关、Agnes 参数、会话存在性批量查询和
窗口首次定位。模型执行仍只有固定 K-brain 后端；现有四个 MCP 补丁不增加兼容行为。

记忆总开关属于 K-brain，和 Native 的记忆整理设置分开。设备快照从同一份规范后端读取
投影 `kbrainMemory`，写入映射回后端 `memory`，沿用当前 profile 的配置 gate、读取版本、
CAS、失败补偿及落盘回执。共享开关传回实际展示时读取的版本，不临时借用最新 GET 绕过
冲突；读取失败、保存结果未知与跨实例通知沿用上游行为。失败补偿同时恢复记忆开关。
上游独立写入辅助函数不接生产入口，避免形成第二套不受版本约束的配置通道。

远程记忆命令采用上游 Go 资源，通过现有 Native 公开 facade 处理账户失效、取消与输出
脱敏；异步响应绑定接收请求的原 WebSocket 流，不向切号后的新流发送旧结果。

平台供应商允许已有模型的生图自动识别、开启和关闭，保留固定地址、凭据及平台权限。
采用上游去除图像目标额外验证步骤的实现，仍拒绝启用未完成的适配器或停用连接下的目标。
单模型缓存字段仍按固定后端的实际 schema 投影，不因合并恢复无法保存的表单。

旧会话签名、完成标记和批量存在性查询只服务显式旧 ZeroAgent 会话导入。沿用 ADR 0035
的固定只读来源、幂等和账户归属，不激活启动自动导入，不导入其他产品或旧供应商配置。
现有模型选择双视图、默认折叠和 Desktop/WebUI 刷新入口保留。

不改旧数据布局或回退策略，不清除用户数据。验证范围、失败诊断和未验平台见 beta.23
同步报告；撤销通过 Git 恢复集成前源码，不主张旧版本可读取新增数据。

2026-10-27 桌面生图验收补充：Native facade 必须在 CORS 和请求转发中保留上游标准
`Idempotency-Key`；托管代理只增加当前平台绑定下的图像生成、编辑精确路由及已有 `/v1`
前缀规范化，不开放任意 API、地址或凭据。回归使用本地模拟供应商和真实固定 Go 后端，
覆盖浏览器预检、创建任务、重复请求去重、最终图片读取及账户 API 仍被拒绝；真实平台的
收费生成由用户手动验收，不在自动测试中提交。

同日后续验收发现固定 Go 后端的删除规则遗漏 `result_unknown`，导致 UI 已结束记录永久
返回忙碌。以第五项最小源码补丁复用现有终态函数；真实执行 lease 仍阻止删除，任务不被
改写为成功/失败，不自动重试或取消平台请求。记录采用既有软删除及请求收据，保持账户
范围和删除后去重。Desktop 及连接该设备的 WebUI/Android 共用同一后端；无存储格式变化、
旧数据修复或清理。上游提供等价修复并通过同组回归后撤除此补丁，撤销只恢复源码。

按用户同日追加要求，Desktop/WebUI/Android 共用上游尺寸弹层的比例网格、分辨率和宽高
区域。原生枚举尺寸按后端 `ParameterSpec` 拆成联动比例/分辨率，只选择已声明的尺寸组合；
独立比例/分辨率也只展示声明枚举，宽高仅作估算。无独立分辨率字段时明确由模型决定；
原有提示词画幅模式继续保留。更多参数在弹层内纵向排列，已知参数及选项仅作中文展示，
提交键和值、未知工作流字段、模型连接、权限和存储格式不变。此 UI 适配无新增后端补丁，
不自动改变当前草稿或提交真实生图；撤销恢复对应共享 UI 源码。
