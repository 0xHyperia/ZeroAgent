# ADR 0055：CloudChat 就近错误与状态反馈

- 日期：2026-10-30。
- 状态：按用户最新设计要求本地实施，不推送。
- 范围：CloudChat 反馈呈现；共享 ChatComposerBar、GatewayTranscript 增加可选插槽。

原任务失败提示横跨画布顶部，脱离发生失败的消息与恢复动作。终态提示改放在消息阅读列末尾，
随该会话正文滚动；已生成内容、原请求正文、显式编辑及新分支重试链路保持。
发送错误、未知提交结果、队列满和分支待核对放在输入框前；历史失败保留并显式重试原加载链路。
参数准备、上传/导出和上下文说明使用紧凑状态行。关键错误与未知结果不自动关闭，未知提交不自动重发。
普通上下文说明允许用户显式关闭。

CloudChatFeedback 只呈现中性表面、状态图标、文案和调用方提供的动作。历史终态使用 status；
新错误使用 alert，不能在恢复历史时连续产生紧急播报。图标复用主题色，文案作为文本处理。
窄屏动作换行并保留至少 44px 触控区；输入框前的反馈组有界滚动，计入原 composer 高度测量。

ChatComposerBar.feedback、GatewayTranscript.footer 均为可选 ReactNode，默认不渲染，不引入第二个
编辑器、模型状态或键盘测量。设备/桌面默认命令、安全、队列、Git 与执行语义不变。
不改服务端状态机、幂等键、账户守卫、租约、历史持久化、自动重放或现有重试权限，不做数据迁移与清理。

验收覆盖明确点击后才恢复、未知状态核对、零输出失败仍保留用户消息、任务反馈在正文内、反馈变化
不重建编辑器或丢失选择范围、默认宿主行为、类型/边界/构建以及桌面和手机布局。实际结果见 design-qa.md。
