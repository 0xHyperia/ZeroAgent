# ADR 0035：平台模型设置与显式旧会话导入

- 日期：2026-10-26（Asia/Hong_Kong）
- 状态：用户在当前线程明确要求；替代 ADR 0034 中对应的两项范围限制
- 上游：LiveAgent v2.0.0-beta.21

## 决策

只允许 USA-Zero 平台的模型连接，不等于禁止用户配置模型。复用上游模型编辑器、模型元数据和保存协议，开放模型 ID、显示名称、启停、顺序、上下文窗口、输出上限、输入模态及已有请求格式和缓存提示配置。实际调用仍受平台密钥与模型权益约束。刷新发现列表保留用户编辑及禁用状态。

供应商身份、服务地址、模型发现地址和真实凭据由平台/原生代理固定管理；自定义 headers、任意 URL、代理配置等不得变成外部中转站入口。共享的 Native 配置写入边界同时约束 UI、HTTP 与设备设置路径，不能仅靠隐藏表单。模型参数不包含可复制的托管密钥；已有二次认证与凭据遮罩要求继续适用。

模型启停属于持久配置，不能因 renderer 尚未注册运行时凭据而清空；连接未就绪仍清空公开连接能力，实际执行由现有登录 Gate 与 Native 当前授权控制。对已知的空启用集合不猜测重开模型。

固定K-brain后端支持供应商级缓存提示，不接受单模型 `promptCacheHintMode`。托管表单只提供受支持的供应商级缓存配置，不显示不能持久化的单模型覆盖；规范模型请求不发送该仅前端字段。真实HTTP保存和重启回读验证该边界，不为此分叉Go模型schema。

上游固定后端支持单模型缓存字段、且真实保存/重启测试通过后，撤销对应UI隐藏与请求投影，直接采用上游实现。

2026-10-27 用户明确要求对齐上游缓存默认值并补齐实际请求，以上两段的临时限制由
[ADR 0045](0045-prompt-cache-provider-and-model-inheritance.md) 替代；模型覆盖经固定 Go
最小接线补丁、真实保存/重启与代理出站测试后开放，不重置已有配置。

恢复上游旧会话转换与导入能力，作为桌面设置“备份与同步”中的显式操作。仅从本机旧 ZeroAgent 固定历史数据库只读采集，由用户确认内容属于当前账号，写入操作绑定当前已验证的 profile/后端连接。保留上游多段历史、工具内容、附件、checkpoint、幂等导入、失败列表及删除意图语义。取消、退出、切号或连接更换后不能把迟到结果写进新空间的映射或界面状态。

不启用启动自动导入、不扫描其他产品的历史，不恢复旧供应商配置、密钥、MCP 配置迁移、旧版回退或额外历史协议兼容。原有文件不迁走、不覆盖、不删除；新版正常备份与持久化继续保留。

## 维护与撤销条件

上游继续维护会话转换、模型编辑器、数据结构和普通持久化。ZeroAgent 只保留平台连接约束、账号操作归属与明确的产品入口。上游提供同等固定供应商策略/账号作用域入口后，可撤销对应适配。

账号信息集中在侧栏底部的头像/昵称入口，详细资料、余额、用量、设备与安全仍使用现有账号页面；设置与退出沿用已有生命周期，不引入第二套账户状态。

## 验证

要求模型表单及刷新保留的交互测试、Native 非平台连接绕过测试、真实旧会话转换/幂等/删除夹具、导入过程中切换目标的竞态测试、原生编译和界面截图。夹具与编译不替代真人账号、设备、签名或跨平台安装验收；实际记录见 beta.21 同步报告。
