# ADR 0062：CloudChat 阅读导航、渐进加载与项目创建

- 日期：2026-10-31。
- 状态：按用户明确要求本地实施，不推送。
- 范围：CloudChat Web 与移动视图；共享侧栏仅新增显式可选加载方式。

用户优先关注布局、UI、交互和动效。后续能力接线须先明确主任务、入口、状态和阅读层次，
复用已有组合与设计变量，不能以临时面板、重复入口或调试式控制代替完整用户体验。

对话侧栏移除最近/置顶/归档筛选胶囊，默认显示未归档的最近对话并保持置顶排序；现有
消息搜索、置顶和归档操作继续使用原后端协议。列表在接近滚动底部时按有界服务端游标
自动续载，单次只请求一页，加载状态与读取失败明确区分，失败后保留显式重试。
关闭侧栏、折叠分组、切换范围或已有读取请求时不能重复触发；过期观察器不能加载新范围。
共享组件默认仍为手动加载，不改变原生桌面宿主的行为。

CloudChat 接入既有 FloorNavRail、楼层模型和虚拟列表导航，显示当前已加载消息的楼层，
提供短线导航、悬停预览、当前项高亮、收藏及触屏适配。点击复用虚拟行定位并解除自动
跟随，后续流式更新不抢回阅读位置；会话历史分页继续保持原有读取边界。导航收藏使用
账户与会话组合身份，不能跨账户共用同一导航状态。

页头分支与选项控件必须具有不同身份。此前相邻控件使用相同 React key 导致切换会话
错误复用并累积按钮，现以独立前缀修复；取消、草稿、历史和实际分支数据不受影响。

新建项目复用单一 CloudProjectCreateDialog。侧栏加号、空态按钮、输入框的项目选择器和
项目管理中的创建入口打开弹窗，不导航到创建页面或创建空会话；会话菜单的新建并移入
复用同一弹窗。名称输入、用途说明、创建/保存中、
失败及未知结果均在弹窗内完成，不展示尚未接通的记忆选项。成功创建后的关联重试不再
创建项目，创建结果未知时阻止盲目重发。浏览已有项目的原有功能保持。

移除正文上方重复的“本会话附件/成果”汇总及其空容器样式；输入资料留在对应用户消息，
正式交付留在对应助手回复，点击仍走受认证的统一预览工作区，不删除原件或已保存产物。

无数据迁移或清理；撤销仅涉及前端组合，已保存项目、对话、资料与任务状态保留。验证
覆盖自动续载/重试与失效观察器、连续会话切换的控件数量、共享导航的消息身份与跳转、
创建弹窗不导航、宽窄屏和现有 Page/原生共享回归，以及类型、边界与前端构建。

## 2026-11-01：项目内会话归属

按用户截图与要求，项目在侧栏中作为可折叠的会话分组，子会话缩进展示；选中的会话高亮，
从搜索或地址进入项目会话时自动展开所属项目。按需读取项目会话及后续页，关闭侧栏或折叠
时不继续预取，加载、空态与失败重试各自明确。悬停/焦点显示项目设置与项目内新对话，
触屏保留可见操作；复用统一控件、表面、圆角、焦点与减少动态效果。

最近目录改用服务端 `unassigned` 范围，先按账户、未归档和无项目关联过滤，再分页；原有
`active`、搜索和项目管理协议继续保持，不能依赖前端逐条查关联后隐藏。项目读取返回规范
置顶/归档状态，归档会话不在项目的活动列表显示。移入/移出、改名、置顶和删除同步刷新
相应目录；原项目会话仍可直接打开，已保存消息、资料和关联不做迁移或清理。

项目内新对话仅准备带项目选择的空白草稿，首条消息发送时才创建记录并关联。草稿协调器
的显式新建支持种入项目草稿，避免空白草稿的迟到恢复覆盖项目选择；默认无参数新建语义
不变，原会话草稿独立保留。变更只影响 CloudChat，桌面设备本地工作区继续使用原适配。
