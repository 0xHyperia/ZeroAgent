# ADR 0054：对话标题、连续框架与导航预览

- 日期：2026-10-29。
- 状态：按用户截图本地实施，不推送。
- 范围：CloudChat；共享 ChatHeader、ApplicationRail、ChatHistorySidebar 增加可选展示/回调。

已有对话且桌面侧栏收起时，标题前显示新对话按钮，复用本地空白草稿导航；固定展开时使用
侧栏中的同一入口。手机保留抽屉入口及新对话。不得直接产生空历史记录或取消原服务端 Run。

标题点击行内编辑，悬停显示图标，Enter/失焦保存、Escape 撤销，IME 组合输入不提交。
空值拒绝；保存中不重复提交，失败保留输入与错误，成功返回触发器焦点。复用原会话 PATCH
及账户守卫，主标题和历史列表共用会话摘要，不另建状态权威或重载消息。

2026-10-30 标题宽度修正：标题区域使用操作按钮之外的实际剩余空间，内容按自然宽度展示，
仅空间不足时截断；移除影响按钮固有宽度的负边距及固定480px/32%上限。
短标题不再为了隐藏的编辑图标而被提前省略，编辑、焦点和保存链路保持。

应用轨在外层，侧栏与画布使用四周圆角、细边界的共同表面。固定侧栏融入页面，临时预览
内缩并加轻阴影，复用原宽度/位移动效及减少动态支持。手机沿用原 Sheet、安全区和全宽布局。

对话、资料库、设备导航在侧栏收起时可悬停预览对应侧栏。按 2026-10-30 用户修正，固定展开时
禁用导航 hover 预览，点击才正式导航；展开后立即关闭现有预览并撤销待打开计时。预览保留当前会话、
正文位置、编辑器、草稿、执行目标与固定偏好；点击后才执行既有守卫后的导航。另一目标预览
的固定按钮表示显式打开目标并展开，不反向收起旧侧栏。资料库显示真实分类与当前账户最近文件，
设备显示真实列表与在线状态。悬停不执行模型、切换设备或创建内容，不伪造尚未实现的应用导航。

2026-10-29 修正交接区域：侧栏边缘仅在没有预览时选择当前页面；已有资料库或设备预览跨过
边缘进入内容区时保持目标。临时状态随原关闭/失效逻辑一起清理，不增加持久配置或数据变更。
回归覆盖图标→边缘→内容、完全离开后重入边缘以及资料库/设备两类目标。

账户失效守卫清空旧会话后显示刷新提示，避免只留下空内容。保留原有失效及迟到结果隔离，
不自动重发请求或恢复未经重新验证的账户状态。

不迁移或清理数据。回退可撤销展示扩展；用户显式保存的新标题保留，不自动改回。
验收须覆盖标题提交/取消/失败/重复/IME、已有 Run 与草稿、空白新会话、预览不导航、账户及
布局重置、迟到文件读隔离、默认 Desktop 行为、类型/边界/构建及宽窄屏实测；证据见 design-qa.md。
