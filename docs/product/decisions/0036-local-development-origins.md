# ADR 0036：本地开发服务来源

- 日期：2026-10-26（Asia/Hong_Kong）
- 状态：按用户明确要求连接本机 Gateway 和局域网 HTTP Sub2API 开发环境

Desktop 的 debug 构建允许构建时明确指定的 loopback、RFC1918 IPv4 或 IPv6 ULA HTTP
账号/模型根来源。来源的协议、主机和端口仍必须与构建配置完全一致，拒绝凭据、路径、
查询和片段；不能通过模型设置或运行时参数更换账号来源。发布构建继续只接受 HTTPS。
这仅补充 ADR 0008、0016 的开发传输条件，OAuth、PKCE、账户隔离、凭据保护、固定路由
和禁止重定向保持既有契约；不改变持久化格式或迁移既有数据。撤销本次源码改动可恢复
原先所有构建均要求 HTTPS 的行为。

三端使用同一组本地环境变量，桌面端的编译期与运行期 Gateway 值一致。开发就绪探针
使用 ZeroAgent 的真实应用标识和当前 checkout 路径，不能将任意 Vite 响应当作 Native 就绪。
验证包括 debug/发布传输策略、跨来源与非法 URL 拒绝、三端实际启动和请求连通性。

2026-10-27 内网安装包补充：桌面远程访问设置在未提供运行时 Gateway 环境变量时，使用
同一组构建时 Gateway 地址和端口；均未配置时仍使用官方来源。显式运行时覆盖保持原有
优先级。安装后的快捷方式无需额外启动脚本；远程访问仍由用户开启，既有账号、设备凭据、
托管模式和存储布局不变。子进程测试清空运行时变量后检查生产设置投影，并验证显式覆盖；
源码撤销只恢复安装版依赖运行时变量的行为，不执行数据回滚。
