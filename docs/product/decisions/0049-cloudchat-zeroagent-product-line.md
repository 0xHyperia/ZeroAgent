# ADR 0049：CloudChat 继续以 ZeroAgent 为主线

- 日期：2026-10-29。
- 状态：用户明确选择；本地实施，不推送、发布或部署生产。
- 范围：CloudChat 与共享对话交互；保留既有 Desktop、设备 Agent 和 Android 能力。

保留 ZeroAgent Gateway、Go 唯一模型/工具循环、PostgreSQL、Redis、对象存储与 E2B。
不以 LibreChat 整体二开取代当前产品，不为聊天能力引入 MongoDB 或第二套 Node 应用后端。
LibreChat 作为独立参考来源，允许移植适用的对话逻辑、交互代码和测试；逐项记录固定来源、
许可证、适配边界与验证。引用的实现必须接入现有账户、任务及权限契约，不能同时维护两套数据权威。

当前工作围绕对话与写作、资料理解、公开联网研究、数据分析、成果交付、项目接续和编程辅助。
角色、分组、运营配置管理、运营审计与语音不列为本次 CloudChat 完成条件；这不授权删除
已有桌面语音、正常模型参数设置、账户隔离、权限校验、费用约束或必要运维诊断。

UI 和交互以 ZeroAgent 现有共享组件、主题、字号、菜单、输入框、消息、侧栏与响应式规范为准。
不引入 LibreChat 的外观或整套状态框架；新增能力进入统一导航和资源面板，避免逐项堆放临时按钮。
宽屏资源与对话并列；窄屏复用共享 Sheet 的模态、焦点和关闭语义。编辑、引用、导出、取消、
错误与恢复操作必须有可验证入口，已存在的功能不能因整理导航而消失。

本次展示层调整不迁移、清理或重写用户数据，不改变 USA 登录、托管模型或执行授权。
撤销本次 UI 可恢复原展示，不承诺旧二进制读取后续新增任务。既有七类真实场景验收继续有效，
不能用页面美化、组件测试或本地协议夹具替代真实内容质量与外部链路验收。

验证包括菜单与资源入口、键盘/关闭焦点、窄屏、流式阅读不抢滚动、既有对话/附件/成果/项目
回归、三端类型检查、Web 构建及生产构建浏览器检查；最终支持端和外部验收分开记录。
