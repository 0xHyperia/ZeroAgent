# ADR 0037：网页对话采用当前共享布局

- 日期：2026-10-26（Asia/Hong_Kong）
- 状态：修复用户报告的本地 Gateway 页面错位

网页对话复用当前上游 `webStyleClasses`、共享侧栏、聊天容器和设置层的布局，不恢复已经
移除的旧 CSS。品牌通过侧栏现有 `brand` 扩展入口集中注入 Gateway 的公开图标资源。
Cloud Chat 不挂载需要设备日程后端的时区控件；Desktop 与已选择设备的能力保持原有边界。
不修改账户、历史、模型配置或持久化格式，也不触发数据迁移。撤销这些改动会恢复此前
网页布局和缺失资源问题，不涉及数据回滚。

验证包括 WebUI/Shared 类型检查、构建、既有能力与移动布局回归，以及真实浏览器中的
侧栏、聊天区、附件隐藏、设置打开/返回、错误提示和图片加载检查。
