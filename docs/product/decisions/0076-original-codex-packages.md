# ADR 0076：CloudChat 使用本机 Codex 原始包

- 日期：2026-11-05。
- 状态：运行时方案已由 ADR 0077 和 ADR 0079 取代。下文保留当时的验证记录。
- 范围：Product Design、Plugin Creator、Image Gen、Skill Creator。
- 本决策替代 ADR 0073 对这四个能力的中文改写与展示命名。插件与独立技能仍分别归类。

原始清单、提示词、脚本、参考资料、模板、样式和图片保留原路径与字节，按整个文件树校验。
附 Apache 许可证的系统技能随 Gateway 构建；标记为 Proprietary 的两个插件只复制到 Git 和
构建上下文均忽略的本地目录。开发栈在本机环回模式下使用该副本；未配置副本时保留原有包。
不读取 Codex 账户配置、凭据、运行历史或工作区；不改动 Codex 安装。
从此 checkout 运行 `node scripts/import-codex-originals.mjs` 后重新启动本地 Gateway，
即可启用已固定摘要的专有插件副本。脚本不会用不同字节覆盖现有副本。

在自定义的目录、详情、技能文件、会话菜单和引用中使用包原本的英文名称、说明及起步提示；
安装、返回等界面文字沿用 ZeroAgent 界面语言。保持共享布局、手机阅读与返回流程。
包内辅助文件和嵌套的样例技能只作为资料，不注册为独立条目。无可连接的原始应用时说明状态，
原有 ZeroAgent 插件编辑器保持为单独入口。

原始包只提供工作流及源码数据。CloudChat 仍只使用已授权的云端工具：生图走已配置的
ZeroAgent Images，文件和代码只有在已提供隔离工作区时才能运行。Plugin Creator 的
`.app.json` 声明远程连接，缓存中没有托管实现；保留原清单，不注册、连接或模拟该服务。
二进制及超过阅读上限的文件保留在原包中，不塞入模型上下文。

原始包使用新的内部修订，原有引用和账户安装/启停状态保留。文件不一致时拒绝将其注册到
同一修订；本地专有副本撤除后，对该本地修订的引用明确不可用，不会静默换成其他指令。
个人包上传限制、公开包编辑/下载限制及账户隔离保持。通过文件树校验、技能读取、历史固定
引用和 Web 入口测试验收；本轮不提交、推送或发布。
