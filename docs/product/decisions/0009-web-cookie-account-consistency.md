# ADR 0009：WebUI 共享 Cookie 与页面账号的一致性

- 状态：已采纳，实施与验收中
- 关联：ADR 0007、0008；LiveAgent v2.0.0-beta.20

同源页面共享 HttpOnly 会话 Cookie。页面 A 仍显示旧账号时，页面 B 的登录可能已将 Cookie
换成另一个账号。仅取消页面 A 的旧请求不能阻止它用新 Cookie 请求并展示 B 的数据；延迟
退出或认证失败响应中的 `Set-Cookie` 删除也可能覆盖新登录。

WebUI 在验证 current-user 后，把该账号 ID 作为 `X-ZeroAgent-Account-ID` 一致性断言附到
账户、云对话和执行目标请求。Gateway 仍独立验证 Cookie、账号与执行租约；此标识不是
认证凭据。声明与实际会话不符时返回 409，拒绝读取、写入和退出，也不修改 Cookie。
旧客户端未发送断言时保留现有认证接口，不能据此扩大其权限。

新页面的退出先撤销服务端会话，再清空本页的连接、租约、对话、草稿、上传和队列状态。
带账号断言的退出响应不再删除 Cookie；已撤销的旧会话 ID 无法认证，下次登录会替换它。
认证失败的读取响应同样不删除 Cookie，避免旧启动查询晚到时清除新身份。旧客户端的
显式退出保留 Cookie 清理行为。普通过期只清理本页，不退出浏览器当前可能属于另一账号的会话。

请求持有页面会话代次，身份变更后不能把旧响应交给调用者，也不能让旧 401 触发新会话退出。
登录、注册、2FA、嵌入 OAuth 完成和退出通过同源 Web Locks 串行，锁不可用时仍有本页队列
和服务端身份断言。Cookie 变更后仅向本地存储写入随机 nonce，通知其他页面清理本页状态、
重载并重新验证 current-user；不广播账号、密钥或令牌。普通 current-user 查询不广播，避免重载循环。

必须验证账号 A/B 互不读取或写入、旧退出不能撤销 B、过期响应不能清理新 Cookie、租约仍
按账号授权、延迟响应丢弃、跨页面锁及 nonce 通知。真实浏览器多页面、Android OAuth 和
受限浏览器环境的完整验收仍以同步报告记录为准。
