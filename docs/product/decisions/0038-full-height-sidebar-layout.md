# ADR 0038：侧栏从窗口顶部开始

- 日期：2026-10-26（Asia/Hong_Kong）
- 状态：按用户截图反馈调整 Desktop 与 WebUI 布局

折叠按钮移到搜索右侧后，原本横跨全窗的标题栏仍在侧栏上方留下 48px 空白。
Windows、Linux 桌面与 WebUI 设备视图使用共享 CSS Grid：侧栏跨越标题栏和内容两行，
标题栏及工作区位于右列。保留现有组件顺序、侧栏状态、搜索、窗口控件和工作区分栏；
不使用负边距覆盖标题栏，也不重复创建侧栏。Cloud Chat 已有并列结构，去掉其标题栏内
不再需要的侧栏宽度占位。macOS 保留原生窗口按钮所需的标题栏布局，窄屏仍使用 Sheet。

这项改动不改变账户、设备、模型、数据格式或持久化，不需要迁移。撤销只恢复之前的布局。
验证包含共享 UI、Desktop、WebUI 类型检查与构建，28 项既有侧栏、窗口、搜索、Cloud Chat
和窄屏回归，以及生成 CSS 中的跨行侧栏规则检查。实际窗口视觉效果由用户手动确认。

2026-10-27 追加导航修复：桌面顶部新对话使用独立的最近对话回调，必须先切回聊天页，
再取消旧的历史打开请求、缓存输入状态并创建一个不绑定项目的新会话。此前回调遗漏页面
切换，使资源页保持可见。保留既有会话与草稿缓存、空工作目录及后台执行；不改变账户、
权限或持久化格式。回归点击真实侧栏按钮并执行生产回调，覆盖六类资源页及聊天页。

按用户后续反馈，顶部“新对话”作为操作入口不再随聊天页持续选中，只保留悬停、按压和
键盘焦点反馈。Desktop/WebUI 使用同一组件；当前会话、工作区及资源页的选中状态保持。
