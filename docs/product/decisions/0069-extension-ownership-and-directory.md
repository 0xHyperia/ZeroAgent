# ADR 0069：插件、独立技能与归属权限

- 日期：2026-11-05。
- 状态：用户通过本轮五项要求明确授权实施，不提交、推送或发布。
- 覆盖：ADR0068 中的目录混排、公开下载及可见版本流程。

插件与独立技能分别建模，公开/个人是来源，已安装/未安装是账户使用状态。插件包含的技能不进入独立技能页。
现有账户技能按其真实内容解释为独立技能或多技能包，不清除、不拆分已保存数据。个人创建/上传可明确选择类型；
类型创建后不能借编辑变更，防止同一身份在两种目录中跳转。卸载保留归属与内容，并可显式重新安装。
公开的独立 skill-creator 使用独立包定义与身份，不由插件内容扁平化生成。原 Product Design 中的同名入口保留，
避免破坏已有引用；它仍归 Product Design 管理，不因此获得独立技能页条目。

公开定义的所有权由服务端确定，用户只能改变自己的安装和启用选择。公开条目拒绝编辑和归档下载；
个人条目只从当前认证账户读取，只有所属账户能编辑或下载。请求不能通过提交 owned/visibility 冒认归属。
本轮不引入公开投稿、分享、第三方账号连接或额外凭据存储。

界面删除 V1/V2 及版本管理流程；原有内部 CAS、已发引用、执行快照与保存事实保留，防止覆盖和数据丢失。
保存不再以二十次修订作为用户使用上限，仍受账户文档总量 8 MiB、单份内容 256 KiB 等现有安全边界约束。
个人与公开内容都使用既有 Go Run 工具循环，安装或引用不增加工具权限。切页、切号、未知保存结果和草稿保护保持。
详细布局与交互以 `docs/design/cloudchat-extensions-ux.md` 本轮修订为准。

验证应覆盖对象分离、两维筛选、卸载后重装、公开下载/编辑拒绝及跨账户拒绝，实际桌面/手机路径与视觉对照；
构建或静态菜单隐藏不能代替权限和体验验收。
