# ADR 0058：以 CloudChat 为基准统一跨端体验

- 日期：2026-10-30。
- 状态：用户通过当前目标明确授权本地实施、测试和交付，不推送。
- 范围：共享 UI、桌面本机及远程工作台、Web 和 Android 嵌入 WebUI。

将当前 CloudChat 已确认的视觉和交互提升为全产品规范。这项授权替代 ADR0050–0057 中
“新外观仅限 CloudChat、Desktop/设备默认外观不变”的展示限制；原有功能、状态所有权、
账号隔离、Native 密钥保管、工具审批、执行目标和持久化契约不变。

沿用 agent-ui 与现有 Base UI、React、主题及适配器，不另建 UI 框架。共享语义设计变量、
基础控件和页面组合；具体账户、文件、模型、任务与设备操作仍由各宿主提供。共享层不
反向依赖 Gateway 或 Tauri，不把云资料协议用于本机文件，也不合并两个独立远程运行时。

基础控件统一普通/悬停/选中/选中悬停/焦点/按下/禁用/加载/失败。页面统一应用轨、上下文
侧栏、页头、输入和模型控件、设置、资料卡片、空态与就近反馈；保留终端、Git、审批、
队列、语音及其他已有功能入口。鼠标、键盘、触控、窄窗及系统缩放分别适配。

桌面保留窗口拖动区、系统控件、本地文件选择与多面板；Android 保留 Native 安全区、
IME 避让、系统返回、凭据及更新桥。触屏入口不依赖 hover，hover 仅在支持的输入设备启用。
平台能力和内容密度通过显式组件参数描述，不通过改动执行模式或检测全局凭据来决定外观。

桌面及 Android 的应用更新提示位于左侧应用轨底部、头像上方。桌面远程工作台通过宿主
插槽显示桌面自身的更新状态；不查询被控设备的应用更新。Android 自动发现只显示入口，
点击后查看详情；“稍后”关闭详情并保留入口。手动检查、下载来源和原生更新桥保持。
普通浏览器不显示原生更新控制。按用户最新要求，纯布局与组件交互默认在 Web 宽窄视口
验收，不为每次 UI 调整构建 App；下载安装、系统返回、IME、安全区等仍区分原生验证。

桌面本机与设备 WebUI 切换到功能页时，侧栏改为功能导航，页头标题和选中项跟随当前页面，
项目与会话列表仅在对话页出现；会话控制器、运行任务及草稿继续保持挂载。设置页沿用
CloudChat 的应用轨、分类导航、圆角画布和正文页头保存状态，保留各宿主专属设置和窗口控件。
原工作台的同一应用轨通过展示插槽进入设置外壳，保留账号、更新和设备状态；导航离开设置
仍受未保存配置守卫约束，后台布局保留轨道占位，禁止为设置页另建账户或执行客户端。

手机会话行常显“更多”按钮，复用原菜单与限制，长按仍保留。原生返回沿用共享弹层的
Escape守卫，事件交给最上层已打开的弹层；触屏焦点留在body时不能让父级抽屉一起响应。

桌面和设备的模型控件改为 CloudChat 的两个直达区域与同一个浮层，选定模型后关闭浮层。
执行方式的原生单选组和模型原生联网开关仍由设备宿主控制。资源入口迁到共享应用轨，
原快捷入口可见性配置继续有效，搜索、历史和项目动作保留。

实施和验收依据为 docs/design/zeroagent-cross-platform-ux.md；实际覆盖及未完成项记录于
docs/design/cross-platform-implementation.md。原 CloudChat 专项规范作为具体业务流程约束继续有效。
迁移逐批核对草稿/选择/撤销、保存失败、取消/重试、隐藏宿主、切号和远程卸载，避免改外观导致状态重建。

不迁移或清理用户数据。回退只撤销展示及组合变更，已保存业务数据保留。每批运行相关
组件/宿主回归及边界检查；最终验证 GUI/Web/embedded-mobile/embedded-desktop 构建与
运行画面、浅深主题、宽窄屏、键盘/IME/触控和现有功能入口。真实设备尚未运行的项目不得
以浏览器视口代替通过，编译或局部组件测试也不代表完整目标完成。
