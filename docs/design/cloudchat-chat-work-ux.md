# ZeroAgent CloudChat：对话与工作体验规范

## 对话执行位置

当前交互以顶栏切换为准。桌面顶栏左侧沿用「此电脑」与远程设备菜单，并提供「云端」。浏览器在原工作台顶栏切换云端与已授权设备。两端的新建对话直接使用当前环境，输入区不再显示切换菜单。下方的草稿位置菜单与工作区预检记录对应此前的实现。

手机顶栏点击当前执行位置，从底部打开设备列表。选择成功后关闭弹层，连接失败在原位显示目标、原因和重试。关闭或返回将焦点交给顶栏入口。手机空白对话把问候和建议放在一起，建议只填草稿。空白输入框保留附件、编辑区和发送的单行布局。工作模式将项目、技能、模型及思考程度放在输入框上方的同一行，资料从「＋」进入。模型、思考程度、资料与技能选取均使用底部弹层，并复用各自的当前选择和键盘交互。设备工作台在这一行提供权限、模型与会话选项。

桌面本机和设备 WebUI 的 Agent 输入框共用「＋」菜单中的「计划模式」开关。启用时在输入区显示可关闭的计划标记。权限菜单独立选择执行权限，切换权限不关闭计划。两端均可用键盘操作菜单和计划标记。

首次发送前，在输入区的模型与发送操作旁显示执行位置。设备草稿标出设备与已选工作区，工作区入口复用现有目录选择流程。选择云端时打开账户工作台的新对话，原设备草稿和文件继续留在设备。云端嵌入桌面时可回到原设备草稿。Web 复用账户内设备选择及设备项目控制。离线设备可见，连接失败留在位置菜单并允许重试。

首次发送后，标题栏显示只读执行位置。换执行环境时从新对话开始，原对话与运行继续保留原位置。位置选择使用共享菜单、文字标签和图标，支持键盘选择、Escape 和焦点返回。窄屏优先保留设备或云端名称，过长的工作区名称在辅助文本中可读。入口、错误和状态在桌面及 Web 使用同一组件，账户与设备授权沿用现有实现。

Web 云端新对话在共享位置菜单中列出设备已发布的工作区。每行显示设备名与工作区名，离线设备或没有工作区的设备仍可辨认，长列表在菜单内滚动。选择后先保存原云端草稿与附件，再通过该设备既有控制租约读取最新项目并检查目录。失败留在原菜单，反馈该目标不可用并可重新选择。切换成功只将确切工作区交给设备的新草稿入口，原云端输入不会复制到设备。设备端加载后再次检查项目标识、路径及可用状态。连接中断或项目变化时保留目标并提供返回云端的入口，避免误在默认工作区发送。

执行位置检查失败时，菜单顶部保留设备与工作区名称、原因和「重试」，长列表滚动时仍可见。重试使用当前目录中仍在线且身份和路径一致的原目标。设备离线时只显示一行状态，待恢复后可重试。目录移除或修改工作区路径后保留失败说明，引导重新选择，不使用已变化的目标。重新选择和 Esc 沿用原菜单的键盘操作与焦点规则。

一次性草稿目标按账户和设备保存在新设备对话的浏览器历史条目中。刷新、设备离线或租约失效时保留原工作区，重试取得有效的设备授权后重新验证该工作区。已保存的会话和定时任务地址不接收这份草稿。打开正确设备草稿或明确取消交接后清除标记。标记只用于界面定位，不进入请求凭据或 URL。宽屏和窄屏沿用原设备不可用提示及重试入口。

Web 设备工作台在同一标签刷新时恢复当前未发送的新对话。账户、设备及原工作区必须通过现有设置与会话边界核对，明确路由、已保存会话和刚选择的设备目标优先。正文、引用、大段粘贴和已完成导入的附件随同一个草稿恢复。原工作区不可用时在当前工作台提示，避免将草稿交给其他目录。上传中的文件需要重新添加，刷新后提示。草稿只保存在该标签的浏览器会话内，退出账户清除。附件只保留设备已导入的路径与显示信息，不保留文件字节、临时预览地址或授权。桌面、手机沿用原输入区和状态提示。恢复不发送消息或重新导入附件。

已有设备会话的回复草稿按经设备确认的会话标识保存，桌面显示标识变化时以同一个后端会话标识恢复。每个分屏从自己的输入框和附件状态保存，刷新后打开同一会话时分别恢复。尚未发送的其他分屏以原工作区的本地草稿行恢复，继续采用冷启动单分屏布局。宽屏可重新并排打开，手机通过侧栏访问。用户开始输入、已有当前草稿、原会话无法读取或工作区不匹配时，历史快照不覆盖当前内容。旧分屏已提交的内容、设备操作凭据及工具布局不进入恢复。可删除的草稿行和定时任务结果保留各自的操作范围。

设备工作区暂不可用时，在设备草稿内容区保留恢复提示及「重试恢复」。工作区或工作模式恢复后，重试按当前已同步的设备设置核对原目标。已有当前输入或附件时，将当前内容保留为侧栏中的独立草稿，引导用户到空白设备对话重试原草稿。刷新或离开页面时保留两份草稿，已打开的正式会话和其他账户或设备不显示这条提示。

## 浏览器路由与刷新恢复

在已登录的 ChatGPT Web 核对了 `/c/:id`、项目会话 `/g/:project/c/:id`、`/space?tab=suggested`、`/plugins` 和 `/skills?skill_id=:id`。设置分类参考 ADR 0053 记录的 `/settings/general-settings`。ZeroAgent 给可独立打开的内容分配稳定地址，会话统一使用 `/c/:id`，项目移动后仍可用原链接。公开分享使用独立入口，访问权限继续由账户或分享规则决定。

| 用户打开的内容 | ZeroAgent 地址 |
| --- | --- |
| 云端新对话、已有对话 | `/`、`/c/:conversationId` |
| 云端会话内明确定位的消息 | `/c/:conversationId?message=:messageId` |
| 设备新对话、已有对话 | `/?device=:deviceId`、`/c/:conversationId?device=:deviceId` |
| 项目列表、项目详情 | `/projects`、`/projects/:projectId` |
| 资料空间、文件夹、文件、成果、站点 | `/space`、`/space/folders/:id`、`/space/files/:id`、`/space/artifacts/:id`、`/space/sites/:id` |
| 插件及管理、技能和包内技能 | `/plugins`、`/plugins/:id`、`/plugins/:id/manage`、`/skills`、`/skills?skill_id=:id`、`/plugins/:id/skills/:name` |
| 个人扩展编辑器与待审阅草稿 | `/customize/edit/:id`、`/customize/new/:kind`、`/customize/drafts/:id` |
| 设置总览与分类 | `/settings`、`/settings/:section` |
| 定时任务列表、任务与运行记录 | `/tasks`、`/tasks/:id`，状态、目标与运行标识使用查询参数 |

筛选和会话内打开的阅读器使用查询参数。地址只包含路由用标识，不写入草稿、正文、凭据或执行租约。同一标签用账户绑定的浏览器历史记录恢复底层会话。冷启动按 URL 打开目标，保持现有加载、无权限与错误状态。会话和设置使用上表地址。公开分享和设备授权沿用各自的入口。

用户进入另一页面时新增历史记录，回退和前进恢复对应视图。首次发送后以新建会话的地址替换当前草稿地址。桌面保留会话画布和 Run 订阅，窄屏沿用现有单列、阅读器和返回入口。项目编辑离开仍经原有确认，个人扩展编辑由已有草稿恢复机制保留。短暂菜单、二次确认及高级设置弹窗留在当前页面。

桌面应用轨与设备宿主从有未保存修改的账户项目发起导航时，先在原项目上显示离开确认。确认前保留应用轨选中项、项目地址和编辑内容。确认文案跟随界面语言，键盘焦点默认落在继续编辑。明确放弃后才应用目标位置。账户变更后，旧确认不能打开任何新页面。未打开的账户内容或没有未保存修改时，导航即时进行。

桌面和 Web 从应用轨重新进入「自定义」时，恢复当前账户上次浏览的插件目录、技能目录或插件详情，目录内保留已保存的搜索、筛选和滚动位置。技能阅读、插件管理和草稿编辑都有各自的显式入口和地址。应用轨回到浏览位置，明确的链接或侧栏入口优先打开指定对象。只在正式打开的工作台更新浏览位置。

普通云端会话记住用户离开时正在阅读的消息及其在视口中的位置。回到会话或刷新时，先校验当前账户并读取会话；最近一页已有原消息时在同一页恢复，较早位置用已有的消息窗口读取。搜索结果、明确指定的任务运行以及正在发送的消息优先。生成仍在运行而原位置已超出最新一页时，继续显示并同步当前运行，同时提供「返回上次阅读位置」。已读到最新的会话继续从最新消息打开。位置只保存在当前窗口，以账户和会话隔离，不记录正文、不改地址、不发起运行。原消息不可访问时回到最新，暂时读取失败时允许重试或回到最新。

从搜索或来源明确定位的云端消息随链接保留，刷新、后退和前进按会话及消息重新核对。明确定位优先于窗口记住的阅读位置，普通滚动只更新窗口中的阅读位置。消息找不到时，提示留在消息区，提供「返回最新消息」。暂时读取失败时可重试原位置。宽屏沿用会话状态行，窄屏允许操作独占一行。返回最新时移除当前链接的消息定位，焦点回到消息区，并保留输入草稿。任务运行与设备会话沿用各自的地址和权限校验。

云端、设备 WebUI 和桌面会话共用「返回最新消息」按钮。用户离开最新消息后，向下箭头浮在当前分栏的输入区中心线上，与队列、进度和输入框留有间距。窄屏和触屏保留至少 44px 的操作区域，主题切换沿用通用按钮的背景、边界和焦点。点击只恢复当前会话的阅读跟随。键盘焦点返回消息阅读区，触屏不会因此打开输入键盘。

云端对话持续显示最近收到的回复。事件连接无数据时先核对同一次运行的最新状态，再从已接收的序号续接。服务器心跳代表连接可用，等待工具或模型输出期间保留正常状态。连续三次既无法读取事件也无法读取运行状态时，在当前对话的输入框上方显示「重试同步」及已保留内容说明。确认没有读取权限时在同一位置解释。已收到完成状态而完整对话历史读取失败时，提示区改为「重试读取记录」。重试沿用原账户、会话和运行，只执行读取。宽屏使用共享状态行，窄屏动作可独占一行。等待时保留草稿及重试按钮的键盘焦点，成功后若焦点仍在该按钮则回到消息阅读区。会话或账户切换后，旧请求不能更新当前界面。

从消息定位编辑重发时，接受新运行后回到同一会话的最新消息。退出旧消息定位只结束该次历史读取，新运行继续接收事件。并行刷新的历史未含这次回复时，保留最新已知输出。

设备 WebUI 在查看资料、任务或设置时保留原会话画布。画布隐藏或不可交互期间，当前页面可处理键盘事件，分屏快捷键暂停。返回对话后，快捷键继续操作原分屏，保留选中的分屏、草稿和运行。

云端任务的 `task_run` 地址始终指向选中的那次运行。运行早于最近历史列表时，按当前任务和账户单独读取，并保留在当前选中位置。读取暂时失败或确认不可访问时，在任务内容区解释，并提供原位重试和返回任务的入口。期间保留当前地址，避免将最近一次的内容显示成原链接的结果。

浏览器开始回退或前进后，地址可能先于历史事件改变。在界面路由未变时，后台加载、流式输出和预览更新应等待历史事件，避免把当前阅读器或会话重新写回历史。

设备 WebUI 在同一标签按已验证的账户和设备恢复最近会话。历史读取暂时失败时保留原会话，正文上方使用状态提示和「重试」，侧栏和其它工作台入口仍可操作。读取完成后按设备返回的会话工作区恢复工具上下文。在历史不可读期间暂停向该会话发送，用户可以明确打开其它会话或新建对话。重新选择账户或设备后，旧请求无法覆盖新会话。

从设备侧栏打开会话与从链接恢复会话共用历史读取失败状态。侧栏、地址和已读取的正文保留在当前会话，发送与附件导入等待同一会话的历史核对。重试只使用原账户、设备和会话，并复用打开成功后的工作区定位。搜索结果验证失败时保留已打开的会话，用户可继续操作原会话或重新选择搜索结果。

设备会话的显式地址同时指定设备与会话。首次打开、刷新或浏览器返回时，先按当前账户检查目标，再使用该设备的原控制租约读取历史。地址只包含设备及会话标识。明确的新对话地址可恢复该标签的设备草稿，已有会话地址优先于最近会话及新草稿。用户选择另一个会话时新增历史记录，发送第一条消息后以正式会话地址替换草稿地址。设备不可用、授权过期或会话读取失败时保留当前地址。在原位置提供重试，正文与发送功能等待原目标确认。用户也可通过工作台导航返回云端。宽屏与手机沿用同一导航与状态组件。桌面嵌入的设备宿主仍由外层窗口管理位置。

已打开设备会话后，连接中断时在对话内容顶部用状态提示区分「连接中断」与「设备离线」，并提供「重新连接」。提示与正文、分屏和输入区并存。重连检查期间保留草稿、附件和工作区，暂停所有分屏的发送，直到原连接返回最新在线状态。手动重连沿用当前设备的运行时准备流程，仍离线时保留操作入口。宽窗与手机共用状态组件。

设备传输暂不可用时，已打开会话和已挂载分屏的草稿继续接受文本编辑。当前输入框与光标原位保留，回车用于换行；暂停引用候选、命令执行、上传和发送。重新确认同一设备在线后恢复发送快捷键及操作，不自动提交已编辑的草稿。协议不兼容、历史尚在加载及上下文压缩继续使用各自的保护条件。

发送设备会话消息时绑定当时的设备选择。大段粘贴导入、运行时准备、首次发送及回执重试都沿用同一绑定。同一设备断线恢复后可以继续核对原请求。已明确选择的设备暂时不在目录中时仍保留该目标。改选设备会结束旧请求的前台等待，旧响应不能更新新设备的状态或把原草稿、附件发给新设备。即使切回原设备，也需由当前会话重新发起操作。

设备定时任务链接保留设备、任务、运行和筛选位置。刷新、浏览器前进或返回时，先恢复链接指定的设备，再打开其定时任务工作台。设备暂不可用时留在该链接并显示重试。浏览器在云端有未保存内容时沿用已有的离开确认。普通云端任务链接仍打开账户任务，桌面嵌入位置继续由外层工作台管理。

明确的设备任务链接必须包含唯一且有效的设备标识。如果指定运行，也必须包含有效的任务和唯一运行标识。设备标记、设备标识或运行位置缺失、重复或格式错误时，保留原地址并在内容区提示重新打开有效链接。宽屏保留应用轨，手机保留返回云端操作。格式错误不显示重试，不打开云端同名任务或其他设备，也不发起设备连接。格式正确但设备暂不可用时仍可原位重试。

1440px 和 390px Chromium 在实际 WebUI 路由中核对缺少设备、重复设备和有效离线设备链接。离线重试只读取设备目录，手机动作高度为 44px。见 `device-task-invalid-link/browser-evidence.json`。

从设备任务返回对话时，直接写入同一设备的会话地址。已有会话使用已知会话标识，空白草稿仍指向同设备的新对话。冷启动直接打开任务时，可返回同账户、同设备上次查看的会话。历史仍在读取或失败时刷新也保留这个目标。从任务结果明确打开对话时，地址直接指向该结果对应的会话。

## 1. 参考与完成标准

参考本次用户提供的六张 ChatGPT 工作首页、项目/文件/插件菜单、添加菜单和工具标签截图，
以及已登录首页的桌面、手机响应式实测。来源为 [ChatGPT](https://chatgpt.com/) 的可观察界面，
不是对其内部代码、私有协议或后台能力的推断。参考会变化，本版规范固定本次观察。
原图和实测证据保存在 `.codex-artifacts/chat-work-experience-20261029/`。

完成标准是用户可以在首条消息发送前，用同一份草稿在对话与工作间切换、准备上下文、选择模型、编辑并发送，
切换过程连续，页面在桌面和手机上各有明确布局。不能以两张静态截图、一个会动的开关，
或只有外观的菜单代替这条完整路径。

### 能力映射

| 参考区域 | ZeroAgent 实际入口 | 行为契约 |
| --- | --- | --- |
| 聊天 / 工作 | 对话 / 工作 | 改变输入呈现与上下文入口；不另建消息历史或执行引擎 |
| 项目选择 | 当前账户项目快捷选择 | 真实列表、分页、筛选、当前项目、版本校验关联与显式移出 |
| 文件快捷选择 | 当前账户文件库 | 只引用可用原件，已有引用去重，处理中文件展示真实状态 |
| 插件上下文位置 | 工具 | 当前接入公开联网研究及数据分析引导；名称与实际能力一致 |
| 添加菜单 | 照片和文件、资料库、项目、联网研究 | 复用原上传、授权引用和研究主题确认链路 |
| 建议 | 研究问题、分析数据、撰写文档 | 填入或追加可编辑草稿；不自动发送、不启动计费任务 |
| 模型与思考强度 | 一个视觉胶囊、两个直接操作区域 | 模型名直接开模型列表，思考标签直接开滑条；共用同一弹层，长名截断，完整名称可访问 |
| 输出 / 来源 | 原成果、来源、文件资源入口 | 维持现有账户校验、预览、下载和引用 |

完整消息阅读器将正文、工作过程和关联资料分为独立区块。关联资料按首次出现的顺序列出消息附件、工具输入、来源和产出，使用同一页内列表，文件和固定成果版本按身份去重。正文与过程翻页时只显示各自的文本。产出保留版本与保存状态，打开资料沿用现有的身份核验。标签使用共享键盘导航，手机上的资料行保留至少 44px 的点击区。

会话内的工作过程、思考、工具批次和单次工具结果使用同一套折叠层级。折叠箭头常显，读屏可区分各批次的实际活动和状态，窄屏及触控设备的操作行至少 44px。收起后，仍在运行的输出可以留在内存继续累积，隐藏内容立即退出 Tab 顺序。当自动收起的区域内仍有键盘焦点时，将焦点交回其展开按钮。用户已移到其它区域时保持原焦点。

从对话打开来源引文时，记录来源标识和引用行段。快照或行段读取失败后，刷新仍读取同一来源和行段。翻页失败时继续显示上次已核验的正文，直到所请求的行段通过身份和快照校验。用户可以明确返回「全部来源」，切换引用或账户后的迟到响应不能替换当前内容。

参考中的语音、浏览器标签、相机、Figma 等第三方连接和图像生成不因界面出现同样位置就
被视为已经接入。现阶段不放置没有执行链路的按钮。后续接入这些能力必须沿用本规范的
选择、已选标签、取消、不可用原因和权限边界，不能新增另一套输入框。

## 2. 不变量

1. 主编辑器、附件列表和模型选择器各保持单一实例。切换模式不改变编辑器节点、撤销历史、
   草稿段落、大段粘贴、光标、选择范围或待发送引用。
2. 模式开关仅在首条消息发送前的新会话显示，只改变呈现，不自动切换模型、推理强度、账户、设备或联网开关。
   首次发送后及已有历史的会话隐藏切换；生成完成后不重新出现，需要另建新对话才能重新选择。
3. 项目、文件、工具属于同一份草稿/当前会话的上下文，两种呈现下必须保留并能取消。
4. 悬停、聚焦、展开菜单、切换模式和选择建议都不发送消息。联网研究仍逐次确认公开主题。
5. 会话/账户切换、权限过期后，旧请求不能更新新界面；未知提交结果遵循既有任务核对机制。
6. Desktop/设备 Agent 默认编辑器和执行权限保持原契约。CloudChat 不借“工作”按钮获得本地权限。

## 3. 桌面布局

### 3.1 页面框架与锚点

保留应用导航轨、会话侧栏与主画布。宽屏模式开关相对主画布水平居中，不跟随左侧标题长度变化；
中等窗口按标题栏剩余空间排列，优先保证操作可达和互不覆盖。
桌面内嵌云端以标题栏的实际可用宽度决定是否居中。选中背景随两个按钮平移，宽度始终等于一个按钮，横向收窄时与执行位置、主题和窗口控件保持间隔。
手机仅在云端新草稿顶栏居中显示「对话／工作」。左侧是侧栏，右侧保留执行位置及主题切换。宽度在 464 CSS px 及以下时，执行位置只显示图标与展开箭头，保留完整可访问名称和 44px 点击区。更宽时显示名称，并在模式开关与右侧操作之间留出间隔。已有云端会话继续使用原对话操作，主题仍可从顶栏切换浅色、深色和跟随系统。

隔离 Gateway 的 Edge 和 WebKit 共 18 组中文、英文及横竖屏检查，核对 320–844 CSS px 下开关居中、入口间距和 44px 点击区、可访问名称、设备面板打开及浏览器返回。412px 与 465px 的截图及测量见 `.codex-artifacts/reader-touch/image-actions/cloud-landing-spacing-results.json` 同目录。
输入框、工具栏和建议共享同一中心轴。切换模式时，输入框上边缘保持稳定；工作内容向下展开，
不能因整组内容重新居中而把输入框抛到另一个位置。

新会话的顺序为标题、输入框、工作工具栏、建议。已有消息时沿用消息阅读区与底部输入，
不显示模式切换或首页问候；历史加载、首次发送准备及生成期间也不显示切换。
完成或停止生成后仍保持已有会话布局；资源面板保持原阅读和滚动跟随契约。
开始输入或添加附件后收起首页建议，清空草稿与附件后恢复；不挤占正在编辑内容的注意力。

“新对话”只进入本地空白草稿页，重置当前编辑内容与待发送引用，不调用创建会话接口，
不向最近会话插入空记录。连续点击也不能生成记录。普通文本首次实际发送时，才沿原链路创建
一次会话并提交消息；明确保存项目关联或上传所需的持久上下文仍沿用各自原链路。
从执行中的会话打开新草稿只断开当前页订阅，不取消服务端任务；原会话及已保存数据保留。

| 项目 | 基准 |
| --- | --- |
| 输入框最大宽度 | 768px；窄窗口扣除左右各至少 16px |
| 标题 | 24px、约 1.3 行高、400 字重；不添加营销副标题 |
| 标题至输入框 | 32px |
| 模式轨 | 常规 224 × 40px；中等窗口 184px 宽 |
| 输入文字 | 16px / 26px；使用 ZeroAgent 既有系统字体和中文回退 |
| 空白对话输入框 | 约 54px 高、28px 圆角，单行内容垂直居中 |
| 空白工作输入框 | 约 128px 高、24px 圆角，编辑区至少两行 |
| 主要图标按钮 | 桌面 36px；移动触控区至少 44px |
| 工作工具栏 | 输入框两侧各内收 12px，中性薄底，无额外卡片边框 |
| 工作建议 | 3 列、12px 间距、约 128px 高、20px 圆角 |

尺寸以 CSS 像素为准，系统缩放和字体配置不能通过缩放整个页面补偿。
主画布的排版留白沿用现有品牌，不复制参考的个人项目、会话标题或第三方品牌资产。

### 3.1.1 账户与设置入口

桌面应用导航轨底部展示 40px 触发区内的真实头像/姓名首字，不放独立设置齿轮。
点击头像后，账户菜单在其右侧展开、底边对齐；顶部是当前姓名及可进入账号页的身份区域，
下面保留设置、退出等已实现动作。使用统一菜单表面、rounded-2xl 圆角及主题变量，不虚构订阅级别或入口。
会话侧栏底部不重复显示第二个账户条，也不触发共享侧栏的默认设置按钮回退。

手机展开导航时，同一个受控账户菜单位于抽屉内应用轨底部；不在历史面板重复放置账户条。
变更屏幕布局或账户时关闭原菜单；Escape/取消返回头像焦点，选择设置后仅在手机关闭导航抽屉。
默认完整设备工作台的 UserMenu 展示不受 CloudChat 的 rail 变体影响。

### 3.1.2 折叠侧栏预览

固定状态与预览状态分开。桌面收起后，鼠标进入应用导航、左边缘 10px 或展开按钮区域，
120ms 后临时展开同一侧栏；移出后等待 220ms 再收起，穿过两区交界不能闪退。
这些计时是 ZeroAgent 的体验参数，并非对 ChatGPT 内部数值的测量。
预览宽 272px，在共同页面框内内缩 4px，16px 圆角、轻边框和阴影；不加遮罩、不推动画布。
只有显式点展开或使用原侧栏快捷键才修改固定偏好。菜单、搜索对话框和键盘焦点仍可连续操作，
Escape 优先关闭内层。进入设置、切换账户/布局或明确导航后清理临时状态。
Escape 收起后，即使鼠标仍在边缘也不能立即再次展开；鼠标离开触发区域后才重新启用预览。
手机保留点击打开的模态抽屉，不将 hover 当作触屏入口。

固定侧栏展开时不启用 hover 预览；悬停其他应用导航不替换当前侧栏，点击才正式导航。
展开侧栏立即关闭已有预览并取消等待中的打开计时。侧栏收起时，主会话、正文滚动、
草稿和执行目标在预览期间不变。悬停不改变 aria-current，不发起写入、模型或设备选择。对话显示历史/项目，
资料库显示真实资源分类和最近文件。条目和导航需点击才正式打开。设备名称与在线状态在顶栏的环境切换菜单显示。
预览另一目标时，头部展开按钮表示打开该目标并固定，不把原已展开状态反向关闭。
从应用轨跨过左边缘触发区再移入预览内容时，保持已经显示的目标；完全收起后再次进入边缘，
才默认预览当前页面侧栏。切换预览目标须经过对应应用图标，不能由交接边缘隐式切回对话。

### 3.1.2.1 页面表面和对话标题

应用轨留在外层；聊天侧栏与画布在同一个四角 18px、细边界的表面内，桌面上下和右侧保留 2px 外层。
桌面标题栏 52px，首行与侧栏对齐；手机保留原较高标题栏与触控空间。
固定侧栏使用轻分隔，临时侧栏浮在当前内容上；展开/收起复用同一宽度和位移动效，不缩放文字。
减少动态时取消新增淡入；手机取消外层内缩与大框圆角，保持有效触控宽度和原抽屉。

已有消息且桌面侧栏收起时，标题前显示 36px 新对话按钮；展开时由侧栏提供同一动作。
手机保留抽屉按钮，并显示 44px 新对话触控区。新对话继续只进入本地空白草稿。
页头和侧栏的新对话使用同一个编辑图标；默认 Desktop 图标不因 CloudChat 扩展改变。
标题悬停出现编辑图标和浅底，点击或键盘激活进入行内编辑并全选。Enter/失焦保存，Escape 撤销，
IME 组合输入不提交。保存期间输入只读，焦点可继续移到其他操作。失败或空值在原标题处保留文本和提示，
用户回到标题后可修正或重试。编辑结束时只有焦点仍在标题输入框内才交还标题按钮，Tab 或点击离开后焦点留在目标位置。
改名使用原会话 PATCH，历史列表同步，不重建编辑器或任务。标题按可用空间截断，手机不覆盖环境/更多入口。
账户失效守卫清空旧内容后提供明确的刷新提示，不能只剩空白；不自动重发或绕过账户验证。
实现边界见 [ADR0054](../product/decisions/0054-cloudchat-conversation-chrome-context-preview.md)。

### 3.1.3 设置页面

按实际观察的 ChatGPT `/settings/general-settings`，设置属于应用内页面：最左应用轨保留，
聊天侧栏替换为设置标题、搜索及真实分类，右侧显示所选内容。没有覆盖聊天的绝对定位层或模态遮罩。
设置侧栏复用聊天/资料库的页面背景和 272px 宽度、17px 标题、36px 导航项、8px 圆角与 16px 图标；
导航 hover、选中和键盘焦点共用相同规则，搜索使用轻灰输入底面，不另套一套深灰导航主题。
内容最大 768px，标题与正文对齐；导航、正文分别滚动。设置期间聊天树保持挂载并隐藏/inert，
返回后保留编辑器节点、草稿、引用和原任务订阅，不隐式新建、发送或取消会话。
进入设置只增加一次浏览器历史项，分类变化更新同一项。设置的返回按钮和浏览器后退都回到本标签的原工作台位置。会话、资料阅读器和选中的定时运行仍在时直接恢复原界面。正在阅读较早消息时记住消息及其视口位置，以此恢复虚拟列表。刷新设置后通过原历史位置恢复。直接打开设置链接时，返回当前账户的对话入口。设置历史按账户隔离，桌面嵌入沿用宿主导航。
保留原主题、字体、保存指示和账号权限，默认设备工作台设置页不改用这一可选布局。

820px 及以下设置改为单列分类列表，条目触控高度至少 48px。选择分类进入详情，详情顶部“设置”
返回分类列表；列表提供「返回工作台」，触控高度至少 44px。详情长内容内部滚动，不挤压为双列或横向分类条。
320px、390px 和 820px 边界必须检查；真机返回键/输入法仍需单独验收。
决策与边界见 [ADR0053](../product/decisions/0053-cloudchat-sidebar-preview-settings-page.md)。

### 3.2 对话输入

空白与能容纳的单行草稿保持胶囊形。输入换行、文字超过当前可用宽度、出现不可编辑引用块
或添加附件时展开为多行，控制按钮留在底边。文本重新能容纳时可收起；有附件时不强行收起。
宽度判断要同时考虑实际字体、模型标签、已选工具和窗口尺寸，不能使用字符数阈值。

测量采用不参与可访问树的纯文本宽度测量，不能复制一个隐藏编辑器来持有第二份草稿。
不要把动画 transform 施加到文字、光标或整张输入卡片来伪装高度变化。

### 3.3 工作输入

工作模式直接展示多行编辑区。模型与发送控制位于右下角，添加入口位于左下角。
工作工具栏包含项目、文件、工具；选中项目显示真实名称并截断，完整名称保留可访问标签。
名称很长时不能把文件和工具按钮挤出工具栏。
共享编辑器的容器查询不能把 inline 模型控件收成空按钮；中等窗口仍显示模型/强度标签，
空间不足时截断文字并保留完整可访问名称。

云端对话和工作、本机及远程设备的新对话都在问候上方显示同一枚 ZeroAgent Logo。工作首页直接提供三项可交付任务，说明预期产出，桌面在输入区下方并排展示，手机竖屏在问候下方纵排，短横屏并排展示。手机输入栏保持在底部。普通对话用轻量建议帮助提问或整理内容，设备新对话示例围绕项目、故障和实现方案。
点选示例将提示词加入当前草稿，保留已有正文与引用并将焦点移入编辑器。已有草稿仍可追加工作示例，手机键盘打开时隐藏欢迎区。空白对话的示例选择本身不启用工具或创建运行。
如果当前草稿正文已包含完整示例，再点同一示例只把焦点移回编辑器。其他示例仍可追加，移除原示例后可以重新添加。

以 `22fd2c3f` 为基线，在同一工作树构建 Windows Debug、Gateway WebUI 和 Android 开发版。WebUI 在 320、390、412、914 和 1440 CSS px 验证布局、示例追加与模式切换，含英文 412 CSS px 和深浅主题刷新。Windows 本机、浏览器远程和桌面远程验证了新对话 Logo 与示例，并用同一设备会话、Markdown、PNG 及 200 CSS px 文件树复验草稿、标签、焦点、断线重连及授权失效。最终的手机顶栏间距由 WebUI 与 Android 单独复验。

以 `45d07772` 为基线，在同一工作树构建 Gateway WebUI 和 Windows Debug。390 和 1440 CSS px 的云端工作页验证同一示例只插入一次、其他示例可追加、移除后可重加，390 CSS px 另验刷新恢复的草稿。Windows 本机、浏览器远程和桌面远程均验证设备示例去重，并用同一设备会话、Markdown、PNG 和 200 CSS px 文件树复验草稿、标签、焦点、断线重连及授权失效。

「文件」弹层同时服务两个入口。可从已加载的资料里筛选并引用，也可直接打开系统文件选择器上传。

待确认处理和账户范围检查。

### 3.4 模型、思考程度与输入操作

常态是一枚连续的视觉胶囊：厂商图标、模型名、弱化的思考短标签和展开箭头。
模型区域直接打开模型列表，思考区域直接打开离散滑条；各自有完整的可访问名称与独立焦点。
不增加两套按钮外框或两份配置状态。整体 hover/展开时出现很浅的统一底面，当前指向区域提亮文字。
名称过长时仅截断模型名，保留思考标签和停止入口；完整名称在提示与可访问名称中可读。
滑条内的模型名称进入模型列表；模型页头的思考短标签返回滑条。点击任一区域均应直接到达对应页面，
包括从弹层内部导航后再次点击原触发区域，不能意外关闭或要求重复点击。
显式 `/model` 请求直接进入模型列表；不支持调节思考的模型也直接进入模型列表。
弹层默认在下方展开，靠近底部时自动翻转；最多一个弹层，不叠第二层菜单。

模型列表每次打开自动展开当前分组/厂商，并只滚动列表内部使选中项可见。手动折叠不被普通重渲染覆盖。
搜索、排序、刷新及厂商归并后的“模型→具体分组”两步路由选择保留，浏览不改变模型、分组或密钥。
这是 CloudChat 的显式 opt-in，默认设备/设置选择器继续遵循原默认折叠契约。
厂商图标复用 ProviderBrandIcon 与已有库资产，优先按模型身份识别。

两页共用同一锚点和 312px 宽、18px 圆角的表面，最大宽为视口减 32px。
桌面思考页常态约 101px 高；模型页随列表内容增长，列表在可用高度内独立滚动。
页面及说明展开使用 180ms 高度过渡，快速反向从当前可见高度继续；文字不缩放，减少动态时直接切换。
顶部居中显示当前档位，下方模型名称可点击；左侧问号实际控制当前档位说明，右侧恢复默认。
恢复仅使用宿主既有默认思考值，并明确提示将恢复到哪一档，不冒充跨模型的“推荐组合”。
模型页不在日常选择行塞入配置编辑入口；完整模型/供应商管理继续在设置及默认选择器中提供。
使用原生 range 承载输入，刻度沿用宿主传入的参数选项与保存链路，不另建静态模型能力表；思考强制开启时不出现关闭档。
鼠标/触屏拖动即时预览，松手提交；键盘方向键/Home/End 调节、松键提交，失焦提交，Escape 取消尚未提交的预览。
预览属于开始拖动时的模型；模型变化后不得通过迟到的失焦/松手事件写入另一个模型。
调节后弹层保持打开，原模型、分组和运行方式保持。说明按需展开，解释投入与等待时间，不承诺结果质量。
所有思考档位使用蓝色进度与白色滑块；最高档通过刻度、标签和进度表达。
紫色协作、Ultra、Fast、跨模型推荐均须有真实能力契约后才能出现，不借装饰暗示不存在的执行方式。
ReasoningSlider 将指针的连续位置与离散参数分开：拖动保留小数位置，最近档位仅用于标签预览，松手才吸附并提交。
不以step=1驱动视觉位置。进度和视觉圆钮使用独立的transform轨道，拖动时无过渡延迟，松手/键盘换档时220ms平滑归位。
轨道24px、圆钮28px、静态点4px；仅鼠标指向的档位点在120ms内放大至8px并略微加深，其余点不一起变化。
滑条使用手型光标，悬停档位点不更改参数；手柄自身Hover/按住时平滑放大至1.1倍，不改变轨道与档位位置。
说明、恢复及模型导航有明确的 Hover/按压反馈。
键盘保持整档调节，Escape/指针取消恢复，模型变化重建滑块的局部拖动状态；减少动态只取消归位过渡，不破坏连续跟手。
说明只保留当前档位的用途，不重复“模型和分组不变”等实现解释。
分组/厂商切换在同一帧确定展开项并完成列表内定位，不先绘制折叠态；列表轻微过渡，减少动态时取消。
刷新保留已有结果并明确指示加载，初始无结果时展示骨架，不把加载状态当作空结果；刷新按钮复用共享反馈。
触屏打开模型列表聚焦面板，不自动弹出搜索键盘；滑条和弹层保持键盘可达与清楚焦点。

发送是输入区唯一的深色主操作：圆形轮廓、斜向箭头、轻内沿与克制投影，hover 仅让箭头略向发送方向移动。
模型目录或账户模型偏好尚未读取时，对话与工作仍显示原首页和同一个可编辑草稿。上传、引用和执行位置沿用现有权限，
发送和加入发送队列等到可用模型和账户偏好都确认后才启用。读取失败或目录为空时，在输入区附近使用共享状态提示，
提供「重试」和「模型设置」。重试只读取缺失的账户偏好并刷新目录，保留草稿、输入节点及已知模型配置；恢复后由用户发送。
手机让两个动作留在内容区并保持触控尺寸。已运行的任务仍可停止，已有提交的回执仍可核对。
没有确认模型时不显示默认模型或推理档位。宽屏用键盘重试，提示消失时把焦点还给原输入区。手机重试后不自动打开键盘。
生成时同一个真实按钮平滑扩为“停止”胶囊，使用实心小方块与文字；沿用原停止/队列语义。
不把停止涂红，不借动效模拟发送完成；禁用态弱化且取消投影。减少动态时取消位移与过渡。
添加按钮默认是干净的加号，hover/展开呈轻灰圆底，展开时转为关闭形态。
菜单锚定触发按钮，使用紧凑可扫读的图标、标题、说明及统一圆角；保留原真实资源动作与焦点返回。
手机模型与思考区域、说明/恢复、面板内模型导航及滑条触控高度至少 44px。
因此手机思考面板约 132px 高，不机械套用桌面密度；320px 视口的面板宽 288px、左右各留 16px。
停止胶囊固定占 70px × 44px，宽度动画期间也不能挤出主操作，模型名优先收缩。

### 3.5 提示与层次

助手回复下方不显示“回复信息”按钮及其元数据弹层，各端共用同一消息操作栏。
回复的模型、思考、状态及用量数据仍由原运行和存储链路记录，不因精简操作栏删除历史数据。
消息操作栏对鼠标保持轻量，悬停所在消息或键盘焦点进入操作栏时显示。手机触屏直接显示可用操作，采用连续的 32×36 CSS px 点按区，保留清晰的图标、独立的命中边界和键盘焦点。操作行靠近正文，时间紧随操作组，极窄分栏可以整体换行。操作顺序与确认规则沿用当前消息。

本轮以 `f7291bc1` 为基线，在同一工作树构建 Windows 桌面、Gateway WebUI 和 Android 开发版。Android 模拟器用实际远程设备会话验证了两种消息操作行，手机 WebUI 在 320、390 和 914 CSS px 宽度复测。桌面本机、浏览器远程和桌面远程用同一设备会话、Markdown、图片及 200 CSS px 文件树复验了历史、草稿、标签、焦点、断线重连和授权失效。

短 tips 使用近黑胶囊、14px/600 字重白字、6px 侧距和软投影；不缩放文字，淡入只改变透明度。
只有已经实现的快捷键才显示在半透明浅色小胶囊内。长说明和结构化统计使用较小圆角，保持阅读空间。
展开菜单期间抑制触发器提示，disabled 不悬浮提示；原 aria-describedby 与门户层级保持。
白色选中胶囊高 40px，底轨高 32px，上下各外扩 4px；选中以表面和轻边界表达。
对话/工作 hover 只提亮文字，不新增灰底、描边或阴影。点击推动选中块，聚焦不切换模式。
这种层次规则贯穿输入区：常态减少边框与背景，只有主操作、当前选择和展开表面承担视觉重量。

实现边界见 [ADR0056](../product/decisions/0056-cloudchat-composer-controls.md)。

## 4. 切换与动效

参考页可直接读取到编辑区 300ms 的 min-height 过渡及 `cubic-bezier(0.23,1,0.32,1)`。
下面其余数值是 ZeroAgent 的实施参数，不能称为反编译获得的 ChatGPT 原始参数。

| 部位 | 实施规则 |
| --- | --- |
| 选中滑块 | 240ms；横向移动，无弹跳；选中底为同一真实元素 |
| 编辑卡片高度 | 300ms，`cubic-bezier(0.23,1,0.32,1)`；不拉伸内容 |
| 编辑卡片圆角 | 同步 300ms，从 28px 到 24px |
| 标题 | 淡入淡出 160ms、最多 5px 位移；始终只有一个可访问的一级标题 |
| 工作工具栏 | 0fr / 1fr 展开 300ms，透明度 160ms；不挂载第二份编辑器 |
| 菜单与提示 | 使用共享 Popover、Sheet、Tooltip 的既有进出与定位 |
| 悬停 | 仅颜色、边框和轻阴影；不缩放按钮，不让列表或正文位移 |

快速往返时，从当前可见高度反向继续，取消旧动画，不排队重播。初次加载不从零高度播放。
编辑文字和附件预览不整体缩放，模型与发送控制以当前卡片底边定位，不在过渡中被裁掉后弹出。
系统启用减少动态效果时，切换立即完成，所有可用入口与焦点反馈保留。

### 状态转换

| 起点 / 操作 | 结果 | 必须保持 |
| --- | --- | --- |
| 空白对话 → 工作 | 多行输入、工具栏、工作建议 | 模型、会话、执行目标 |
| 有草稿对话 → 工作 → 对话 | 同一内容按能否容纳恢复形状 | 段落、引用、选择范围、附件 |
| 菜单打开时切换模式 | 先收起上下文菜单，再切换呈现 | 草稿与已选工具 |
| 未发送草稿上传附件时切换 | 仅改变呈现，不重发、不取消上传 | 正在上传的附件状态 |
| 首次发送、已有消息或生成中 | 隐藏模式开关；完成/停止后仍隐藏 | 当前输入呈现、模型、真实任务与草稿 |
| 连续快速切换 | 最后一次选择立即生效，动画追随当前状态 | 不增加编辑器/模型控件实例 |
| 资源页返回对话 | 回到同一会话和草稿 | 未保存项目编辑仍受原导航保护 |

## 5. 上下文交互

### 5.1 项目

桌面使用锚定按钮的紧凑选择层，包含筛选已加载项目、新建/管理、项目列表、当前选择和分页。
不要把本地名称筛选说成全库服务端搜索。当前已关联的项目必须有标识，支持显式移出。

项目选择层在桌面和手机上都固定显示当前项目的图标、名称和移出操作。筛选及分页只改变其他可选项目，
不会隐藏当前项目。项目管理放在列表末尾，打开项目页时保留原会话与草稿。只有已明确发起的关联变更才改变选择。

选择项目时先读取当前服务器关联版本，再按 expected_version 更新。冲突显示可理解的错误，
只有用户再次选择才重试；不能静默覆盖另一页面的变更。选择更新中禁用重复变更和发送。
选择完成后再更新名称，不以乐观勾选冒充保存成功。
如果会话的项目刚在其他端改过，选择器保留筛选和原列表，就地重新读取当前归属并显示在已选区。
用户从同一层再次选择才会写入。归属暂时读不到时提示尚未核实，保留最后一次已确认的项目和未发送草稿。
即使变更早于点击，也先比较最新归属和用户在选择器看到的归属。已确认的新归属同步到侧栏，旧请求迟到时不能覆盖它。
同一会话的侧栏刷新不重置打开的选择器或取消已发起的选择。

新草稿选择项目时仅更新草稿上下文，首条消息发送时才创建一次会话并关联项目。
保留完整结构化草稿、附件和成果引用，创建与关联均绑定原账户及当前视图。
项目详情页的编辑、未保存保护和原关联入口继续可用。

从输入框的「选择项目」内新建时，沿用共享创建弹窗。空白草稿显示「创建并选择」，创建后立即回显项目，
保留输入、附件和模型，首条消息发送时才创建并关联会话。已有会话显示「创建并移入」，沿用项目关联版本检查。
保存中禁止重复提交，关联失败后只重试关联并在弹窗内说明结果。取消或保存后焦点回到打开项目选择的按钮；
按钮已离开时回到原输入框。桌面锚定菜单和手机选择层进入同一弹窗，侧栏的普通创建仍只创建项目。
弹窗标题下直接说明保存后的去向，名称是唯一输入项。标题、表单和操作栏共用两侧对齐线，手机的两个操作可在同一行操作。
选择器及输入框回显复用侧栏的项目图标和颜色。输入区的可关闭反馈不应产生横向滚动。

### 5.2 文件

快捷选择层展示当前账户的真实文件，可筛选当前已加载页、显式继续加载及浏览完整文件库。
ready/vision_ready 才可引用；上传中、处理中、失败和删除中的条目展示真实状态，不能假装已解析。
文件名作为文本渲染，不解析其中的 HTML。引用只携带文件身份，继续由服务端做账户校验。

已在草稿中的文件显示已添加并禁用重复选择；文件和成果共用每条消息最多 8 项的原限制。
选择后关闭浮层并返回同一编辑器。失败留在选择层解释原因，用户可以重试或取消。
文件和项目选择器区分首屏读取、加载更多和选择失败。分页失败时保留已读取条目、搜索词和当前位置，
在列表下方用同一个按钮重试原页。已读取的条目仍可选。手机继续使用原底部面板和触控尺寸，重试结束后不自动弹出键盘。

### 5.3 工具与已选标签

完整账户资料页已按[个人资料空间规范](cloudchat-personal-space.md)升级：独立上传、全库名称搜索、
分类/文件夹/收藏/回收站、真实容量，以及原件与不可变成果版本的接续。上节快捷选择层仍明确筛选已加载页，
“浏览全部”进入完整空间；页面和快捷选择不是两套原件权威。边界见[ADR0057](../product/decisions/0057-cloudchat-personal-space.md)。

公开联网研究由用户显式开启，主输入区域显示可移除标签，在对话/工作间保持。
标签移除、菜单取消和模式切换不能发送请求。发送时仍走公开研究主题确认，私有草稿不复制到搜索主题。
数据分析入口准备可编辑的目标文本；真正执行仍在用户发送之后由既有 Go 工具循环处理。

工具选择不修改平台模型授权，不自动提升设备或文件系统权限。未来第三方连接应清楚展示
未连接、连接中、已连接、授权过期及不可用原因，不能沿用一个永远成功的装饰性勾选。

### 5.4 添加菜单

加号服务对话与工作。上传、资料空间引用和项目放在前组，生成图像、插件与技能、数据分析和公开联网研究放在第二组。
生成图像只在当前账户启用了该能力时快捷显示。安装更多扩展时菜单高度保持稳定。加号里的「插件与技能」与工作工具栏的「插件」打开同一个选择器。
选择器把可用插件和独立技能分别成组，搜索同时匹配本地化和原始名称。搜索仍返回插件本身，内置技能从详情查看。
主行添加或移除引用，末尾箭头打开详情。探索目录是选择器尾部操作。目录加载失败时在选择器内重试，保留草稿和搜索词。
桌面选择器与加号菜单同宽，切入时聚焦搜索。手机底部面板打开时聚焦面板。
Esc 返回触发入口，选中引用后把焦点交回原草稿。中英文同步覆盖模式、菜单、资料引用动作、研究状态和辅助标签。

桌面使用 352px 紧凑菜单，锚定加号并留出约 8px。图标靠左，操作名称与短说明上下排列，
空间不足允许说明换行。按可用空间自动翻转，菜单内部滚动，不能把内容挤出窗口。
手机保留视口两侧至少 16px；照片/文件调用原系统选择器，资料库/项目调用同一快捷选择层。
菜单之间互斥；展开菜单时让位于共享 Tooltip。

## 6. 手机布局

### 6.1 正常竖屏

820px 及以下使用紧凑布局。收起导航时主画布使用全宽；展开时同一个模态抽屉包含52px应用轨与历史/资料导航面板。
面板常规280px，两列总宽最多332px，同时为右侧上下文保留至少48px；320px下自动缩窄面板，不挤掉应用轨。
轨底部保留唯一头像，面板标题只展示文字，关闭使用清楚的X；导航操作命中区至少44px，复用桌面图标与四态。
背景使用主题底色60%的退让层，保持正文轮廓清晰，不叠深灰遮罩或背景模糊。此为共享Sheet的navigation语义变体，
默认对话框、资源和项目选择Sheet保持原样。应用轨与面板在同一模态内，焦点/返回/点外关闭统一管理。
移动端仅挂载当前导航面板；切换页面或选择会话后收起抽屉，主编辑器和运行订阅保持。
模式开关保留在顶部，
标题栏资源入口合并进更多菜单；执行环境仍有明确可访问名称和可操作入口。

输入框固定在可用画布底部；工作工具栏在输入框上方。首页问候占剩余空间的中部，
不能为了显示长介绍把发送控件推出首屏。手机不使用被按钮挤到只有几个字宽的单行编辑区，
对话和工作都保留独立输入行，模型和发送位于下方。

工作建议为横向滚动卡片，默认露出下一张的一部分，采用 scroll-snap；不压缩成三张细长卡片。
聊天建议是较轻的纵向入口。左右边距至少 16px，输入字体不小于 16px，避免聚焦触发页面缩放。

### 6.2 键盘、安全区与短窗

复用已有 `--zeroagent-visual-viewport-height`、安全区和 Android IME 桥，不建立第二套键盘高度权威。
键盘打开时隐藏首页问候和建议，保留输入、工具栏和发送；键盘关闭后恢复，不清空草稿。
首页底部取 36px 与系统安全区的较大值；键盘打开时收紧为 8px，短窗取 12px 与安全区的较大值。
窄屏首页把输入区留在底部，问候与示例在上方独立滚动。可用高度充足时问候和示例居中，空间不足时从顶部开始，仍可滚到最后一项。短横屏用三列工作示例减少纵向占用，窄屏窗口的鼠标操作也使用同一布局。打开键盘后隐藏欢迎区，继续编辑原草稿。

以 `692b801c` 为基线构建 Gateway WebUI。320×390 CSS px 验证最后一项示例可滚动点选且发送按钮持续可见，760×320 CSS px 验证三项示例同屏以及资料菜单可滚到「数据分析」并填写草稿。320×660 和 1440×900 CSS px 复查输入区和示例。截图位于 `.codex-artifacts/compact-audit/`。

Android 返回键先按现有桥收起键盘；抽屉与选择层的返回/关闭由共享模态组件消费。
手机 Web 保留正常浏览器缩放与输入行为，不为模仿设备外观绘制状态栏、刘海或键盘。

### 6.3 手机选择层

项目、文件、工具使用同一共享底部 Sheet，最大约 70dvh，上方标题和关闭入口固定可达。
打开时聚焦选择层，不自动聚焦搜索框而召唤键盘；只有用户点搜索才进入输入。
列表独立滚动，不让背景会话跟着滑。完成文件选择返回编辑器，取消返回原触发器。
外部点按、Escape、关闭按钮与 Android 返回应遵循同一关闭路径。

### 6.4 错误与状态反馈

任务失败、停止或中断的提示放在对应会话的消息阅读列末尾，与消息一起滚动；不使用横跨整个
画布、固定在页头的横幅。保留已生成内容和原请求的编辑/重试入口，点击编辑只打开原消息编辑区，
编辑器在重发按钮旁说明此操作会替换当前消息并移除后续对话。新任务被服务端接受后，同一会话展示新的回复，独立输入草稿保留。看到的是历史搜索窗口且尚未加载后续消息时，先回到最新消息。请求被拒绝或结果未确认时保留现有历史，结果未确认通过同一请求标识核对。用户也可以从消息菜单显式创建分支。历史恢复的终态使用 status，不在每次进入会话时播报紧急警报。

发送失败、提交结果待核对、队列已满和分支状态待确认靠近输入框展示，让原因与下一步操作相邻。
未知提交结果只提供原核对入口，不能改成自动重发。关键失败和待核对提示不定时消失，不能随意关闭。
准备参数、上传和导出使用紧凑状态行；普通上下文说明可提供明确关闭按钮。

打开已有会话时分别处理历史消息和当前运行状态。运行状态暂时读不到时，已读取的对话和资料继续可用，草稿可编辑，发送和重发等待状态核实。输入区用共享反馈提示，并提供「重试读取运行状态」。重试核对同一会话的活动运行，若没有活动运行则按最近已读的用户消息查找终态。只有发现活动运行的用户消息还缺失时补读历史。找到运行后沿原游标接续。打开明确的历史消息地址时可先阅读该段，返回最新消息后再核对运行。

统一使用 CloudChatFeedback：12px 圆角、中性薄底和轻边界，16px 状态图标；严重程度通过图标与文字
共同表达，不铺大面积红黄底色。主文案 14px/21px，说明 12px/18px，先说明结果，再给用户能采取的动作。
桌面操作靠右，窄屏移到文字下方，允许长文案换行，手机动作至少 44px。
输入区多条反馈最多占 min(32dvh, 240px)，超出后在组内滚动；高度必须计入原输入框测量，不能遮住
正文末尾或另建键盘高度权威。新增组件只负责呈现，恢复、取消和关闭条件仍由原业务状态决定。
实现边界见 [ADR0055](../product/decisions/0055-cloudchat-contextual-feedback.md)。

### 6.5 鼠标光标

按钮、链接、可点击导航/列表、菜单项、选项、页签、开关、原生选择器及可展开摘要使用手型光标。
共享基础样式按真实 HTML/ARIA 交互语义提供默认值，Portal 菜单也遵循同一规则；不能只给带 Tooltip
的按钮补样式，或把所有 div/带 tabindex 的容器都标成可点击。
文字输入和编辑区保留 I 型光标；禁用控件不能显示可点击手型，原有禁用/只读及点击守卫继续有效。
拖动、缩放、预览放大等专用光标由对应控件保留，正文和普通提示不显示手型。
仅统一 cursor 呈现，不用鼠标监听器、浮动假光标或新增点击行为实现。

## 7. 键盘、输入法与可访问性

- 模式控件使用原生按钮及 aria-pressed，同组仅选中项进入 Tab 顺序；左右箭头、Home、End
  可选择并移动焦点。普通聚焦不切换模式。
- 点击模式开关后焦点留在模式按钮，不能强制弹出手机键盘；回到编辑器时继续原光标位置。
- 编辑器 Enter、Shift+Enter、中文 IME composition 与原发送判定保持，不因动画注册另一套快捷键。
- 项目/文件筛选框可用向下键进入条目，条目上下键移动、Enter/Space 选择；Escape 关闭。
- 菜单打开时关闭 Tooltip；选择、移除、加载、失败均有可读名称，不用颜色作为唯一状态。
- 模式标题的视觉交叉淡变不能产生两个可访问 h1；隐藏工具栏同时退出焦点与可访问树。
- 焦点环可见。深色、强制颜色和减少动态效果不能丢失选中或操作反馈。

## 10. 会话选项与最近列表

按 ADR0061，页头不再显示“资料”资源菜单。会话选项仅包含重命名、置顶、归档、删除和
移至项目；状态变化后显示取消置顶/取消归档。空白新对话不显示该菜单。
宽屏对话顶栏保留标题和相关对话，重命名进入标题输入框。手机对话顶栏省去标题与相关对话，保留对话选项。通过选项重命名时在弹窗中编辑，关闭后焦点回到选项按钮。会话列表继续显示标题，消息上的分支操作保持可用。删除使用带会话标题的确认层，取消不改变内容。
项目采用二级菜单，显示当前归属、新建项目、加载与失败反馈及分页；窄屏自动避让边缘。
新建成功后关联失败只重试关联，创建结果未知时保留核对提示，不重新创建。
最近列表标题为可聚焦的折叠按钮，折叠保留项目区、当前会话、草稿和阅读位置。

桌面、设备 WebUI 和云端共用对话搜索弹窗。顶部固定输入、「清除搜索词」和「关闭」，清除后回到置顶与最近对话并可继续输入。手机使用共享命令面板的可见视口布局，软键盘出现时让结果区独立滚动，保留关闭入口和 44px 触控区，键盘提示仅在宽屏鼠标环境显示。宽屏保持现有命令面板与方向键。首次搜索失败仍保留关键词，键盘重试回到输入框。分页加载期间保留当前行、滚动位置、分页按钮和键盘焦点，失败后重试原游标。最后一页到达后，焦点仍在分页按钮时，键盘操作回到输入框。关闭搜索回到原触发位置。

手机短横屏弹出键盘时，搜索弹窗按可视视口和刘海安全区定位。搜索栏保留 44px 的输入、清除和关闭区域，结果区收紧分组间距，列表、分页和错误重试在同一区域内滚动。键盘收起后恢复常规间距，搜索词和结果保留。打开属于当前会话的结果时，可定位到历史消息并继续编辑当前草稿和待发送附件。

横屏键盘只留下不足 124px 的可用高度且宽度足以容纳两列时，搜索栏与结果并排。结果保留标题、单行匹配片段和 44px 触控区，分组仍供辅助技术识别。结果侧独立滚动，续页与重试都在这一侧；点击命中项可直接打开。系统返回收起键盘后恢复上下布局，继续使用原搜索词、结果和草稿。

设备会话搜索与会话列表、读取历史使用同一被控设备的引擎和会话标识映射。搜索结果带回可直接打开的会话及消息标识，沿用设备连接与授权边界。会话历史与滚动视口就绪后定位到匹配消息，关闭导航抽屉时也保留该位置。正常从会话列表打开时仍显示最新消息。
云端账户切换或登录失效时关闭搜索并清除原查询和结果，迟到的搜索响应不能打开会话。
结果把会话名和时间放在同一行，工作区和匹配类型作为辅助信息。手机输入时优先留出正文片段与下一条结果的空间。

菜单定向 8 项通过。Web 类型、三个变更源文件 Biome、产品契约及 UI 边界检查通过；
Web 和 embedded-mobile 前端构建通过。浏览器确认最近列表收起/展开、重命名焦点及
Escape 取消、新建验收项目并移入当前对话、当前项目选中状态和删除确认取消。
390px 视口主页面宽度为 390px，二级菜单全部位于屏幕内。未执行实际删除或新模型请求。

## 11. 阅读工作流收敛

按 ADR0062，最近/置顶/归档筛选胶囊从对话侧栏移除。最近列表接近滚动底部时自动续载，
滚动位置、当前对话与正文阅读不随列表追加而重置；一次只加载一页，读取失败才给出重试。
正文上方不再重复汇总本会话附件和成果，相关资料只在所属消息与回复中出现。

多轮阅读复用现有 FloorNavRail 的短线、波形悬停、预览卡、当前楼层与消息跳转，不另建
CloudChat 专用导航样式。导航作用于当前已加载的消息；历史分页仍遵循既有边界。
导航和回到最新消息按钮复用输入层的实际高度测量，避开编辑器、工具栏和安全区。

侧栏、输入框项目选择器、项目管理中的新建入口和会话菜单的新建并移入共用
CloudProjectCreateDialog。弹窗包含名称、
用途说明和创建状态，遵循共享圆角、表面、焦点、动效与按钮规范，不以新页面打断对话。
会话菜单创建后执行关联，侧栏创建仅保存项目；未知结果不自动重发。账户变化关闭原创建
上下文，名称草稿不带到新账户。

2026-10-31 实际验收：Page、菜单、导航、侧栏续载和既有楼层组件共 165 项回归通过；
新增切号保护用例单独通过。共享 UI、Web、GUI 类型检查及产品/UI 边界通过。
浏览器用 End 键滚动侧栏后，列表高度由 1613px 增至 2441px，未点击加载按钮；连续切换

## 18. 阅读器完整交互对齐（2026-11-01，实施方案）

  可 hover 的剩余宽度。文档页、加载图标、滚动条不因工具开关挪动或重新读取原件。

### 在所选设备继续新任务

在共享任务弹窗选择设备后，继续操作直接打开该设备的新任务编辑器。已写入的任务名称和说明一同带过去。按钮旁说明时间、模型、资料、审批和工作区仍需根据该设备重新确认。设备读取成功后以它的时区显示下次运行预览。设备处于纯对话模式时仍显示带入的提示词，并解释启用条件。桌面与窄屏沿用现有任务页面和编辑弹窗，选择位置本身不保存或运行任务。

设备任务编辑器沿用同一个放弃修改确认，涵盖名称、时间、执行方式、工作区、模型以及脚本和 HTTP 草稿。新任务从工作台交接的名称与说明仍是未保存的输入，即使在设备编辑器里尚未继续修改也应保护。浏览任务类型、展开配置或关闭未修改的已保存任务可直接返回。继续编辑保留原表单与下次运行预览，保存成功后正常关闭。

390px 浏览器预览用真实设备编辑表单和模拟预览验证，交接草稿在 Esc 后出现确认，继续编辑保留同一输入和预览。1280px 设置表单能直接关闭未改动的任务，输入未写完的 HTTP 头后点击窗外也可继续编辑。两条路径均未写入任务。见 `device-task-editor-discard/browser-evidence.json`。

### 设备立即运行的回执核对

「立即运行」先在当前账户、设备和任务下记录一个执行标识。设备调度器以此标识准入，沿用原先的并发、权限和不扣减计划次数的规则。正常收到回执后直接打开本次记录。桌面、手机和 Web 的任务详情共用状态提示。回执丢失后，同一按钮变为「核对运行」，通过原设备授权读取该标识的记录。已准入的记录可在设备重启后识别。核对期间保留任务、地址和既有输出。

设备已经接受运行、但列表暂时还没有这条记录时，在该次运行的地址提示已接受和记录等待状态。期间不显示新的「立即运行」或其他运行的输出。重试只读取设备历史并核对原执行标识。记录出现后继续展示本次结果，也可以从等待状态明确返回计划。宽屏和手机共用状态提示及操作。

390px 的实际任务组件复验记录先收到回执、历史读取失败和重试成功三个状态。只有一次执行提交，重试按钮为 44px，见 `device-run-admitted-read/browser-evidence.json`。

若读取成功仍没有匹配记录，提示用户检查原设备。可显式结束核对以重新开启一次操作，结束核对不发起执行。定时触发、其他客户端的立即运行和相近时间的记录都不会被当作本次回执。旧设备缺少该接口时显示更新提示。工作台在未知结果时不重放写请求。

用户离开任务或选择了另一条运行后，迟到的回执保留原核对入口和当前阅读位置。回到任务时可以显式核对。

### 从任务运行阅读资料

从任务结果或详情打开文件、来源或产物时，阅读器留在该次运行的工作台。URL 记住计划、运行记录和所选资料，
文件与来源引用可记录行段。刷新先核对所选运行，再恢复阅读器。关闭只退回这次运行的正文，保留追问草稿，
焦点回到触发入口，移动端已收起详情时回到「任务详情」。在产物阅读器切换版本更新当前阅读记录。
用户另选任务或运行时关闭旧阅读器。资料读取继续经过当前账户的资料权限检查。桌面宿主用同一任务路由保存阅读位置。

在手机上从详情打开资料后，再次展开同一次运行的详情，会从上次的滚动位置继续，焦点回到刚打开的那条资料。只恢复一次。如果该条资料未出现在当前详情，或打开了其他运行，则焦点仍从详情的关闭按钮开始。

390px 浏览器使用实际任务详情组件与模拟阅读器宿主复验。打开来源、关闭阅读器并用键盘重开详情后，滚动位置、选中运行和追问草稿均保留。见 `task-resource-return-focus/browser-evidence.json`。

### 设备运行记录读取失败

设备任务计划仍可读取时，单个任务的运行记录读取失败只在结果区显示重试。桌面和窄屏沿用同一个内容区状态提示。之前成功读取的记录、当前选中输出和原会话输入区保留，任务列表及计划操作继续按设备权限工作。暂无记录仅在确认列表为空时显示。缓存按当前账户、设备和任务读取，切换上下文后忽略迟到的响应。

从含运行标识的设备任务链接打开时，结果区依次区分正在读取、暂时读不到设备记录及所选运行不在设备可读取的历史中。所选记录未确认时保留原地址，正文不显示当前计划或其他运行作为替代。重试只读取设备现有记录，显式「返回任务」才清除运行标识。重试恢复或返回任务时，焦点回到该任务标题，手机使用同一提示和触控操作。

### 任务首页、筛选与恢复

工作台先区分正在读取、部分来源不可读、当前筛选无匹配和确实没有任务。已有列表时，宽屏画布引导选择任务查看计划和结果，手机直接展示列表。只有当前目标范围读取完成且没有任何任务时，首页才显示第一项任务的创建按钮和可用的云端示例。手机空页将新建动作集中在画布，已出现任务后由列表承接。示例以画布实际宽度决定一列或两列，点击只填入草稿。

无匹配时从列表清除状态、执行位置及搜索。来源未读取完时保留查询、已知任务与当前所选结果，不把读不到的数据算作无匹配。重试只重新读取任务列表，沿用当前连接和执行权限。

状态或执行位置有筛选时，在任务侧栏固定区显示当前条件和「清除筛选」，有结果时也可直接恢复全部任务。状态名称和执行位置各占一行，长设备名截断时仍保留完整名称。手机和宽屏复用这一行。来自旧链接、当前已无法识别的执行位置标为「执行位置不可用」，保留选择直至用户清除或改选。清除后留在当前任务和运行，焦点回到搜索框或筛选入口；手机从详情返回时继续显示原条件。

1280px 和 320px 浏览器预览用实际任务侧栏核对长名称、组合状态和清除后的列表。手机以触控打开任务再返回，条件保持，清除操作为 44px 且恢复焦点。390px 筛选弹层显示失效的执行位置。任务数据由模拟接口提供。见 `task-filter-summary/browser-evidence.json`。

### 云端单次运行的详情恢复

运行详情将「暂时读不到」和「正文中确实没有可定位的消息」分别提示。任务侧栏及当前运行的正文与草稿继续可用。详情区用一条共享状态提示统管来源和输出，保留已经读取的条目和计划保存的单次输出。没有打开详情时，显式历史链接的读取错误在正文旁提供同一个重试操作。

没有可打开的结果对话时，详情中的「输出」仍显示所选运行已保存的结果。云端保留原有 Markdown 呈现，设备脚本与 HTTP 结果沿用原始文本。打开其他运行后只显示新选中的记录，不用最近一次的输出替代。

### 云端立即运行的回执核对

立即运行沿用现有提交请求。连接中断后保留提交编号，任务页的「核对运行」只读取该账户与该任务的原回执。提交中、核对中、暂时不可读、尚无回执分别反馈。读取不到时可以继续核对，或明确确认结束核对。确认文案说明原提交仍可能完成，下一次立即运行会发起新请求。

任务、运行历史及草稿在核对期间仍可查看。切换任务或另一条运行后，迟到回执不改变当前地址与结果。返回原任务时可核对并打开已准入的原运行。与设备任务共用提示与确认的交互层，手机上的核对和确认按钮至少 44px，读取仍经现有账户鉴权。

390px 浏览器使用实际任务组件和模拟云端接口验证一次提交、原运行标识的读取重试和同一草稿节点。重试按钮为 44px，恢复后焦点移至任务标题。见 `cloud-run-admitted-read/browser-evidence.json`。

云端任务在结果对话内查看已选的等待、排队或运行记录时，「任务操作」提供「取消本次运行」。待准入时提交原计划及触发标识，准入后提交该记录绑定的 Cloud Run 标识。查看已完成的旧运行时，即使同一结果对话另有活动，也不提供这次取消。任务标题下按运行记录显示「正在取消」或「已取消」，保留所选记录、正文和追问草稿。后续计划仍按原设置执行。

390px 浏览器预览用实际任务菜单和模拟运行接口确认取消操作为 44px，只向所选运行发起一次取消，状态依次显示且追问草稿与已启用计划保留。见 `cloud-task-exact-cancel/browser-evidence.json`。

### 审阅待批准的云端运行

从运行记录选择待审批项时，也把焦点移到这次运行的审批标题。桌面保持详情展开，手机在详情弹层释放焦点后接续。普通历史记录和手动关闭沿用原焦点行为。切换记录只选择该次运行，批准和拒绝仍由用户在审批卡上分别触发。

### 编辑云端计划的资料来源

「高级」中的「来源」先列出草稿已引用的资料，再展开独立的资料搜索。已选项按文件或原成果版本读取账户元数据，旧成果保留原版本。查不到或暂时读不到的引用仍可单独移除。移除只编辑当前任务草稿，保存后影响后续运行，已保存的运行和原资料保持原样。搜索、翻页及重试保持任务内容和已选引用。

### 恢复已暂停的云端计划

选择「恢复」后先用当前计划规则和已运行次数预览下一次触发。有后续日期时沿用现有恢复写入，已读结果和历史选择保持原位。预览失败时在任务区说明原因，可以重新选择「恢复」重试。没有后续日期时直接打开同一个编辑弹窗，保留原计划内容和来源，引导调整日期或重复范围。看到新的下次运行后才能点击「保存并恢复」。关闭弹窗保留暂停状态。已完成且没有后续触发的计划保留编辑和立即运行入口。

暂停、恢复或编辑收到成功回执后，列表和任务详情即采用回执中的状态与下次运行时间，保留已有的单次运行信息。正在返回的旧列表不能覆盖已确认的变更。列表暂时读不到时继续显示已确认的任务状态，只在列表位置提示重试。保存结果未确认时仍需读取核对。
