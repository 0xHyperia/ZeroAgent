# ZeroAgent CloudChat：对话与工作体验规范

版本：1.12。日期：2026-10-30。适用范围：CloudChat Web、嵌入 Web 的 Android。
实现决策：[ADR0052](../product/decisions/0052-chat-work-interaction-spec.md)。
本规范是后续功能的共同验收依据；实际验收结果单独记录在仓库根目录 `design-qa.md`。

## 1. 参考与完成标准

参考本次用户提供的六张 ChatGPT 工作首页、项目/文件/插件菜单、添加菜单和工具标签截图，
以及已登录首页的桌面、手机响应式实测。来源为 [ChatGPT](https://chatgpt.com/) 的可观察界面，
不是对其内部代码、私有协议或后台能力的推断。参考会变化，本版规范固定本次观察。
原图和实测证据保存在 `.codex-artifacts/chat-work-experience-20261029/`。

完成标准是用户可以在首条消息发送前，用同一份草稿在对话与工作间切换、准备上下文、选择模型、编辑并发送，
切换过程连续，页面在桌面和手机上各有明确布局。不能以两张静态截图、一个会动的开关，
或只有外观的菜单代替这条完整路径。

### 能力映射

| 参考区域 | ZeroAgent 实际入口 | 行为契约 |
| --- | --- | --- |
| 聊天 / 工作 | 对话 / 工作 | 改变输入呈现与上下文入口；不另建消息历史或执行引擎 |
| 项目选择 | 当前账户项目快捷选择 | 真实列表、分页、筛选、当前项目、版本校验关联与显式移出 |
| 文件快捷选择 | 当前账户文件库 | 只引用可用原件，已有引用去重，处理中文件展示真实状态 |
| 插件上下文位置 | 工具 | 当前接入公开联网研究及数据分析引导；名称与实际能力一致 |
| 添加菜单 | 照片和文件、资料库、项目、联网研究 | 复用原上传、授权引用和研究主题确认链路 |
| 建议 | 研究问题、分析数据、撰写文档 | 填入或追加可编辑草稿；不自动发送、不启动计费任务 |
| 模型与思考强度 | 一个视觉胶囊、两个直接操作区域 | 模型名直接开模型列表，思考标签直接开滑条；共用同一弹层，长名截断，完整名称可访问 |
| 输出 / 来源 | 原成果、来源、文件资源入口 | 维持现有账户校验、预览、下载和引用 |

参考中的语音、浏览器标签、相机、Figma 等第三方连接和图像生成不因界面出现同样位置就
被视为已经接入。现阶段不放置没有执行链路的按钮。后续接入这些能力必须沿用本规范的
选择、已选标签、取消、不可用原因和权限边界，不能新增另一套输入框。

## 2. 不变量

1. 主编辑器、附件列表和模型选择器各保持单一实例。切换模式不改变编辑器节点、撤销历史、
   草稿段落、大段粘贴、光标、选择范围或待发送引用。
2. 模式开关仅在首条消息发送前的新会话显示，只改变呈现，不自动切换模型、推理强度、账户、设备或联网开关。
   首次发送后及已有历史的会话隐藏切换；生成完成后不重新出现，需要另建新对话才能重新选择。
3. 项目、文件、工具属于同一份草稿/当前会话的上下文，两种呈现下必须保留并能取消。
4. 悬停、聚焦、展开菜单、切换模式和选择建议都不发送消息。联网研究仍逐次确认公开主题。
5. 会话/账户切换、权限过期后，旧请求不能更新新界面；未知提交结果遵循既有任务核对机制。
6. Desktop/设备 Agent 默认编辑器和执行权限保持原契约。CloudChat 不借“工作”按钮获得本地权限。

## 3. 桌面布局

### 3.1 页面框架与锚点

保留应用导航轨、会话侧栏与主画布。宽屏模式开关相对主画布水平居中，不跟随左侧标题长度变化；
中等窗口按标题栏剩余空间排列，优先保证操作可达和互不覆盖。
输入框、工具栏和建议共享同一中心轴。切换模式时，输入框上边缘保持稳定；工作内容向下展开，
不能因整组内容重新居中而把输入框抛到另一个位置。

新会话的顺序为标题、输入框、工作工具栏、建议。已有消息时沿用消息阅读区与底部输入，
不显示模式切换或首页问候；历史加载、首次发送准备及生成期间也不显示切换。
完成或停止生成后仍保持已有会话布局；资源面板保持原阅读和滚动跟随契约。
开始输入或添加附件后收起首页建议，清空草稿与附件后恢复；不挤占正在编辑内容的注意力。

“新对话”只进入本地空白草稿页，重置当前编辑内容与待发送引用，不调用创建会话接口，
不向最近会话插入空记录。连续点击也不能生成记录。普通文本首次实际发送时，才沿原链路创建
一次会话并提交消息；明确保存项目关联或上传所需的持久上下文仍沿用各自原链路。
从执行中的会话打开新草稿只断开当前页订阅，不取消服务端任务；原会话及已保存数据保留。

| 项目 | 基准 |
| --- | --- |
| 输入框最大宽度 | 768px；窄窗口扣除左右各至少 16px |
| 标题 | 24px、约 1.3 行高、400 字重；不添加营销副标题 |
| 标题至输入框 | 32px |
| 模式轨 | 常规 224 × 40px；中等窗口 184px 宽 |
| 输入文字 | 16px / 26px；使用 ZeroAgent 既有系统字体和中文回退 |
| 空白对话输入框 | 约 54px 高、28px 圆角，单行内容垂直居中 |
| 空白工作输入框 | 约 128px 高、24px 圆角，编辑区至少两行 |
| 主要图标按钮 | 桌面 36px；移动触控区至少 44px |
| 工作工具栏 | 输入框两侧各内收 12px，中性薄底，无额外卡片边框 |
| 工作建议 | 3 列、12px 间距、约 128px 高、20px 圆角 |

尺寸以 CSS 像素为准，系统缩放和字体配置不能通过缩放整个页面补偿。
主画布的排版留白沿用现有品牌，不复制参考的个人项目、会话标题或第三方品牌资产。

### 3.1.1 账户与设置入口

桌面应用导航轨底部展示 40px 触发区内的真实头像/姓名首字，不放独立设置齿轮。
点击头像后，账户菜单在其右侧展开、底边对齐；顶部是当前姓名及可进入账号页的身份区域，
下面保留设置、退出等已实现动作。使用统一菜单表面、rounded-2xl 圆角及主题变量，不虚构订阅级别或入口。
会话侧栏底部不重复显示第二个账户条，也不触发共享侧栏的默认设置按钮回退。

手机展开导航时，同一个受控账户菜单位于抽屉内应用轨底部；不在历史面板重复放置账户条。
变更屏幕布局或账户时关闭原菜单；Escape/取消返回头像焦点，选择设置后仅在手机关闭导航抽屉。
默认完整设备工作台的 UserMenu 展示不受 CloudChat 的 rail 变体影响。

### 3.1.2 折叠侧栏预览

固定状态与预览状态分开。桌面收起后，鼠标进入应用导航、左边缘 10px 或展开按钮区域，
120ms 后临时展开同一侧栏；移出后等待 220ms 再收起，穿过两区交界不能闪退。
这些计时是 ZeroAgent 的体验参数，并非对 ChatGPT 内部数值的测量。
预览宽 272px，在共同页面框内内缩 4px，16px 圆角、轻边框和阴影；不加遮罩、不推动画布。
只有显式点展开或使用原侧栏快捷键才修改固定偏好。菜单、搜索对话框和键盘焦点仍可连续操作，
Escape 优先关闭内层。进入设置、切换账户/布局或明确导航后清理临时状态。
Escape 收起后，即使鼠标仍在边缘也不能立即再次展开；鼠标离开触发区域后才重新启用预览。
手机保留点击打开的模态抽屉，不将 hover 当作触屏入口。

固定侧栏展开时不启用 hover 预览；悬停其他应用导航不替换当前侧栏，点击才正式导航。
展开侧栏立即关闭已有预览并取消等待中的打开计时。侧栏收起时，主会话、正文滚动、
草稿和执行目标在预览期间不变。悬停不改变 aria-current，不发起写入、模型或设备选择。对话显示历史/项目，
资料库显示真实资源分类/最近文件，设备显示真实名称和在线状态。条目和导航需点击才正式打开。
预览另一目标时，头部展开按钮表示打开该目标并固定，不把原已展开状态反向关闭。
从应用轨跨过左边缘触发区再移入预览内容时，保持已经显示的目标；完全收起后再次进入边缘，
才默认预览当前页面侧栏。切换预览目标须经过对应应用图标，不能由交接边缘隐式切回对话。

### 3.1.2.1 页面表面和对话标题

应用轨留在外层；聊天侧栏与画布在同一个四角 18px、细边界的表面内，桌面上下和右侧保留 2px 外层。
桌面标题栏 52px，首行与侧栏对齐；手机保留原较高标题栏与触控空间。
固定侧栏使用轻分隔，临时侧栏浮在当前内容上；展开/收起复用同一宽度和位移动效，不缩放文字。
减少动态时取消新增淡入；手机取消外层内缩与大框圆角，保持有效触控宽度和原抽屉。

已有消息且桌面侧栏收起时，标题前显示 36px 新对话按钮；展开时由侧栏提供同一动作。
手机保留抽屉按钮，并显示 44px 新对话触控区。新对话继续只进入本地空白草稿。
页头和侧栏的新对话使用同一个编辑图标；默认 Desktop 图标不因 CloudChat 扩展改变。
标题悬停出现编辑图标和浅底，点击或键盘激活进入行内编辑并全选。Enter/失焦保存，Escape 撤销，
IME 组合输入不提交；空值提示，保存中防重复，失败保留文本并允许重试，完成后焦点返回标题。
改名使用原会话 PATCH，历史列表同步，不重建编辑器或任务。标题按可用空间截断，手机不覆盖环境/更多入口。
账户失效守卫清空旧内容后提供明确的刷新提示，不能只剩空白；不自动重发或绕过账户验证。
实现边界见 [ADR0054](../product/decisions/0054-cloudchat-conversation-chrome-context-preview.md)。

### 3.1.3 设置页面

按实际观察的 ChatGPT `/settings/general-settings`，设置属于应用内页面：最左应用轨保留，
聊天侧栏替换为设置标题、搜索及真实分类，右侧显示所选内容。没有覆盖聊天的绝对定位层或模态遮罩。
设置侧栏复用聊天/资料库的页面背景和 272px 宽度、17px 标题、36px 导航项、8px 圆角与 16px 图标；
导航 hover、选中和键盘焦点共用相同规则，搜索使用轻灰输入底面，不另套一套深灰导航主题。
内容最大 768px，标题与正文对齐；导航、正文分别滚动。设置期间聊天树保持挂载并隐藏/inert，
返回后保留编辑器节点、草稿、引用和原任务订阅，不隐式新建、发送或取消会话。
进入设置只增加一次浏览器历史项，分类变化更新同一项；浏览器后退返回原对话，深链接可刷新。
保留原主题、字体、保存指示和账号权限，默认设备工作台设置页不改用这一可选布局。

820px 及以下设置改为单列分类列表，条目触控高度至少 48px。选择分类进入详情，详情顶部“设置”
返回分类列表；列表提供“返回对话”。详情长内容内部滚动，不挤压为双列或横向分类条。
320px、390px 和 820px 边界必须检查；真机返回键/输入法仍需单独验收。
决策与边界见 [ADR0053](../product/decisions/0053-cloudchat-sidebar-preview-settings-page.md)。

### 3.2 对话输入

空白与能容纳的单行草稿保持胶囊形。输入换行、文字超过当前可用宽度、出现不可编辑引用块
或添加附件时展开为多行，控制按钮留在底边。文本重新能容纳时可收起；有附件时不强行收起。
宽度判断要同时考虑实际字体、模型标签、已选工具和窗口尺寸，不能使用字符数阈值。

测量采用不参与可访问树的纯文本宽度测量，不能复制一个隐藏编辑器来持有第二份草稿。
不要把动画 transform 施加到文字、光标或整张输入卡片来伪装高度变化。

### 3.3 工作输入

工作模式直接展示多行编辑区。模型与发送控制位于右下角，添加入口位于左下角。
工作工具栏包含项目、文件、工具；选中项目显示真实名称并截断，完整名称保留可访问标签。
名称很长时不能把文件和工具按钮挤出工具栏。
共享编辑器的容器查询不能把 inline 模型控件收成空按钮；中等窗口仍显示模型/强度标签，
空间不足时截断文字并保留完整可访问名称。

### 3.4 模型、思考程度与输入操作

常态是一枚连续的视觉胶囊：厂商图标、模型名、弱化的思考短标签和展开箭头。
模型区域直接打开模型列表，思考区域直接打开离散滑条；各自有完整的可访问名称与独立焦点。
不增加两套按钮外框或两份配置状态。整体 hover/展开时出现很浅的统一底面，当前指向区域提亮文字。
名称过长时仅截断模型名，保留思考标签和停止入口；完整名称在提示与可访问名称中可读。
滑条内的模型名称进入模型列表；模型页头的思考短标签返回滑条。点击任一区域均应直接到达对应页面，
包括从弹层内部导航后再次点击原触发区域，不能意外关闭或要求重复点击。
显式 `/model` 请求直接进入模型列表；不支持调节思考的模型也直接进入模型列表。
弹层默认在下方展开，靠近底部时自动翻转；最多一个弹层，不叠第二层菜单。

模型列表每次打开自动展开当前分组/厂商，并只滚动列表内部使选中项可见。手动折叠不被普通重渲染覆盖。
搜索、排序、刷新及厂商归并后的“模型→具体分组”两步路由选择保留，浏览不改变模型、分组或密钥。
这是 CloudChat 的显式 opt-in，默认设备/设置选择器继续遵循原默认折叠契约。
厂商图标复用 ProviderBrandIcon 与已有库资产，优先按模型身份识别。

两页共用同一锚点和 312px 宽、18px 圆角的表面，最大宽为视口减 32px。
桌面思考页常态约 101px 高；模型页随列表内容增长，列表在可用高度内独立滚动。
页面及说明展开使用 180ms 高度过渡，快速反向从当前可见高度继续；文字不缩放，减少动态时直接切换。
顶部居中显示当前档位，下方模型名称可点击；左侧问号实际控制当前档位说明，右侧恢复默认。
恢复仅使用宿主既有默认思考值，并明确提示将恢复到哪一档，不冒充跨模型的“推荐组合”。
模型页不在日常选择行塞入配置编辑入口；完整模型/供应商管理继续在设置及默认选择器中提供。
使用原生 range 承载输入，刻度沿用宿主传入的参数选项与保存链路，不另建静态模型能力表；思考强制开启时不出现关闭档。
鼠标/触屏拖动即时预览，松手提交；键盘方向键/Home/End 调节、松键提交，失焦提交，Escape 取消尚未提交的预览。
预览属于开始拖动时的模型；模型变化后不得通过迟到的失焦/松手事件写入另一个模型。
调节后弹层保持打开，原模型、分组和运行方式保持。说明按需展开，解释投入与等待时间，不承诺结果质量。
所有思考档位使用蓝色进度与白色滑块；最高档通过刻度、标签和进度表达。
紫色协作、Ultra、Fast、跨模型推荐均须有真实能力契约后才能出现，不借装饰暗示不存在的执行方式。
ReasoningSlider 将指针的连续位置与离散参数分开：拖动保留小数位置，最近档位仅用于标签预览，松手才吸附并提交。
不以step=1驱动视觉位置。进度和视觉圆钮使用独立的transform轨道，拖动时无过渡延迟，松手/键盘换档时220ms平滑归位。
轨道24px、圆钮28px、静态点4px；仅鼠标指向的档位点在120ms内放大至8px并略微加深，其余点不一起变化。
滑条使用手型光标，悬停档位点不更改参数；手柄自身Hover/按住时平滑放大至1.1倍，不改变轨道与档位位置。
说明、恢复及模型导航有明确的 Hover/按压反馈。
键盘保持整档调节，Escape/指针取消恢复，模型变化重建滑块的局部拖动状态；减少动态只取消归位过渡，不破坏连续跟手。
说明只保留当前档位的用途，不重复“模型和分组不变”等实现解释。
分组/厂商切换在同一帧确定展开项并完成列表内定位，不先绘制折叠态；列表轻微过渡，减少动态时取消。
刷新保留已有结果并明确指示加载，初始无结果时展示骨架，不把加载状态当作空结果；刷新按钮复用共享反馈。
触屏打开模型列表聚焦面板，不自动弹出搜索键盘；滑条和弹层保持键盘可达与清楚焦点。

发送是输入区唯一的深色主操作：圆形轮廓、斜向箭头、轻内沿与克制投影，hover 仅让箭头略向发送方向移动。
生成时同一个真实按钮平滑扩为“停止”胶囊，使用实心小方块与文字；沿用原停止/队列语义。
不把停止涂红，不借动效模拟发送完成；禁用态弱化且取消投影。减少动态时取消位移与过渡。
添加按钮默认是干净的加号，hover/展开呈轻灰圆底，展开时转为关闭形态。
菜单锚定触发按钮，使用紧凑可扫读的图标、标题、说明及统一圆角；保留原真实资源动作与焦点返回。
手机模型与思考区域、说明/恢复、面板内模型导航及滑条触控高度至少 44px。
因此手机思考面板约 132px 高，不机械套用桌面密度；320px 视口的面板宽 288px、左右各留 16px。
停止胶囊固定占 70px × 44px，宽度动画期间也不能挤出主操作，模型名优先收缩。

### 3.5 提示与层次

短 tips 使用近黑胶囊、14px/600 字重白字、6px 侧距和软投影；不缩放文字，淡入只改变透明度。
只有已经实现的快捷键才显示在半透明浅色小胶囊内。长说明和结构化统计使用较小圆角，保持阅读空间。
展开菜单期间抑制触发器提示，disabled 不悬浮提示；原 aria-describedby 与门户层级保持。
白色选中胶囊高 40px，底轨高 32px，上下各外扩 4px；选中以表面和轻边界表达。
对话/工作 hover 只提亮文字，不新增灰底、描边或阴影。点击推动选中块，聚焦不切换模式。
这种层次规则贯穿输入区：常态减少边框与背景，只有主操作、当前选择和展开表面承担视觉重量。

实现边界见 [ADR0056](../product/decisions/0056-cloudchat-composer-controls.md)。

## 4. 切换与动效

参考页可直接读取到编辑区 300ms 的 min-height 过渡及 `cubic-bezier(0.23,1,0.32,1)`。
下面其余数值是 ZeroAgent 的实施参数，不能称为反编译获得的 ChatGPT 原始参数。

| 部位 | 实施规则 |
| --- | --- |
| 选中滑块 | 240ms；横向移动，无弹跳；选中底为同一真实元素 |
| 编辑卡片高度 | 300ms，`cubic-bezier(0.23,1,0.32,1)`；不拉伸内容 |
| 编辑卡片圆角 | 同步 300ms，从 28px 到 24px |
| 标题 | 淡入淡出 160ms、最多 5px 位移；始终只有一个可访问的一级标题 |
| 工作工具栏 | 0fr / 1fr 展开 300ms，透明度 160ms；不挂载第二份编辑器 |
| 菜单与提示 | 使用共享 Popover、Sheet、Tooltip 的既有进出与定位 |
| 悬停 | 仅颜色、边框和轻阴影；不缩放按钮，不让列表或正文位移 |

快速往返时，从当前可见高度反向继续，取消旧动画，不排队重播。初次加载不从零高度播放。
编辑文字和附件预览不整体缩放，模型与发送控制以当前卡片底边定位，不在过渡中被裁掉后弹出。
系统启用减少动态效果时，切换立即完成，所有可用入口与焦点反馈保留。

### 状态转换

| 起点 / 操作 | 结果 | 必须保持 |
| --- | --- | --- |
| 空白对话 → 工作 | 多行输入、工具栏、工作建议 | 模型、会话、执行目标 |
| 有草稿对话 → 工作 → 对话 | 同一内容按能否容纳恢复形状 | 段落、引用、选择范围、附件 |
| 菜单打开时切换模式 | 先收起上下文菜单，再切换呈现 | 草稿与已选工具 |
| 未发送草稿上传附件时切换 | 仅改变呈现，不重发、不取消上传 | 正在上传的附件状态 |
| 首次发送、已有消息或生成中 | 隐藏模式开关；完成/停止后仍隐藏 | 当前输入呈现、模型、真实任务与草稿 |
| 连续快速切换 | 最后一次选择立即生效，动画追随当前状态 | 不增加编辑器/模型控件实例 |
| 资源页返回对话 | 回到同一会话和草稿 | 未保存项目编辑仍受原导航保护 |

## 5. 上下文交互

### 5.1 项目

桌面使用锚定按钮的紧凑选择层，包含筛选已加载项目、新建/管理、项目列表、当前选择和分页。
不要把本地名称筛选说成全库服务端搜索。当前已关联的项目必须有标识，支持显式移出。

选择项目时先读取当前服务器关联版本，再按 expected_version 更新。冲突显示可理解的错误，
只有用户再次选择才重试；不能静默覆盖另一页面的变更。选择更新中禁用重复变更和发送。
选择完成后再更新名称，不以乐观勾选冒充保存成功。

新草稿第一次选择项目时，创建一次会话并保留完整结构化草稿、附件和成果引用，再关联项目。
创建和关联都必须绑定原账户/当前视图；页面已经离开时，不把迟到结果带到新会话。
项目详情页的编辑、未保存保护和原关联入口继续可用。

### 5.2 文件

快捷选择层展示当前账户的真实文件，可筛选当前已加载页、显式继续加载及浏览完整文件库。
ready/vision_ready 才可引用；上传中、处理中、失败和删除中的条目展示真实状态，不能假装已解析。
文件名作为文本渲染，不解析其中的 HTML。引用只携带文件身份，继续由服务端做账户校验。

已在草稿中的文件显示已添加并禁用重复选择；文件和成果共用每条消息最多 8 项的原限制。
选择后关闭浮层并返回同一编辑器。失败留在选择层解释原因，用户可以重试或取消。

### 5.3 工具与已选标签

公开联网研究由用户显式开启，主输入区域显示可移除标签，在对话/工作间保持。
标签移除、菜单取消和模式切换不能发送请求。发送时仍走公开研究主题确认，私有草稿不复制到搜索主题。
数据分析入口准备可编辑的目标文本；真正执行仍在用户发送之后由既有 Go 工具循环处理。

工具选择不修改平台模型授权，不自动提升设备或文件系统权限。未来第三方连接应清楚展示
未连接、连接中、已连接、授权过期及不可用原因，不能沿用一个永远成功的装饰性勾选。

### 5.4 添加菜单

桌面使用 352px 紧凑菜单，锚定加号并留出约 8px。图标靠左，操作名称与短说明上下排列，
空间不足允许说明换行。按可用空间自动翻转，菜单内部滚动，不能把内容挤出窗口。
手机保留视口两侧至少 16px；照片/文件调用原系统选择器，资料库/项目调用同一快捷选择层。
菜单之间互斥；展开菜单时让位于共享 Tooltip。

## 6. 手机布局

### 6.1 正常竖屏

820px 及以下使用紧凑布局。收起导航时主画布使用全宽；展开时同一个模态抽屉包含52px应用轨与历史/资料导航面板。
面板常规280px，两列总宽最多332px，同时为右侧上下文保留至少48px；320px下自动缩窄面板，不挤掉应用轨。
轨底部保留唯一头像，面板标题只展示文字，关闭使用清楚的X；导航操作命中区至少44px，复用桌面图标与四态。
背景使用主题底色60%的退让层，保持正文轮廓清晰，不叠深灰遮罩或背景模糊。此为共享Sheet的navigation语义变体，
默认对话框、资源和项目选择Sheet保持原样。应用轨与面板在同一模态内，焦点/返回/点外关闭统一管理。
移动端仅挂载当前导航面板；切换页面或选择会话后收起抽屉，主编辑器和运行订阅保持。
模式开关保留在顶部，
标题栏资源入口合并进更多菜单；执行环境仍有明确可访问名称和可操作入口。

输入框固定在可用画布底部；工作工具栏在输入框上方。首页问候占剩余空间的中部，
不能为了显示长介绍把发送控件推出首屏。手机不使用被按钮挤到只有几个字宽的单行编辑区，
对话和工作都保留独立输入行，模型和发送位于下方。

工作建议为横向滚动卡片，默认露出下一张的一部分，采用 scroll-snap；不压缩成三张细长卡片。
聊天建议是较轻的纵向入口。左右边距至少 16px，输入字体不小于 16px，避免聚焦触发页面缩放。

### 6.2 键盘、安全区与短窗

复用已有 `--zeroagent-visual-viewport-height`、安全区和 Android IME 桥，不建立第二套键盘高度权威。
键盘打开时隐藏首页问候和建议，保留输入、工具栏和发送；键盘关闭后恢复，不清空草稿。
首页底部取 36px 与系统安全区的较大值；键盘打开时收紧为 8px，短窗取 12px 与安全区的较大值。
横屏或短窗优先保证编辑与操作，建议可让位，内容仍可滚动。

Android 返回键先按现有桥收起键盘；抽屉与选择层的返回/关闭由共享模态组件消费。
手机 Web 保留正常浏览器缩放与输入行为，不为模仿设备外观绘制状态栏、刘海或键盘。

### 6.3 手机选择层

项目、文件、工具使用同一共享底部 Sheet，最大约 70dvh，上方标题和关闭入口固定可达。
打开时聚焦选择层，不自动聚焦搜索框而召唤键盘；只有用户点搜索才进入输入。
列表独立滚动，不让背景会话跟着滑。完成文件选择返回编辑器，取消返回原触发器。
外部点按、Escape、关闭按钮与 Android 返回应遵循同一关闭路径。

### 6.4 错误与状态反馈

任务失败、停止或中断的提示放在对应会话的消息阅读列末尾，与消息一起滚动；不使用横跨整个
画布、固定在页头的横幅。保留已生成内容和原请求的编辑/重试入口，点击编辑只打开原消息编辑区，
确认发送后才按既有分支链路执行。历史恢复的终态使用 status，不在每次进入会话时播报紧急警报。

发送失败、提交结果待核对、队列已满和分支状态待确认靠近输入框展示，让原因与下一步操作相邻。
未知提交结果只提供原核对入口，不能改成自动重发。关键失败和待核对提示不定时消失，不能随意关闭。
准备参数、上传和导出使用紧凑状态行；普通上下文说明可提供明确关闭按钮。

统一使用 CloudChatFeedback：12px 圆角、中性薄底和轻边界，16px 状态图标；严重程度通过图标与文字
共同表达，不铺大面积红黄底色。主文案 14px/21px，说明 12px/18px，先说明结果，再给用户能采取的动作。
桌面操作靠右，窄屏移到文字下方，允许长文案换行，手机动作至少 44px。
输入区多条反馈最多占 min(32dvh, 240px)，超出后在组内滚动；高度必须计入原输入框测量，不能遮住
正文末尾或另建键盘高度权威。新增组件只负责呈现，恢复、取消和关闭条件仍由原业务状态决定。
实现边界见 [ADR0055](../product/decisions/0055-cloudchat-contextual-feedback.md)。

### 6.5 鼠标光标

按钮、链接、可点击导航/列表、菜单项、选项、页签、开关、原生选择器及可展开摘要使用手型光标。
共享基础样式按真实 HTML/ARIA 交互语义提供默认值，Portal 菜单也遵循同一规则；不能只给带 Tooltip
的按钮补样式，或把所有 div/带 tabindex 的容器都标成可点击。
文字输入和编辑区保留 I 型光标；禁用控件不能显示可点击手型，原有禁用/只读及点击守卫继续有效。
拖动、缩放、预览放大等专用光标由对应控件保留，正文和普通提示不显示手型。
仅统一 cursor 呈现，不用鼠标监听器、浮动假光标或新增点击行为实现。

## 7. 键盘、输入法与可访问性

- 模式控件使用原生按钮及 aria-pressed，同组仅选中项进入 Tab 顺序；左右箭头、Home、End
  可选择并移动焦点。普通聚焦不切换模式。
- 点击模式开关后焦点留在模式按钮，不能强制弹出手机键盘；回到编辑器时继续原光标位置。
- 编辑器 Enter、Shift+Enter、中文 IME composition 与原发送判定保持，不因动画注册另一套快捷键。
- 项目/文件筛选框可用向下键进入条目，条目上下键移动、Enter/Space 选择；Escape 关闭。
- 菜单打开时关闭 Tooltip；选择、移除、加载、失败均有可读名称，不用颜色作为唯一状态。
- 模式标题的视觉交叉淡变不能产生两个可访问 h1；隐藏工具栏同时退出焦点与可访问树。
- 焦点环可见。深色、强制颜色和减少动态效果不能丢失选中或操作反馈。

## 8. 组件与维护边界

| 所有者 | 组件 / 模块 | 职责 |
| --- | --- | --- |
| 共享 UI | ChatComposerBar 的 inline 可选布局 | 单一编辑器、模型、附件、发送、上下文位置插槽；默认 Desktop/Agent 不变 |
| 共享 UI | useInlineComposerLayout | 用真实宽度和字体决定单行；监听输入、字体及尺寸变化并清理 |
| 共享 UI | useComposerShapeMotion | 有界高度动画、反向重定向和减少动态效果 |
| 共享 UI | ComposerModelControls | 可选紧凑标签；不新增第二套模型、推理或参数状态 |
| CloudChat | ModeSwitch、EmptyState、Starters | 呈现、问候和可编辑建议 |
| CloudChat | WorkToolbar、ContextPicker | 真实资源快捷入口与手机 Sheet；复用服务客户端和账户守卫 |
| CloudChat | CloudChatFeedback | 统一错误/状态外观、可访问语义和操作位置，不拥有执行或恢复状态 |
| CloudChatPage | 上下文提交与视图所有权 | 项目版本、一次会话创建、草稿恢复及引用上限 |

业务状态不放在 CSS 或动效计时器中。服务端是项目关联和文件可用状态的权威；共享展示组件
不读取密钥、不调用模型、不管理执行租约。上游提供等价能力时，可在完整满足本规范和测试后替换。

## 9. 验收矩阵

每次调整应选取相关矩阵验收，并记录实际执行范围；规范中的要求不等于已经真机通过。

| 维度 | 必查内容 |
| --- | --- |
| 桌面 | 1440×900、宽屏、侧栏收起/展开、对话/工作、空白/单行/多行/长文/附件 |
| 手机 | 320px、390px、820px 边界、短窗、键盘打开/关闭、安全区、长项目/模型/文件名 |
| 模式 | 首次发送前慢切换/快速往返、已选研究、菜单打开、上传中、资源返回；发送后/已有历史/生成中隐藏，新对话恢复 |
| 输入完整性 | 同一编辑器节点、草稿段落/长粘贴、选择范围、撤销、附件和模型不变 |
| 真实数据 | 空、加载、失败重试、分页、已添加、不可用文件、项目冲突与显式重试 |
| 隔离 | 会话切换、账户切换、退出、迟到成功/失败、关联进行中发送和重复点击 |
| 无障碍 | 键盘、IME、可见焦点、aria、长文本换行、减少动态、浅色/深色 |
| 执行 | 选择不运行，模式不提权；确认后才联网，模型和工具仍走原执行链路 |

浏览器响应式检查不能代替 Android/iOS 真机键盘、系统文件选择器和真实外部链路验收。
本地协议与组件测试不能证明 ChatGPT 后台能力等价。实际通过项及尚未验证项以 `design-qa.md` 为准。
