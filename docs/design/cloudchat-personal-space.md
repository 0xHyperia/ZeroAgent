2026-11-01 补充：预览顶部不显示“引用 / 已添加”状态按钮，移除独立勾号；
文件引用收纳至文件标题菜单，已在草稿内时禁用同一操作。顶部保留阅读、下载与窗口操作，

## 2026-11-01 图片快捷批注与请求修改状态补齐

现场对照浏览器中 ChatGPT 的工作会话（普通聊天只读预览没有修改入口），以及本轮四张截图。
用户任务是读原件、指出某段或图片、连续写多条意见、核对后一次发送；文件详情只辅助辨认原件与关联对话。

| 状态 | 画布与操作 | 浮层与反馈 |
| --- | --- | --- |
| 普通阅读 | 保持文本选择、滚动、缩放；点击 Word 内图片选中该图片 | 图片细蓝虚线，下方靠右出现“请求修改”及 Ctrl+Shift+X；点击空白或 Escape 收起 |
| 请求修改待选择 | 顶部按钮淡蓝选中，进入时 160ms 颜色/轻微位移过渡；底部黑色提示条 | 光标与蓝色批注标记共用同一水滴形；悬停块细实线，无背景填充 |
| 选中块/拖出区域 | 淡蓝底、蓝色虚线及右上水滴标记；段落、图片均可选，拖选限定同页 | 输入胶囊在选区下方靠右，宽 360px、距选区 8px，窄屏距边 12px；输入为主，右侧圆形确认，空值灰色 |
| 输入与滚动 | 输入位置跟随选区；选区离开视口时隐藏输入，回到视口恢复原文 | 只在切换逻辑锚点时切换输入，不因缩放、重排或详情开关清空 |
| 已保存批注 | 保留淡蓝虚线和水滴，悬停强化蓝色；再次点击可编辑已有意见 | 标记旁白色小浮层显示批注意见；底部数量胶囊可悬停/点击打开列表，页码和单行原文弱化、意见正文突出 |
| 多条核对 | 上下条平滑定位，底部条可拖动，边界内限位 | 修改/移除针对指定条，保存不会重复添加；语音功能未接通，不显示空按钮 |
| 发送/失败 | 显式发送走原有文件引用与提交链路，等待中禁止重复发送 | 成功清队列，失败保留全部意见；不在预览内直接覆写原件 |
| 取消 | 无意见立即退出；有意见或输入需确认 | “保留批注 / 放弃”，Escape 先收起当前选区；已有草稿及其他文件意见不受影响 |

桌面目录/缩略图统一加宽至 232px（占位 244px），纸张仍以剩余可用宽度计算真实比例；
小于 600px 的阅读区域仍用浮动导航，触屏按钮至少 44px，不挤压纸张。详情保持右侧悬浮卡片，
移除“状态”“AI 使用”；关联对话为图标和真实标题的列表，标题长时省略并可查看全文。
元数据读取复用当前账户会话 API，过期、切换文件或账户时作废请求，不展示已无权限的标题。

图片锚点由原件渲染结果生成，保留所属页和标准化区域；不信任 iframe 自报的引文或图片说明。
图片快捷操作只在宿主提供真实请求修改能力时出现，使用相同 opaque sandbox / nonce / source / token 校验。
所有新选中态、浮层出现及导航过渡遵守 reduced-motion；确认按钮不改变原件、版本与提交协议。

## 2026-11-01 阅读工作区精修方案

依据本轮 12 张参考图，任务为：打开原件，查看详情/历史，快速定位当前页面，选择区域写
批注，核对批注后显式提交。此轮不修改存储、账户权限、模型路由或已有草稿。

- 完整阅读画布拥有唯一滚动视口，滚动条固定在整个阅读区最右边。详情/历史为右侧浮层，
  与工具分层，距顶部 52px、外侧留 8px；Word/PDF 仅调整纸张可用空间，其余类型覆盖。
  浮层不能改变滚动视口宽度，不能把滚动条挤到正文与详情之间。
- 工具一行排列：文件标题和请求修改在左，缩放、下载、已有文件操作、展开/关闭在右。
  采用 36px 胶囊、14px 正文权重、18px 图标、6px 间距和轻边界/柔影。展开与关闭共用
  一个胶囊，子按钮仅 hover 时出现内侧底面；历史入口归文件菜单。无真实分享能力不伪造按钮。
- 自动缩放仍保留自动模式，胶囊显示实际比例，菜单勾选自动模式；尺寸及详情变化更新比例。
- 导航分固定和临时预览。鼠标移入左侧导航热区，完整目录浮出；从热区移向目录保持展开，
  离开整个区域后收回；点按可固定。收起后保留随页数生成的刻度及当前页位置。
  目录/缩略图有独立 hover、选中、选中 hover、键盘焦点，滚动同步当前页和当前标题。
- 请求修改使用短淡入/图标转动反馈与蓝色活动态；选择模式使用专用光标、轻底面和虚线。
  支持点段落、文字选区及拖动框选同页文字区域。框选保存归一化纸面坐标、已验证原文锚点，
  不把屏幕像素当原件坐标，不在预览桥增加网络或宿主权限。
- 底部批注条可用专门手柄拖动并限制在阅读区内，窗口变化重新约束位置；hover 可浏览批注，
  点击和键盘亦可打开完整列表，支持定位/编辑/移除。未发送批注退出需保留或明确放弃。
- 手机维持单列和至少 44px 点击区，目录及详情可点按关闭；主要动作不依赖 hover。
  批注条不遮住工具或移出屏幕，框选模式与普通阅读滚动明确区分。减少动态关闭装饰动画。

复用 agent-ui 的 ScrollArea、菜单、Tooltip、Popover、AlertDialog。导航/批注/缩放为共享
阅读组件；CloudChat 只提供插槽、详情状态和真实资源动作。验收按八项分别对照截图与实际
PC/440px 页面，特别检查详情开关前后滚动条位置、hover 过渡、目录同步和批注拖动。

版本：1.3。更新：2026-10-31。实现边界：[ADR0057](../product/decisions/0057-cloudchat-personal-space.md)、
[ADR0060](../product/decisions/0060-cloud-space-seaweedfs-and-online-preview.md)。

本规范定义目标体验，不表示下列布局和能力均已实现。现有公共查看器的格式接线及构建结果，
不能替代资料空间与成果工作台的产品体验验收。开发流程同时遵循 [跨端组件与交互规范](zeroagent-cross-platform-ux.md)。

资料空间是当前账户的资料和工作产出中心。核心闭环为：直接上传 → 找到并预览 → 引用到原草稿 →
显式发送并工作 → 正式产出按版本保存 → 再次引用。页面不模拟尚未实现的协作、站点发布或完整Office编辑器。

## 导航与信息架构

- 外层应用轨沿用对话/资料空间/设备、唯一头像及四态。上下文侧栏标题为“资料空间”。
- 分类为全部资料、文档与文件、图像、我的上传、工作产出、收藏；另列真实文件夹、项目资料和研究来源。
- 回收站和容量放在侧栏底部。容量真实统计原件与产出各版本；点击管理可查看明细及回收站。
- 全部资料默认展示根目录和文件夹；分类、收藏和搜索可以找到文件夹内资料。
- 每个产出family展示最新版本，详情保留版本列表；引用的是实际选定版本。

## 桌面布局

内容区最大1240px，常规左右40px留白，中等窗口24px。头部左侧为当前分类/文件夹，右侧为名称搜索、
上传与新建；列表工具和过滤位于下一行。使用既有字体、主题与轻边界，不增加大幅hero或容量看板。
文件名是主信息，来源/状态、大小、修改时间为次信息。表头12px，名称13px，行高至少64px。
仅空间不足时截断名称，独立更多菜单保持可达；hover改变中性底色，不缩放行或移动文字。

收藏资料以“随手可用”呈现，只展示真实收藏，不填充虚构模板。列表与网格使用同一数据与选择状态。
图像网格按需显示受认证原件缩略图；限制可见小图、并发和大小，大文件仍可通过详情下载。
不生成公开S3链接，不把HTML/SVG作为不受信任页面执行。文本按原行号预览，图片在原件详情预览。

搜索覆盖账户所有资料名称，输入延迟180ms；过滤变化清除旧选择及分页。刷新和继续加载保留当前列表，
显示更新状态并暂停旧条目操作，避免先清空再闪回。首次加载显示骨架；空、无匹配、失败分别说明下一步。

## 操作与反馈

更多菜单复用共享软菜单：预览、引用、收藏、重命名、移动、回收站/恢复。桌面hover显现选择框，键盘聚焦
同样显现；手机常显。批量操作只处理选中条目，失败保留已知结果并可显式刷新，不自动重发未知写请求。
引用前复核规范状态，最多8项且排除重复。添加资料不发送模型请求，不替换模型、分组或草稿。

名称/文件夹使用统一Dialog，保存时单次提交；版本冲突保留错误并允许刷新核对。
网络中断或响应异常导致保存结果未知时，暂停再次写入；用户显式刷新并成功读取后再恢复操作。
新建与文件操作菜单共用10px图标文字间距，桌面行高至少36px、手机至少44px。
回收站不等于彻底删除：原件仍占空间，已有引用仍可读。彻底删除在详情明确说明影响并确认，
沿用原服务的删除意图及远端清理；空间不能提前释放。非空文件夹先移出内容再移入回收站。

新建菜单的文档/表格/演示文稿收集创作目标，再进入可编辑的对话任务，原草稿保留并追加要求。
只有用户发送后才运行；不把草稿、临时沙箱文件或尚未确认的发布当作正式成果。
产出是否成功以服务端ready版本为准。默认保存到账户空间，文件夹不冒充执行工作区。

状态与失败复用CloudChatFeedback，就近显示，不横跨整个应用顶部。未知结果、配额不足、解析失败不能自动消失。
容量由服务端提供，总额及原件/产出/回收站明细有相同数据来源，不能用已加载文件大小之和代替账户用量。

## 资料与成果工作台：目标体验

依据用户 2026-10-31 提供的豆包文档/表格和 Codex 工具面板截图，优先形成
“对话中看到产物 → 就地打开阅读 → 引用内容或继续提出修改 → 核对新版本 → 下载或明确分享”的完整路径。
视觉沿用 ZeroAgent 规范；参考中的编辑、批注或范围引用需先明确是否属于本次范围，并有真实能力接线，
不能因参考图出现对应按钮就当作已经实现。

### 布局与内容层级

- 从消息产物卡片或对话资料打开时，桌面宽屏使用右侧内容工作区，保留对话和输入框；空间浏览页可独立阅读。
  面板按聊天画布实际可用宽度响应，支持明确关闭和独立展开；分栏不能把对话压到不可阅读，也不重建会话控制器。
- 内容工作区顶部集中显示标题、位置、来源/版本和主要动作。名称优先利用可用宽度，路径及时间降为次信息；
  下载、继续修改、版本等围绕当前内容组织。次要动作进入统一更多菜单，不把操作按钮堆成多排占据阅读区。
- 文档正文、表格画布和幻灯片是主要区域。内容区独立滚动，标题和必要工具稳定可达；应用外框、内容面板及
  文档纸面层级清楚。文档自身的纸色和格式不强行改写为应用主题色，外层工具和反馈必须适配浅深主题。
- 多个资源的切换复用同一内容面板；切换时展示当前目标及其加载反馈，不能短暂显示上一份文件冒充新文件。
  对话草稿、引用、消息滚动和输入选择不因打开、缩放、关闭或返回而丢失。

### 消息中的产物卡片

卡片展示类型图标、真实名称、正式状态及有价值的内容摘要或真实预览缩略图，点击主体进入对应内容。
缩略图与打开目标绑定同一不可变版本；尚未生成时使用统一骨架，不放示例内容或假截图。
卡片保持紧凑，正文与说明有主次，复制/下载/更多等次要动作按实际能力呈现；手机不依赖 hover 才能找到入口。
生成中、已保存、保存失败和结果待确认可区分，不能用“生成完成”掩盖正式保存尚未完成。

### 按内容类型设计阅读工具

| 内容 | 阅读与交互要求 |
| --- | --- |
| 文档 | 正文排版、段落/标题/表格清晰，长文提供适用的目录导航与定位；来源、版本和继续修改不挤占正文 |
| 表格 | 工作表切换、行列定位和缩放符合表格使用习惯；明确格式/合并单元格/公式结果的支持范围，受限纯文本表格不能宣称为完整 Office 预览或编辑 |
| 幻灯片 | 页面导航、当前页/总页数、适合宽度及放大阅读集中组织，缩放后仍可翻页；适用时提供页缩略导航 |
| 图片与媒体 | 保持比例，图片缩放与媒体播放控件按内容组织；加载/解码失败就近反馈，保留原件下载 |
| 站点 | 预览、正式保存、指定版本分享和撤销各有清楚状态；不能把私人预览或沙箱链接当作已发布站点 |

只读、编辑及 AI 继续修改是不同能力。只读页面不展示没有实现的编辑工具栏；具备编辑能力时，
明确保存状态、冲突处理、撤销与版本关系。选择段落或单元格范围用于对话时，应显示具体引用范围并允许移除，
不得静默替换草稿或自动发送。开源组件负责格式能力，ZeroAgent 的共享外壳负责一致的用户操作和反馈。

### 手机与窄画布

手机采用单列内容阅读页或全屏内容面板，顶部保留返回、标题和最重要动作，其余动作放入可触达菜单。
返回后回到原对话/空间位置，保留草稿、滚动、选择和当前版本；不照搬桌面三栏及整排工具栏。
Word 在支持重排时优先可读，幻灯片适合宽度且可放大，表格只在自己的画布内平移或缩放。
不让整页横向溢出，不用多层滚动或额外遮罩阻碍阅读；触控区、安全区、键盘和系统返回继续沿用共享规范。

### 功能与体验验收

设计与验收同时覆盖入口卡片、正常打开、长内容、打开另一版本、继续工作、关闭返回、首次加载、更新、
解析失败、下载不可用、配额不足、权限失效及未知保存结果。失败说明使用用户可理解的语言，原件与已有工作保留。
每类工具只显示适用动作，状态反馈靠近正在操作的内容，不把解析库信息和内部协议细节作为正文说明。
检查桌面分栏、窄画布、320/390px 手机和 820px 边界，以及浅深主题、键盘、鼠标、触控与减少动态。
实际走通任务并检查页面质感后记录体验结论；组件和后端测试通过仍需分别记录，不能替代此结论。

## 手机与无障碍

820px及以下，导航继续使用52px应用轨+最多280px上下文面板和清晰浅遮层。主页面左右16px，
名称24px；头部操作可以换行，搜索独立一行、输入16px。次要表格列折叠为名称下的状态/大小，
不出现整页横向表格滚动。更多、复选、页签及Dialog操作触控区至少44px。
网格双列，图片等比contain，名称独立截断；收藏卡横向滚动，不挤成多张细卡片。
容量与页尾尊重安全区。模态标题/关闭始终可见，工作目标Textarea支持长内容及手机输入。
隐藏页面及其弹层退出可访问树，账户变化清理请求和图片URL；焦点、Escape与读屏语义使用共享原语。
减少动态取消装饰过渡和骨架动画，保留全部操作与焦点反馈。真机键盘/系统文件选择器单独验收。

## 2026-10-31 阅读工作区打磨方案

本轮当前界面证据保存在 `.codex-artifacts/space-ux-20261031/before/`。文档打开后采用浮层，
正文之前有多排重复操作和工程说明；桌面宽度不足时盖住对话，列表列宽也没有跟随实际内容区。

- 桌面：`导航 | 对话或资料列表 | 资料阅读`。阅读区内固定页头为文件名、类型/大小或版本、
  引用/继续修改、下载、更多、展开、关闭；正文独立滚动。更多保留刷新、原文、来源和删除等真实能力。
- 内容区不足1040px，或用户选择独立展开时：`导航 | 资料阅读`。隐藏原画布同时退出可访问树，
  不卸载对话编辑器、列表和预览；收回展开恢复原滚动、草稿和版本。手机关闭直接返回原浏览位置。
- 浏览：搜索、来源、排序、视图切换保持原逻辑；按列表容器宽度收合次要列。首次空、筛选无结果、
  文件夹空、回收站空分别说明下一步；更新保留已有内容，显示真实加载状态。
- 内容：格式工具只保留真实的阅读动作；白纸与中性画布分层。表格坐标、工作表与幻灯片页码/缩放
  清晰可达，图片打开即读，不在正文外重复套卡。错误、取消和重试靠近内容。
- 引用：添加到原草稿，随后返回并聚焦编辑器；不自动发送。满8项、权限或忙碌导致拒绝时保留阅读
  并在原操作处说明。已有引用重复操作同样能回到原草稿，不丢模型和分组。
- 无障碍：阅读区具名 region；进入后聚焦关闭/返回，退出返回触发项；菜单优先处理 Escape。
  展开只改变布局而不重建文件控制器。减少动态时关闭过渡，手机动作至少44px。

验收以真实生产bundle的文档、图像、表格、幻灯片、站点和异常文件为样本；覆盖宽窗/实际窄画布、
320/390/820px、浅深色、展开/返回、菜单及引用拒绝。浏览器移动视图检验共享布局，原生系统能力另验。

本轮已按此方案接线，实际验收记录见 [资料空间实施记录](../cloudchat/SPACE_IMPLEMENTATION.md#2026-10-31-阅读工作区与浏览体验打磨)。

### 2026-11-01 表格阅读与输入框封面

用户任务：拖入表格后看到真实首表封面，点击后在同一工作区检查原始排版、选择单元格/范围、查看公式与切换工作表，关闭后保留草稿。以用户提供的 ChatGPT 同文件截图和浏览器实测为布局依据。

- 共享阅读器采用“悬浮文件/缩放/下载/展开关闭 → 坐标与公式栏 → 原格式工作表 → 底部页签”。移除工具条的定位按钮、强制换行开关；坐标框 Enter 定位，公式栏只读。列宽、行高、字体、对齐、合并、数字格式、填色和边框按原文件呈现，不以应用主题改写纸面。
- 鼠标点击/拖动选择单元格范围，行列头同步蓝色选中；方向键、Shift 扩选、Home/End、复制与坐标定位保持可用。选择仅改变阅读状态，不修改原文件、执行公式或自动发送。公式展示原公式，单元格使用文件保存的计算结果。
- 输入框封面使用同一格式模型的首表左上内容，按固定阅读宽度等比缩小后裁剪，去掉坐标、行列头、选择和页签；无内层滚动条，不受完整阅读器的选区、缩放、切表影响。
- 手机采用同一组件和公式栏，页签可横滑，表格只在自身画布平移/缩放，工具触控区至少 44px。详情保持浮层，不挤走表格滚动条；缩放不触发浏览器缩放。
- XLSX 使用 ExcelJS 读取格式，原有 SheetJS 继续负责 XLS/CSV/TSV；解析留在可取消 Worker，先执行既有压缩体积/路径检查，限制工作表、行列与输出单元格数量。长表只渲染可见行；不执行宏、公式、超链接或文档脚本，不添加网络解析服务。
- 状态包含格式图标加载、正常/空表、切表中、损坏/超限、取消重试、不可变版本与账户失效。回归覆盖格式、合并/隐藏、数字与公式、首屏缩略图、范围选择、定位/键盘/复制、缩放、切表、浅深主题、手机和既有状态保留。

实现说明：完整预览与封面共用惰性格式模型、画布绘制和换行布局；封面取首表左上约 360 CSS px 的内容，不展示行列头。表头为 40px 行号区与 20px 列名区，原行高不足时允许换行内容撑高。缩放后在布局提交时恢复滚动锚点，触摸点选与原生单指平移分开处理。大型稀疏行、超大合并区域等先降为有界文本预览，避免格式引擎扩展占用过量内存。该实现覆盖普通单元格格式与已保存的公式结果；嵌入图片/图表、条件格式规则、宏和公式计算不属于本轮新增能力，XLS/CSV/TSV 保留原有文本预览边界。实际对照与验证见根目录 `design-qa.md` 的表格预览条目。

## 2026-11-01 阅读与批注体验细化

本轮以用户截图和两段录屏为验收依据。阅读画布、顶部悬浮工具、两侧浮层保持独立；切换文件只替换内容与格式工具，拖入新文件不会关闭已有预览。加载时在最终卡片尺寸内显示低对比格式图标，完成后原位过渡至真实封面。缩略图是不可交互的首屏裁剪，不具备内层滚动条。

- 文件标题提示完整名称；历史状态的返回胶囊仅提示“返回”。版本按日期、时间轴展示，仅保留版本说明与当前状态，移除右上角重复的更多菜单。
- 页面和目录点击平滑滚动，滚动时同步当前位置；减少动态效果偏好下直接定位。Ctrl/Cmd 滚轮、触控板捏合和缩放快捷键只影响当前阅读器，退出阅读器后保持浏览器默认行为。
- 批注模式使用批注气泡光标；未批注块 hover 为细蓝实线，已批注块为浅蓝底、蓝色虚线和气泡标记，hover 气泡显示实际批注。批注输入框跟随原文位置滚动，原文离开视口时暂时隐藏，输入和选择仍保留。
- 底部工具 hover 列表按“页码—单行原文摘要—修改要求”分层；原文弱化、要求突出。拖动工具条、批注编辑、显式发送和放弃确认保持。
- 手机沿用同一缩略图、历史和批注组件，点击可访问 hover 信息；浮层不超出可见画布。只验证 Web 手机视口，不额外构建 APK。
- 开发环境新增独立“验收”项目，使用合成文件和明确演示文案，覆盖 Word、PDF、PPT、表格、图片、Markdown、版本、失败及保留产物等状态；重复执行不得覆盖真实用户会话、草稿或文件。

## 2026-11-01 表格完整格式覆盖（替代上面的简化画布路径）

用户要求覆盖前述遗漏的条件格式、图片、图表及封面。保留既定任务流程、悬浮工具、坐标/公式栏、底部工作表和手机布局；不增加编辑工具栏。使用固定版本 MIT 组件 `@extend-ai/react-xlsx` 的本地 WASM 解析、虚拟化表格与绘图层，复用现有 ZeroAgent 滚动、加载、恢复及阅读状态契约。

- 正文显示原字体/字号、颜色、边框、对齐、合并、隐藏行列、冻结窗格、表格主题、数字/日期格式、条件样式/色阶/数据条/图标集、迷你图、嵌入图像、形状与图表。图表代码按需加载；公式栏保留单元格/范围的只读语义。不能以文本表格替代正常文件的原始格式。
- 完整阅读与输入框封面使用同一个实际查看器。封面固定首个可见表，去除行列头、选区和工具，裁剪真实首屏；包括图片、图表和条件格式，不使用仅支持单元格的另一套缩略图引擎。
- 阅读状态保留当前表、选区和缩放；关闭/换版本/账户失效销毁控制器和 Worker。恢复状态先于写入，避免默认值覆盖。布局展开不重新加载文件。手机仍为原生单指平移、双指或 Ctrl/Cmd 滚轮局部缩放。
- 解析前继续在可终止 Worker 检查 ZIP 实际展开体积、路径和有界网格；不合格的大表保留原有有界降级及下载原件。CSV/TSV 兼容解析仅在内存进行，XLS 保留兼容路径。格式不支持、损坏、超时如实提示，不静默显示空白。
- 不编辑、重算工作簿公式或运行宏；固定补丁关闭引擎加载时自动重算，继续使用已保存结果。条件格式只是本地展示规则。移除预览副本的外部关系、拒绝带活动外链的 SVG，原件不改变。WASM、字体、图表及地图资源全部本地打包，不加入 CDN 或第三方文件服务。
- 验收包括同一真实文件的 ChatGPT 对照，以及合成多表文件的颜色/数据条/图标集、公式缓存、表格/冻结/隐藏、图片/形状、各类图表、缩略图和手机；保留原先的取消、隔离、选区、草稿和批注回归。

实现确认（2026-11-02）：完整 XLSX 路径采用虚拟 DOM 网格和同一绘图层；公共 ScrollArea 承接原生平移与覆盖式双向滚动。WASM/OOXML Worker 保留已保存数值，补齐条件格式及隐藏区域迷你图输入；图片、形状、图表与单元格共同裁切为封面。文件超限或二进制 XLS/CSV/TSV 采用兼容预览，明确提示，不伪称完整 Excel。常见条件比较表达式支持安全解析，未使用 eval。完整验证与剩余差异见 `design-qa.md` 的“表格完整格式覆盖”。
