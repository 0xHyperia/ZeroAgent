# CloudChat 资料空间体验规范

版本：1.0。日期：2026-10-30。实现边界：[ADR0057](../product/decisions/0057-cloudchat-personal-space.md)。

资料空间是当前账户的资料和工作产出中心。核心闭环为：直接上传 → 找到并预览 → 引用到原草稿 →
显式发送并工作 → 正式产出按版本保存 → 再次引用。页面不模拟尚未实现的协作、站点发布或完整Office编辑器。

## 导航与信息架构

- 外层应用轨沿用对话/资料空间/设备、唯一头像及四态。上下文侧栏标题为“资料空间”。
- 分类为全部资料、文档与文件、图像、我的上传、工作产出、收藏；另列真实文件夹、项目资料和研究来源。
- 回收站和容量放在侧栏底部。容量真实统计原件与产出各版本；点击管理可查看明细及回收站。
- 全部资料默认展示根目录和文件夹；分类、收藏和搜索可以找到文件夹内资料。
- 每个产出family展示最新版本，详情保留版本列表；引用的是实际选定版本。

## 桌面布局

内容区最大1240px，常规左右40px留白，中等窗口24px。头部左侧为当前分类/文件夹，右侧为名称搜索、
上传与新建；列表工具和过滤位于下一行。使用既有字体、主题与轻边界，不增加大幅hero或容量看板。
文件名是主信息，来源/状态、大小、修改时间为次信息。表头12px，名称13px，行高至少64px。
仅空间不足时截断名称，独立更多菜单保持可达；hover改变中性底色，不缩放行或移动文字。

收藏资料以“随手可用”呈现，只展示真实收藏，不填充虚构模板。列表与网格使用同一数据与选择状态。
图像网格按需显示受认证原件缩略图；限制可见小图、并发和大小，大文件仍可通过详情下载。
不生成公开S3链接，不把HTML/SVG作为不受信任页面执行。文本按原行号预览，图片在原件详情预览。

搜索覆盖账户所有资料名称，输入延迟180ms；过滤变化清除旧选择及分页。刷新和继续加载保留当前列表，
显示更新状态并暂停旧条目操作，避免先清空再闪回。首次加载显示骨架；空、无匹配、失败分别说明下一步。

## 操作与反馈

更多菜单复用共享软菜单：预览、引用、收藏、重命名、移动、回收站/恢复。桌面hover显现选择框，键盘聚焦
同样显现；手机常显。批量操作只处理选中条目，失败保留已知结果并可显式刷新，不自动重发未知写请求。
引用前复核规范状态，最多8项且排除重复。添加资料不发送模型请求，不替换模型、分组或草稿。

名称/文件夹使用统一Dialog，保存时单次提交；版本冲突保留错误并允许刷新核对。
网络中断或响应异常导致保存结果未知时，暂停再次写入；用户显式刷新并成功读取后再恢复操作。
新建与文件操作菜单共用10px图标文字间距，桌面行高至少36px、手机至少44px。
回收站不等于彻底删除：原件仍占空间，已有引用仍可读。彻底删除在详情明确说明影响并确认，
沿用原服务的删除意图及远端清理；空间不能提前释放。非空文件夹先移出内容再移入回收站。

新建菜单的文档/表格/演示文稿收集创作目标，再进入可编辑的对话任务，原草稿保留并追加要求。
只有用户发送后才运行；不把草稿、临时沙箱文件或尚未确认的发布当作正式成果。
产出是否成功以服务端ready版本为准。默认保存到账户空间，文件夹不冒充执行工作区。

状态与失败复用CloudChatFeedback，就近显示，不横跨整个应用顶部。未知结果、配额不足、解析失败不能自动消失。
容量由服务端提供，总额及原件/产出/回收站明细有相同数据来源，不能用已加载文件大小之和代替账户用量。

## 手机与无障碍

820px及以下，导航继续使用52px应用轨+最多280px上下文面板和清晰浅遮层。主页面左右16px，
名称24px；头部操作可以换行，搜索独立一行、输入16px。次要表格列折叠为名称下的状态/大小，
不出现整页横向表格滚动。更多、复选、页签及Dialog操作触控区至少44px。
网格双列，图片等比contain，名称独立截断；收藏卡横向滚动，不挤成多张细卡片。
容量与页尾尊重安全区。模态标题/关闭始终可见，工作目标Textarea支持长内容及手机输入。
隐藏页面及其弹层退出可访问树，账户变化清理请求和图片URL；焦点、Escape与读屏语义使用共享原语。
减少动态取消装饰过渡和骨架动画，保留全部操作与焦点反馈。真机键盘/系统文件选择器单独验收。

## 后续演进

服务端按账户维护空间与额度；权益系统可映射账户总额。商业套餐、文件夹自动归档、正文/语义检索、
在线文档编辑、共享协作、站点托管和模板市场需要独立能力及安全契约，不能只增加入口冒充已实现。
额度扩大前，先替换当前硬限额下的有界元数据聚合，再建立稳定游标及缩略图服务。
