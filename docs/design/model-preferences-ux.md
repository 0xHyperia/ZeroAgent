# 模型选择与高级配置统一方案

日期：2026-11-05。用户提供当前模型选择器与高级设置截图，要求本地和网页均能配置不同生成任务。
实施基线：f6e73d92。遵循跨端规范、ADR0035/0040/0058/0059，保持当前模型、草稿、账户及设备数据。

## 用户任务与入口

用户在当前对话选择聊天模型，也能直接进入不同任务的模型与相关配置，再返回原对话。
模型选择器保持紧凑，不将整张高级表单挤进候选列表。在可滚动候选之外保留固定底部入口“高级设置”，
点击关闭浮层，在当前工作区上方打开共享高级设置弹窗。供应商页面原来的高级入口到达同一弹窗。
按用户后续纠正，移除设置侧栏新增的“图像创作”和“模型与高级设置”，不增加独立设置页面。
返回时保留当前模型、输入、引用、运行与原工作区，恢复来源控件焦点。

配置按用户任务组织：标题生成、Commit备注、提示词澄清、图像生成，以及运行环境实际支持的媒体能力。
模型与分组选择继续复用ModelPickerContent；选择完整provider/model身份，不按同名模型猜测路由。
未指定文本辅助模型时跟随当前对话，未配置生图模型时明确要求选择，不静默改用聊天模型。
与模型相关的参数沿用其真实后端约束；故障转移、重试和上下文显示沿用原有卡片。

## 布局与状态

恢复修改前的高级设置样式：桌面为约1024px的居中弹窗，保留标题、说明、右上关闭和底部关闭按钮；
两列相隔20px，左侧通用偏好、右侧协议故障转移，列内独立滚动。沿用原有圆角卡片、16px内边距、
12px卡片间距以及共享模型控件。弹窗和内部选择浮层始终使用用户的设置字号，不因从聊天入口打开而缩小。新增图像配置放在通用偏好内，不改变原有卡片视觉规范。
云端同样使用该弹窗与生成模型、生图字段：云端按标题、生图和显示偏好使用单列任务布局，不再显示模型参数表单，不展示设备专属协议和Git配置。
720px及以下沿用原有全屏弹窗和单列滚动，头尾固定；手机常用动作至少44px，说明与选项可换行。
从图像入口打开时保留自定义工作区，关闭弹窗即返回；Escape、关闭按钮恢复来源控件焦点，不更改URL工作区。

加载保留已知内容，首次加载不显示可写空值；保存中避免同字段重入。已保存、失败、冲突、结果待确认分别反馈。
未知写入先重新读取核对，不能自动重发；刷新失败不覆盖用户草稿。切换账户/设备取消旧读取并拒绝迟到回填。
当前已选模型失效时保留可理解的状态及重新选择入口，不把“读取目录失败”当作“模型已被删除”。

## 状态归属和真实能力

共享UI提供模型入口、任务设置行、模型选择器、加载/保存/错误和响应式布局；宿主提供目录、持久化和执行能力。
本机与远程设备沿用既有Native配置版本、备份及标题/Commit/澄清消费者。CloudChat配置绑定账户，
使用独立CAS资源，服务器校验分组归属，真实凭据仍留在平台。生图沿用已有账户生图资源，不建第二套默认值。
云端辅助标题模型须接入真实命名执行，不能只做可保存表单；设备Git模型不能冒充云端Git执行。
视频当前没有执行链路，已向用户询问是否同时接通。尚未收到选择，本轮按现有能力整合并明确显示暂不可用，不保存伪配置。
云端标题任务采用账户内一项和运行时WorkerCount上限，繁忙时保留原始截取标题，不排队重试辅助收费调用。

## 2026-11-05 生图默认值与宿主配置复用纠正

用户要求删除高级设置中的“图像目标与参数”，生图默认未配置，真实可用模型可选，并让云端复用桌面表单。
高级设置只保留共享的生成模型卡片、字段与模型选择器，不再展示目标编辑或第二层工程配置弹窗。
设备候选读取图像服务listTargets，它包含供应商派生模型；不再只读取手工配置的getSettings.targets。
保留服务端返回的公开providerId/modelId用于分组、别名和品牌，过滤停用或不支持生成的目标。
未选择不自动采用第一个模型；空白草稿、新归档和刷新都保持未配置，已保存草稿、显式选择和任务快照保留。
已有不可用选择明确提示并允许清空，不默默替换成另一收费模型。刷新失败保留已知候选。

共享GenerationModelsCard、ModelPreferenceField和ImageModelPreference：两端左列按生成模型、生图模型、显示偏好组织，
同样的图标、标题说明、全宽灰底选择器、未配置选项和刷新反馈。云端不再单独制作品牌行、胶囊选择器和媒体列。
桌面右列继续协议配置；云端仅保留一列任务偏好，沿用共享卡片和字段。云端标题开关、账户CAS、
草稿恢复与显式保存保持；不把设备Git/故障转移设置复制成云端不可消费的控件。手机继续同一全屏单列流程。


## 2026-11-05 模型弹层层级与云端简化

用户任务是快速找模型，其次才是切换执行方式与联网。候选列表继续使用共享目录、搜索、分组与已选定位。
模型页底部合并成一行：左侧有文字的“高级设置”，设备端右侧紧凑 Chat/Agent 单选与带状态的联网按钮；
云端不显示设备执行方式与原生联网。常规底部约44px，触屏动作至少44px，候选滚动区获得余下高度。
思考页只呈现思考滑块、说明、恢复默认和返回模型，不重复执行配置。保留键盘、禁用、能力检查及宿主回调。

云端删除标题推理强度、最大输出和偏好表单，使用约672px单列共享弹窗；无空白右列。
已保存参数及有效旧编辑草稿继续保留，不改写账户数据。标题模型与开关仍显式保存，未知写入先读取核对。
设备继续原有双列协议布局。两端生图卡片移除常驻“刷新模型”行，目录刷新归入选择器已有工具栏；
只有读取/保存失败时才在错误处提供“重新读取”恢复动作，保存不明时不自动重发。普通成功状态按需出现。

验收：桌面与云端候选列表/思考页/设置往返，模型与草稿不变；执行方式与联网切换只触发各自宿主回调；
不支持联网时按钮禁用且不覆盖偏好。云端无参数字段，生图可选/未配置不变；390px无横溢出，设置字号沿用。

### 底栏视觉细化

按确认的单行设计，左侧保留高级设置，右侧使用等宽 Chat / Agent 分段和带标签的小型联网开关。控件同高、垂直居中，选中分段以细边框表示，联网开启用蓝色轨道与滑块位置表示。复用共享开关外观和原有单选、开关语义。触控目标至少 44px，极窄宽度或放大字号时允许换行，避免截断控件。

### 按输出类型筛选

共用选择器在现有筛选菜单中展示「模型类型」和「分组」，保持搜索栏、模型列表和底栏的位置。对话、文本辅助功能和提示词任务限定为文本，生图偏好和图像创作限定为生图。通用选择器允许在全部、文本、生图、生视频和其他之间筛选；固定用途的入口只显示该用途允许的范围。供应商选择继续只显示分组筛选。

能力以目录声明和宿主可执行的目标为准。目录缺少输出信息时识别已知模型 ID，普通及自定义聊天模型仍可选。能读取图像或视频的文本模型继续归类为文本。打开筛选、搜索和切换分组均不修改已选模型。既有不匹配的配置不在后台改写，用户可在原处明确改选。视频类型用于筛选，当前环境的生成入口继续按实际能力呈现。
