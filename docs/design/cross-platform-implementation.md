# 跨端体验统一实施与验收

目标：以当前 CloudChat 为基准统一桌面、移动和 Web 的组件、风格及交互，保留现有功能和必要平台差异，测试后交付，不推送。
基线：`dd23fe0d`；分支：`codex/cloudchat-workspace-20261030`。
规范：[跨端组件与交互规范](zeroagent-cross-platform-ux.md)；决策：[ADR0058](../product/decisions/0058-cross-platform-design-system.md)。

当前状态：共享实现与宿主接入已完成。桌面中文粘贴、选择/撤销、设置往返保留草稿及系统文件选择已实测；Android 已实测导航、模型浮层、系统文件选择、设置安全区与分层返回、软回车换行、中文拼音候选、原生选词/替换/全选及清空。临时输入法和模拟器按键配置已恢复。用户已取消截图层并手动缩窄 Native 窗口；当前尺寸下的设置和模型/思考浮层可用，多面板下起步卡片已改按画布宽度响应并更新产物。在线测试设备仍未恢复，完整目标保持未完成。构建和组件回归不能代替未完成的在线远程实测。

## 桌面外框与侧栏层级对齐

用户指出桌面固定侧栏仍为直角、内容区独自圆角。本次将装饰外框归属改为侧栏与内容区的整体，
应用轨位于框外；固定展开时只保留内部细分隔线，收起时内容区恢复完整左侧圆角。
外框不命中指针，保持原窗口按钮、拖动、侧栏状态和工作台控制器。
CloudChat 与桌面共用18px外框变量；临时预览、Portal菜单使用共享16px浮层及阴影。
侧栏菜单统一字号、图标、条目圆角和间距，鼠标36px行高、触屏44px；新对话统一使用编辑图标。

Windows 会话当前已恢复。实际 Native 已检查固定展开、收起、临时预览、右键菜单和 Escape 关闭，
预览未推移正文；截图 `48`–`51`，CloudChat 参考为 `47`。22 项侧栏/菜单/页头回归、UI类型、严格 Biome、
UI边界和产品契约通过；最新Web及GUI前端构建均退出0。本次针对桌面与Web展示修整，Android APK未随本次重新编译，不称其包含本次样式。
完整跨端目标的在线设备、精确最小窗宽/拖动区及 Android 硬件撤销未完成项继续保留。
