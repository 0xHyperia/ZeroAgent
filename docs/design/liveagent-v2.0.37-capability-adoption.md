# LiveAgent v2.0.37 能力接入

上游基线为 `e2aa416ccb0ac1dd01fdacee7a8e46544fab36b8`。使用该版本的共享功能和 K-brain 协议，沿用 [ADR 0034](../product/decisions/0034-upstream-first-fresh-preview.md) 的上游优先原则。设备插件与[账户扩展](cloudchat-extensions-ux.md)分别由设备和账户提供状态。

## 设备插件

在设备工作台的设置中打开「插件」。沿用设置页的标题、行间距、主题和侧栏。在宽窗显示插件来源、启用状态和当前工作区。窄窗使用单列，工作区在标题下方，次要动作进入更多菜单。设置页面保留原会话、选择的窗格和草稿。账户「自定义」继续使用原目录及其公开和个人来源，按当前云端开放状态提供操作。

```text
设备工作台 → 设置 → 插件
                      当前设备 / 工作区
                      [从文件夹安装] [重新加载]
                      用户插件     名称   启用   更多
                      工作区插件   名称   启用   更多
右侧工具区 → 插件面板 → 当前工作区已启用插件的声明面板
对话工具结果 → MCP 应用 → 查看结果 / 按当前审批策略操作
```

列表区分加载、空、不可达、缺少后端能力及工作区未信任。文件夹信任和安装由用户明确发起，先确定操作的设备和工作区。选择目录或关闭弹层后恢复按钮焦点。操作等待、失败及状态重读在原行显示。撤销设备授权、退出、切换工作区或停用插件时关闭过期的面板和响应。移动端面板使用共享窄窗工具区，工具结果保留文本入口。

组件和插件协议以 K-brain 上游为基础。设备上仅由 K-brain 管理插件状态。Native 和 Gateway 以当前账户、设备租约和已授权工作区提供显式宿主能力。安装目录用原生选择器或该设备授权目录选择流程确认。启停、重载及移除与现有配置写入和设备回执对齐。页面能力探测随设备和后端会话失效，云端关闭时仍可浏览公开简介。

面板页面经宿主读取限定来源并挂载在共享沙盒中。调用工具确认限定当前账户、设备、工作区、插件版本和工具，重新执行需通过设备原审批。设备后端地址和访问令牌由宿主持有。已有账户包、不可变修订与历史引用继续通过原账户目录解析，设备直接加载上游插件声明。两类包按各自来源处理，保留原安装和启用事实。

## 搜索、导航与编辑器

复用已有命令面板和设置侧栏。命令面板支持搜索命令、`@` 快速打开项目文件和 `#` 搜索对话，并保留关闭与焦点返回。设置搜索在现有分类中定位可见设置项。空查询显示现有快捷动作，加载、无匹配和不可用目标分别反馈。窄窗面板保持输入和首条结果可达，在键盘及触控下均能选中。

文件索引只从当前已授权文件树取数据，缓存按账户、设备和工作区隔离。文件结果复用现有标签打开流程。导航返回和前进使用现有会话及文件入口，切设备或撤权结束原作用域。快捷键由同一注册表解析，遵循 IME、弹窗、终端和阅读器焦点。编辑器选项复用现有文件工具栏与原生启动校验。

## 对话和加载

保持原对话、分栏、文件树和输入区布局。实时消息由当前分栏内的回复行订阅，列表只读取决定行结构的变化。跟随、查找、历史回填、语音输入、Git 审查和批注继续使用当前会话的状态与入口。WebUI 的认证入口保留既有 OAuth、分享及恢复地址，独立页面按需启动较重的工作台。桌面内嵌继续以每次挂载隔离的工厂提供模块状态。

断线和设备离线的反馈在当前对话顶部呈现。用户可以重连原设备，草稿与附件留在原会话。回执未知时使用原请求标识核对，已选离线设备仍可辨认。明确切换设备后加载其工作台，旧请求及旧附件不流入该工作台。HTML 运行成果和图片批注经共享内容预览及草稿引用交付，展开预览时保留原件、焦点和阅读位置。

## 验收路径

- 用同一源码构建桌面、设备 WebUI 与 Android，记录构建来源。在本机、浏览器远程和桌面远程打开同一会话及文件，核对快速打开、草稿、标签、焦点、查找、断线重连和撤权。窄窗检查设置、列表和命令结果。
- 在隔离设备上检查插件只读列表、可信目录安装、启停、重载、移除和权限失效。打开同一插件面板，确认不同账户、工作区及设备的审批互相隔离。检查不支持引擎及云端关闭时的入口和反馈，覆盖现有固定技能引用。
- 复用上游原生端到端用例，使用隔离的 `ZEROAGENT_DEV_HOME`、设备会话、测试模型和匹配的运行时。记录构建、协议、测试配置和真实设备可验证范围。诊断预览只选取当前允许读取的应用信息。

## 剩余能力的接入方案

### 回合、连接和草稿

用户从当前对话继续正在运行或已经中断的回合。实时进度、重启后历史和原回合回执采用同一错误分类、可显示说明和停止原因。连接提示位于对话阅读列顶部，宽窗与手机均保留输入和草稿。未知结果按原请求编号在原设备核对。选另一台设备由用户发起，原对话及待发输入留在原环境。显示偏好按当前宿主归属保存，设备配置仍需经过授权与版本检查。

从回复选区或差异行使用评论动作，在原位置填入批注，确认后在输入区显示可编辑的上下文片段。触屏复用同一动作和输入区，关闭浮层归还焦点。对待发送图片从附件卡片进入标记，窄窗使用全高编辑区。保存标记生成派生图，上传成功后才更新草稿，编辑取消、失败和作用域变更时保留原件。已有阅读器批注与会话草稿归属继续按原流程管理。

### HTML 成果、插件面板与 MCP Apps

回复中的成果卡提供查看和源码入口，历史重开能按会话查回原产物。宽窗在工作区并排阅读，窄窗和手机占用完整阅读区，返回保留焦点和滚动位置。加载、缺少记录与失权在原卡反馈，正文或源码仍可阅读。受限的本机和远程宿主分别提供会话成果内容，共用预览与沙盒组件。

已启用插件的声明面板从工具区打开，MCP 应用从对应工具结果进入。面板在窄窗显示全宽内容，工具结果保留文本。渲染器仅取得当前窗口所需内容，Native/Gateway 按账户、设备授权、工作区和会话绑定资源。过期回执、停用和撤权清理当前内容。发起工具操作使用现有工具审批；发送源、请求标识和来源作用域必须在宿主复核。先验证只读内容和历史回放，再启用已授权的交互。

### 设置、编辑器与诊断

本机用户从「设置 → 智能 → 权限」检查和撤销已记住的工具授权，也可明确选择「所有项目」或「本项目」添加规则。复用共享设置导航、权限规则列表、选择器和确认控件。窄窗纵向排列两级规则及添加表单，项目切换时只展示已核对归属的项目规则。设置入口随已登录账户和「此电脑」选择启用，远程及云端沿用各自现有权限。规则继续写入该账户的设备引擎，切换账户或离开页面后丢弃迟到的界面回执。

项目设置在原通用面板显示有效目录信任及来源，确认后刷新已有命令和插件目录。设备撤权和凭据轮换复用共享确认弹窗，取消归还焦点。工具行显示当前设备可公开的 MCP 服务名称。键盘直达输入区沿用现有焦点与模态守卫。

文件、项目及消息文件链接使用同一外部编辑器入口。等候探测或宿主不可用时保留读取及系统默认打开入口，当前宿主返回可用编辑器和设备首选项。桌面菜单复用工具栏及文件树动作，手机保留宿主明确提供的操作。路径、工作区和行列参数在宿主校验。

从「关于」进入诊断预览，展示当前应用、宿主连接状态和安全错误码。用户确认后保存或复制，预览从当前页面打开和返回，失败在原位置反馈。首次引导沿用账号、连接设备和工作区选择，已有可用配置可以跳过，状态按当前账户或安装保存。诊断输入仅采用已定义的状态和版本字段。

### 产物与验收

桌面首次加载优先交付登录、工作台导航和输入区，文件阅读器、终端、差异高亮及工具面板按入口加载。桌面与 WebUI 各自验证生产输出，桌面内嵌的设备 WebUI 继续通过已有工厂加载。原生回归在隔离用户目录与受控测试模型上运行。记录产物来源、入口与尺寸，核对运行恢复、焦点、断线、撤权、批注、预览与工具审批。

## 接续入口与状态

- 命令面板从当前宿主可见的设置目录取分类和锚点，结果直接打开设置并定位控件。窄窗先进入详情，退出还原原对话及焦点。会话侧栏用共享键盘导航，方向键移动焦点，行内动作和上下文菜单沿用现有控件。快捷命令按当前宿主、目标分屏及现有审批限制提供，提示音沿用运行通知设置中的独立选项。
- 审批卡使用审批所属会话的工作区显示匹配文件的相对路径。工作区外的文件和无项目审批继续显示完整目标。文件提及保留原检索入口，读取失败在选择器内提示，并保持输入焦点与草稿。
- 文件、项目及消息链接在已有上下文菜单提供本机检测到的编辑器。系统默认应用仍在原位置，编辑器首选项用于支持的源码和项目入口。原生校验授权路径，拒绝旧弹层或当前宿主无法执行的启动。宽窗保留原文件与工具区，窄窗菜单可滚动并在关闭后归还焦点。
- 目录信任在项目设置显示直接或继承状态，许可变化后刷新当前项目的命令。远程界面依据现有租约投影信任范围。MCP 设置显示服务名称及应用工具可用性，HTML 预览偏好关闭后保留源码。插件声明面板与只读结果沿用经授权的隔离预览。
- 已登录的桌面用户可从「关于」重新打开入门指引。首次准备本机时，指引从账户、模型和项目三步开始，可跳过或回到原工作区。每一步沿用对应的设置入口，模型和目录准备状态由各自宿主读取。引导不索取、复制或同步密钥，按当前账户保存完成状态。
- 本轮就绪检查分别记录实现、实际运行验收和发布条件。受管远程权限、云端开放策略和设备租约继续以产品契约为准。签名安装、真实账户三入口和授权失效按实际环境记录结果。
