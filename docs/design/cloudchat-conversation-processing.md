# CloudChat 完整对话处理与验收方案

日期：2026-10-31。状态：功能实现与本地集中联调完成，实际结果和验证限制见实施记录；不据此宣称完成生产部署验收。沿用 ADR0048、0049、0058、0059 和现有对话/工作体验规范。

目标是让用户在 CloudChat 完成准备资料、发送、多轮追问、查看工作过程、停止与恢复、编辑与分支、查找历史和交付成果的完整流程。以本地 LibreChat 固定版本及 ZeroAgent 桌面实现为依据，保留 Gateway 唯一执行器、账户隔离、正式历史与资料空间。每项功能均有开发环境可操作的验收场景。

## 用户任务与布局

桌面保留 `应用轨 | 会话/项目侧栏 | 对话阅读列 | 按需资料工作区`；手机保留单列阅读与底部输入，资料进入可返回的阅读页。工具过程、思考和错误属于发生它们的回复，不成为页面顶部横幅。消息动作沿用共享控件，不再建立一套 CloudChat 消息气泡。

每条回复按真实顺序呈现正文、模型返回的思考、工具状态和后续正文。正文优先阅读，思考默认折叠；进行中的工具给出简洁动作和状态，完成后仍可回看。没有模型思考字段时不虚构思考文本。工具参数、私有路径和原始执行回执不直接展示；需要查看的成果与引用通过原有受认证资源入口打开。时间、模型与用量属于对应轮次，不能借用当前输入框模型解释旧回复。

输入继续使用同一个编辑器。普通会话切换保存各自的结构化草稿和资源引用，返回时恢复；“新对话”是明确的新空白草稿操作，直到发送才创建记录。生成中仍允许准备下一条内容；排队必须表达“尚未发送”，可修改和移除，不得把运行恢复变成重复发送。失败、取消、未知结果需要明确用户动作才能继续，不能偷偷发送下一条。

编辑、重生成及从此处分支保留原对话。分支关系应让用户能返回来源或选择相关分支，不以大量无来源的重复标题代替。查找历史需覆盖服务端范围，并清楚区分标题搜索和正文匹配；加载更多、刷新和失败均保留已知内容及草稿。

## 状态与实现边界

- 继续使用持久 Run、执行租约、幂等请求与递增事件水位。页面订阅和服务端取消是不同操作；重放只恢复显示，不重新调用模型或工具。
- 增加有界的公开回复过程快照，保留现有 `output` 正文契约。流式事件、终态历史、分支与导出来自同一提交事实；PostgreSQL 和内存存储必须同合同，不以浏览器缓存替代持久化。
- 思考只读取模型明确返回的公开字段，独立进行分片密钥过滤、UTF-8 与大小检查，不从系统提示词或隐藏内部状态推导。
- 工具过程使用已校验名称、稳定 ID、轮次与状态；允许列表覆盖所有真实云工具，包括站点产出。未知结果不能改写为已成功或已停止。
- 草稿归当前账户和会话所有，资源引用不代表授权；发送时仍由服务端复核。切号、退出、失效清理旧草稿，迟到操作不得恢复旧身份。
- 共享 UI 仅负责呈现。云端不显示本机终端、Git、审批或原生执行入口，不复制桌面授权客户端。
- 本地开发数据使用明确的验收前缀和来源记录，重复执行不重复创建、不覆盖用户后来修改，不调用付费模型来模拟状态，也不把合成输出当成真实模型能力证据。

## 完整范围与证明

| 功能 | 必须实现/保留的结果 | 验收数据与证据 |
| --- | --- | --- |
| 新对话、草稿、多轮 | 无空记录；结构化草稿、附件与模型选择保持；账户隔离 | 两个独立草稿、资源引用、成功多轮与切换/刷新 |
| 流式回复与过程 | 正文、思考、工具顺序、模型/用量/时间；完整历史可回看 | 多轮工具、思考、普通 Markdown/表格/代码/公式 |
| 任务生命周期 | 排队、运行、取消、完成、失败、中断、未知结果准确 | 各终态历史与可启动的本地流式/取消场景；断线重放 |
| 继续输入与发送队列 | 明确尚未发送、编辑/删除、原会话与参数绑定、停止后不误发 | 生成中准备/排队、失败后保留、切换与恢复 |
| 编辑/重生成/分支 | 保留原历史和上下文、能追溯来源并导航 | 原会话与编辑/重生/分支样本；重放不重复创建 |
| 历史与管理 | 分页、搜索、改名、置顶、删除、项目关联和导出 | 超一页历史、长消息、匹配项在后页、项目样本 |
| 附件与资料 | 上传/选择/拖入、预览、引用、移除与不可用恢复 | 既有 20 份真实原件；跨格式、失败与删除引用 |
| 工具与交付 | 公开研究、来源定位、分析产出、版本和站点入口 | 有来源及成果版本的对话；真实外部执行另行验证 |
| 阅读与可访问性 | 跟随/离底、回到底部、长文虚拟列表、复制与消息操作 | 长历史/长正文，宽窄屏、键盘、浅深主题 |
| 多端与安全 | Web/移动共享体验，桌面/远程原能力和状态不回退 | 相关回归、类型/构建、实际浏览器；原生差异另记 |

实际检查结果记在 `docs/cloudchat/CONVERSATION_IMPLEMENTATION.md`，包括集中回归、真实浏览器与一次真实模型/E2B 文件产出的证据，以及未执行的外部环境演练。本表定义本次完整目标；语音、运营角色/分组/审计和新增第三方模型连接仍不在本次范围。资料空间已有原件和用户对话保持，不清除用户数据，不推送或部署生产。
