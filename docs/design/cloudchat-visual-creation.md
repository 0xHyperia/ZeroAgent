# 会话视觉创作：Product Design 与 ImageGen

2026-11-04。依据用户两段录屏、设计方案图片及既有跨端规范实施。这里的 Product Design 是
ZeroAgent 内置的设计工作流，ImageGen 是同一 Agent 可调用的生图技能；不假称连接 ChatGPT
私有插件。保留原对话、草稿、模型选择、资料原件及任务状态，不引入第二条 Agent 执行循环。

## 用户任务与完整流程

- 用户描述图片或设计目标，Agent 按需读取 imagegen / product-design 技能。设计工作先明确
  任务、页面与关键状态，已有参考优先沿用；视觉探索生成真实图片，选定方向后再实现和检查。
- 默认生图模型位于设置的“图像创作”，从账户已连接的 USA-Zero 分组及模型选择。独立于聊天
  模型；只保存模型 ID 与分组密钥 ID，不保存密钥或任意服务地址。无配置时仍提供技能发现，
  返回需要配置的真实状态，会话就近显示“选择生图模型”，直达设置；原草稿与附件保持。
- 生成与编辑由当前 Run 的 generate_image 工具执行，提示词、画幅、质量和原件引用受边界
  校验。编辑只接受当前账户可读取的真实图片，结果作为新成果/新版本保存。禁止伪造图片地址。
- 成果在会话内显示，并自动进入个人资料空间；可打开、下载、引用并继续修改。只有明确的
  分享操作才授权对外访问，图片不会因为生成而公开。

## 布局与视觉状态

- 桌面沿用聊天阅读列。单图保持原比例、限制最大宽度，不套多层卡片；多图为主图加窄缩略图
  列，当前项明确细描边；手机缩略图移到底部。图片出现交叉淡入，尺寸预留，避免正文跳动。
- 生成等待占据图片画幅，低对比点阵、柔和扫光及短状态文案；不显示模拟百分比，不循环插入
  spinner 卡片。执行/保存/未知/失败从真实 Run 工具状态驱动；停止复用已有 Run 取消入口。
- 图片按钮只在 hover/键盘聚焦时显现，触屏常驻核心操作；复用 Tooltip、胶囊、菜单、预览器。
  支持键盘焦点、替代文本、减少动态效果和深色模式。没有接通的编辑、画笔及分享不摆装饰按钮。
- 图片读取与宿主身份绑定。切号/切会话取消读取并撤销 Blob URL，不把鉴权 URL 当图片内容。
  渲染与下载共用既有资料预览器，避免另建一套缩放与媒体弹窗。

图片读取缓存限于当前会话的八份结果；缩略图复用已验证 bytes，主图只解码当前选项。
切换项使用短淡入，不保留八张大图的隐藏 DOM。配置使用共享分组/厂商模型选择器，重新打开
定位到当前项；仅保存账户生图偏好，不能修改对话模型或清空输入。

## 执行与持久化

沿用 Gateway Go Run + CloudToolOperation + PostgreSQL + 当前对象存储。独立、有版本的账户
生图偏好；提交前重新校验分组归属和可用模型，服务端取凭据。仅调用固定 USA 图片路径，
禁用重定向及任意返回 URL 下载。一次调用生成一张图，多方案显式分次调用，逐张持久化，
避免同一操作内的部分结果无法恢复。幂等 ID 来自持久化工具操作；未知执行只呈现待确认，
不自动重发付费请求。原始 bytes 经大小、格式、像素及摘要校验后写入账户成果库，配额、
Run 租约及删除并发边界沿用现有存储契约。模型仅收到成果引用，不接收 base64 大对象。

供应商协议参照 OpenAI 官方 [生成接口](https://developers.openai.com/api/reference/resources/images/methods/generate)
及 [编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。GPT Image 使用
PNG/base64 返回，参考编辑使用 multipart 图片。这里要求平台提供 Images 兼容端点，不把任意
聊天模型列入“已经支持生图”的承诺；运行时拒绝或未知结果单独反馈。

内置技能不包含宿主插件专用工具名或不可用能力。Web/响应式移动端使用账户生图能力，
设备端保留现有图像工作台及其隔离的任务/连接，不能以 CloudChat 的账户身份冒充设备身份。

## 验收

覆盖偏好跨设备及并发保存、缺配置引导、分组归属、生成/参考编辑、真实 bytes 校验、
配额、未知结果不重发、取消/切号、会话重开、单图/多图与手机布局。使用本地受控供应商
验证端到端执行与持久化；真实平台生图单独记录，不把 fixture 或构建通过当作真实模型验收。

### 本轮实施验证（2026-11-04）

- Go account、cloudbackup、cloudchat 测试及 account vet 通过；使用本机 PostgreSQL 的独立测试
  schema 验证偏好 CAS、并发保存、跨账户隔离，测试结束清理该 schema，不改现有账户资料。
- 相关前端 11 项回归、Web 生产构建、共享 UI 和桌面 UI 类型检查通过；产品契约检查通过。
- 隔离的生产包浏览器验收：缺配置直达设置、分组/默认模型保存、三方案切换、打开统一图片
  阅读器、选图加入原草稿、参考编辑保存新版本、刷新恢复；聊天模型保持不变。
- 390×844 手机视口无横向溢出，缩略图在主图下排列；手机完整图片预览沿用既有缩放、
  下载与返回。图像解码和主题色按实际浏览器检查修正，等待按真实工具状态呈现，已有成果
  后继续创作使用紧凑状态，不插入另一整块空画幅。
- 浏览器供应商仅为本地协议 fixture，输出是程序合成 PNG，未调用真实 USA 生图/E2B，
  不证明真实模型的效果或所有 Images 兼容模型的协议支持。正常开发环境保留原账户配置，
  没有替用户选择收费模型。实际模型应在设置中明确选择后验收。
- 原有 `cloud-chat-artifacts.test.mjs` 另一次运行有 4 项依赖已移除菜单名称的断言失败，
