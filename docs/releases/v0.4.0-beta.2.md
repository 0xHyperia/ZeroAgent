# ZeroAgent 0.4.0-beta.2

本地预览候选，尚未发布。

- 账号入口移至侧栏底部，集中提供账号、设置和退出操作；资料、余额、用量、设备与安全保留在账号页。
- 平台内模型支持自定义 ID、显示名称、启停、排序、上下文窗口、输出上限及适用参数。服务地址与凭据继续由 USA-Zero 管理。
- 刷新模型列表保留用户配置和禁用状态；首次发现失败后可正常重试。
- 启动等待凭据就绪时保留模型启用与选择；缓存提示采用可保存的供应商级设置。
- Kimi、DeepSeek、GLM 等模型按名称显示对应厂商图标，并改善暗色主题显示。
- 在桌面“备份与同步”中恢复手动导入旧 ZeroAgent 会话。保留原文件、已有会话和删除意图，不导入旧供应商或密钥。
- 更新后端与共享界面能力，完善设备端 Skills 设置的版本检查，收紧模型目录发现的连接约束。

此候选尚未签名，安装、账号与设备完整流程及其他平台仍需进一步验收。会话导入中的不支持或不完整记录会显示失败详情，不能保证任意旧数据均可无损转换。
