# ZeroAgent 0.4.0-beta.2

预览候选，最终同源Desktop与Android CI全部成功，尚未发布。

- 账号入口移至侧栏底部，集中提供账号、设置和退出操作；资料、余额、用量、设备与安全保留在账号页。
- 平台内模型支持自定义 ID、显示名称、启停、排序、上下文窗口、输出上限及适用参数。服务地址与凭据继续由 USA-Zero 管理。
- 刷新模型列表保留用户配置和禁用状态；首次发现失败后可正常重试。
- 启动等待凭据就绪时保留模型启用与选择；缓存提示采用可保存的供应商级设置。
- Kimi、DeepSeek、GLM 等模型按名称显示对应厂商图标，并改善暗色主题显示。
- 在桌面“备份与同步”中恢复手动导入旧 ZeroAgent 会话。保留原文件、已有会话和删除意图，不导入旧供应商或密钥。
- 更新后端与共享界面能力，完善设备端 Skills 设置的版本检查，收紧模型目录发现的连接约束。
- 修复工作区目录别名的项目提示词投影，并在保存失败时恢复原内容与路径身份。

Windows便携候选已完成托管短对话、模型设置禁用探针重启保持及全开恢复后的抽检。首轮重启点击“重新连接”即可恢复，无需重新登录；第二轮自动进入工作区。首次连接错误原因仍待确认。

Windows NSIS本地候选已完成从0.3.23原地升级、安装后Write人工允许/拒绝及正常重启检查。本地产物仍未签名；另一次CI的MSI/NSIS正式更新签名已实际验签，并在临时Windows runner完成两种安装器的安装、载荷验证与卸载。更新签名不代表Windows Authenticode。

最终源码37922157的Windows完整Native库1310/0/11，macOS两架构各1344/0/10；四平台打包与七组真实updater签名通过，下载后的七对实际文件再次本地验签通过，11份二进制及更新清单已暂存并独立核对。Android最终正式签名APK在新空白模拟器完成0.3.23覆盖升级，应用身份与首次安装时间保持，匿名登录页正常。

完整账号设备流程、Android真实凭据加密状态冷启、Mac/Linux GUI与原生凭据/更新及目标物理设备检查仍待人工反馈；Windows Authenticode与Apple Developer ID/公证未配置或验收。会话导入中的不支持或不完整记录会显示失败详情，不能保证任意旧数据均可无损转换。候选CI未创建tag、Release或部署。
