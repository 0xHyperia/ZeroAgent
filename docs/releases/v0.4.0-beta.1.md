# ZeroAgent v0.4.0-beta.1（草稿）

本预览版尚未发布。工具允许执行、真实账户与远程设备完整流程、安装升级和部分平台条件仍在验收，尚无正式签名；本草稿不代表全平台可用。

## 主要变化

- 更新设备Agent的对话与工具执行流程，统一任务状态、工具审批和会话记录。
- 继续使用USA-Zero登录、账户权益和托管模型，仅显示当前账户有权使用的托管模型。
- 保持账户数据、设备和项目授权隔离。远程执行需明确选择自有设备，项目操作遵循该设备发布的项目范围；Cloud Chat不提供桌面本地工具。
- 远程设备失联或从列表消失时保留原选择并禁发，需要用户明确选择可用目标，不会自动改成本机执行。
- 账户退出或授权失效后，远程连接停止接受新控制和输出；改进Android退出、切换账户时的会话隔离。
- 保留托管密钥默认遮罩及显示、复制前的二次认证。
- MCP支持stdio、Streamable HTTP和标准SSE接入，保留OAuth授权，改进调用取消与进程退出清理。
- Android原生库和APK布局按16KB对齐，修正更新检查的预览版本排序及稳定渠道判断；真实16KiB内核运行和实际更新仍待验证。

## 全新配置与备份

本版使用全新配置，启动时不读取、迁移或清理旧版本的对话、工作区、模型服务商及其他配置；旧数据保留在原位置。

新版备份支持导出、恢复和WebDAV同步，不包含账号登录凭据、模型服务商及默认模型；恢复后需重新选择有权使用的托管模型。旧版备份和旧自建服务商不导入，新数据不提供回迁旧版的能力。

## 当前候选范围

当前已构建Windows安装包与便携版、Linux AppImage/DEB/RPM和Android ARM64包。Windows已验证托管对话、正常退出及重启恢复；Linux完成基础启动与正常退出。Android已完成模拟器安装和登录页启动，真实登录、安全存储及更新仍待验收。

现有安装的覆盖、升级及卸载流程尚未验收。macOS尚未完成构建验收；Android当前包未签名，不能直接安装。最终支持平台、安装方式与更新说明将在验收完成后公布。
