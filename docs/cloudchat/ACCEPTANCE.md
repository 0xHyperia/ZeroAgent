代表性任务：中文方案多轮改写；两份 PDF 差异和页码；DOCX 信息提取；CSV/XLSX 清洗与可复核合计；有来源研究报告；图表及报告连续修订；小型代码项目修复并运行测试。每项需固定输入、预期可检查结果、失败样例与证据。具体样例随对应能力实现加入。

## 本轮有限场景基线

每个场景至少保存原输入、用户指令、调用/费用事实、可核对结果及失败案例。协议夹具仅证明接线，不能替代以下真实任务结果；不以竞品未来新增入口无限扩大完成条件。

1. 中文写作：根据给定事实写方案，连续两次修改要求，刷新后接续；已确认的限制和内容保留，Markdown/JSON导出与规范历史一致。
2. 文档理解：两份带明确差异的PDF及一份DOCX，提取事实和差异，引用定位到正确页/段，明确扫描件和部分提取限制；图片描述由真实视觉模型验收，不能拿hash一致当识图质量。
3. 联网研究：固定一个有时间边界的问题，从公开原始来源形成报告；每项事实可回溯到网页正文行号，搜索摘要不冒充正文，失效/未知来源明确反馈。
4. 表格分析：含重复项、空值和已知合计的CSV/XLSX，计算结果与独立基准一致；输出清洗表、图表和解释，并能下载打开。要求修改一项规则后重算，不能只改答案中的数字。
5. 成果修改：生成正式文档/表格，在原VM终止后从新会话载入，保存v2；旧版内容/摘要不变，来源关联正确，所有正式文件可下载。
6. 项目接续：两个账户、两个浏览器会话，项目指令与资料仅影响正确范围；显式记忆开关、退出/切号、断线恢复不串账号，不从删除的资源恢复正文。
7. 编程辅助：上传小型代码夹具，指出缺陷、修改并真实运行其测试，交付可审阅diff和修复文件；不把模型声称“测试通过”视为执行证据，不要求实现完整云端IDE。

组合任务还需检查研究结果与私有资料的综合质量：只批准通用公开主题，同时在私有项目中
保留会议纪要的5000元预算、2026-11-15期限和未知客户数。最终方案应正确使用这些限制，
而公开搜索/网页请求中不能出现私有标记；随后要求生成可打开的报告文件。不能只以模型
请求里出现了私有上下文或最终答案有引用判断完成，需核对最终内容及实际文件。这也用于
检验公开阶段结束后的模型消息格式和共享轮次预算是否足以完成综合与成果交付。

容量与恢复另行验收：按普通/长任务混合测排队公平、任务/工具延迟、DB/S3读取字节、journal增长、实际费用；初始配置只作校准起点。恢复演练需完整对象及私有journal，且旧认证快照不得复活已注销/撤销权限。

固定内容输入及逐项审阅任务位于 Gateway `test/cloudchat/quality/README.md`。
离线生成器已产出两份可提取 PDF、一份中文 DOCX、CSV/XLSX 和含真实失败测试的小型代码 ZIP，
独立基准为净额44.25、排除退款49.50及明确日期/预算。输入及摘要在 ignored
`cloudchat-quality-inputs-20261029/`，它们尚未经过真实模型，不能记为内容质量通过。

补充`cloudchat-quality-inputs-20261029-v2/`含中文金额表PNG与无文本层扫描PDF，合计8份。
PNG须由真实视觉模型准确识别标签/金额；扫描件须明确文本提取限制。长历史还需验证超过
500条会话可翻页进入、失败重试保持草稿；离线后重开须显示failed/cancelled/interrupted等
真实终态，未知取消不能误称操作未发生或重新执行。ZIP场景必须从正式上传入口开始，
不绕过上传校验直接把夹具放入沙箱。

最新有限工程证据包括 Linux 全模块 race/vet、10账户×3任务本地容量、真实 Garage S3、
SDK 实际容器崩溃恢复及隔离完整备份恢复；各自的环境、范围与未覆盖项见 `PROGRESS.md`。
生产审查复现的参数、联网出站和取消未知状态缺陷必须修复并复验后才能交付候选。
