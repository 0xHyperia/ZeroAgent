# 资料空间站点

## 当前运行范围

已接入成果 ZIP 的静态站点版本、私人预览、显式分享、版本固定和撤销。用户在成果面板选择一个正式版本，
点击“预览站点”，通过包和原件校验后打开隔离页面；分享弹窗不会自动创建链接。
普通 ZIP 仍可浏览目录和下载，保存站点版本不改变旧的成果引用、下载或删除行为。

站点配置、对象存储和隔离执行均启用时，工作任务可调用 publish_site。AI 先在工作区构建/验证，
再提供选定目录（如 project/dist）及 ZIP 下载名称，可用已有 family_id 接续不可变版本。
工具不接受对象密钥、沙箱标识、公共 URL 或分享参数。未配置站点时不向模型声明此工具。

打包程序是执行器随包携带的固定 Python 源码，在归属验证后的 Linux VM 内以普通用户运行；
参数走有界标准输入，不拼接到可执行代码。只选定子目录，拒绝隐藏配置、依赖目录、链接、特殊文件、
路径冲突和超限资源；检查打包期间变化，使用独占目标原子重命名，不能覆盖上次结果。
Gateway 重新校验 ZIP、来源、大小和摘要，通过现有成果预留/日志/对象验证流程保存。
内部站点清单在成果变为 ready 前写入并校验执行租约，staging 状态仍不能签发访问授权。

父工具及打包子操作均保留稳定标识。未知回执不重新打包；写入结果不明时只读核对原操作，
不能发一个新请求冒充重试。模型仅取得 ready 成果 ID、站点版本和默认私有状态，不取得能力链接。
构建仍遵守 VM 禁止联网的约束：依赖需来自预置模板或用户已提供的工作区，不能在 Gateway 构建、
放开公网下载依赖或执行站点后端。没有将协议测试当成实际 E2B/模型能力验收。

当前必须包含 `index.html`。CSS、脚本、字体、图片和数据均放在包内，并使用 `./` 相对基址；
例如 Vite 生产构建使用 `base: './'`。根绝对路径、外部 CDN、服务器程序和动态后端不在这个静态托管契约内。
从 AI 工作目录安全打包并交付站点的工具已接入；合成成果和隔离执行器验收不能替代真实 AI/E2B 构建验收。

## 存储和授权

资料空间的“站点”分类复用成果家族 ID、文件夹、名称、收藏及回收站，不创建重复对象或第二套容量。
列表的 site_version_id 来自该账户已登记且原件 ready/SHA 匹配的不可变版本，打开、引用均绑定该版本。
新版本处于暂存或失败状态时继续提供上一份可用站点；若正式最新成果改成未登记的普通文件，
该家族仍在工作产出中，不把旧站点冒充最新成果。站点清单写入会更新空间分页代次。

点击站点条目即请求该版本的短期私人预览，不创建公共分享。手机使用同一个成果面板和版本控件。
“新建”菜单中的站点入口只在托管已配置时提供，将目标带到可编辑的工作草稿；用户发送前不执行任务。

- 原件仍在 SeaweedFS S3，使用现有成果家族、不可变版本、摘要、元数据和容量预留。没有第二份站点文件副本。
- PostgreSQL 的站点版本表保存受限清单；授权表保存绑定版本、模式、到期时间和撤销版本号。不保存原始签名 token。
- 私人预览链接默认十分钟，绑定当前账户的会话引用，退出登录或会话失效后拒绝新请求。
- 分享链接由用户明确创建，可选 1、7 或 30 天。访问者持有链接即可读取选定版本；该能力不授予整个资料空间。
- 新版本不更新已有分享链接的目标。用户可撤销单条分享；删除成果家族会停止其所有站点访问。
- 链接是访问凭据，不应发给模型、写入业务日志或用于追踪参数。反向代理应隐藏 `/v/` 后的路径和查询日志。
- 已经下载到访问者设备的内容无法远程收回；撤销针对后续请求生效。

每个账户最多同时拥有 100 条私人授权和 100 条生效分享。请求 UUID 绑定操作参数，重复请求不会延长到期时间。
浏览器不会自动重试不明写入结果。分享创建响应丢失时保留同一 UUID，先刷新列表核对，再由用户明确重试。

## 独立内容入口

在 Gateway 私有配置中成组设置：

```dotenv
ZEROAGENT_SITE_ORIGIN_TEMPLATE=https://{site}.usercontent.example.net
ZEROAGENT_SITE_LISTEN_ADDR=127.0.0.1:18081
ZEROAGENT_SITE_SIGNING_KEY=<独立随机生成并保密的至少32字符密钥>
```

主站 `PublicOrigin` 也必须是明确的 HTTPS 来源，例如 `https://chat.example.com`。
主站和内容站点不能都位于 `example.com` 下，防止内容来源影响主站域的 cookie 边界。
每个家族 ID 生成一个内容子域。私有签名密钥必须稳定保存并包含在加密配置备份中；替换密钥将使既有链接失效。

生产反向代理必须终止 wildcard HTTPS，并保留原始 Host，将内容请求转发给上述环回监听。
不能转到主站 API 路由，也不能把 S3 端点或访问凭据暴露给浏览器。
容器部署时，反向代理需要能访问 app 网络命名空间内的数字环回；不能假设发布一个 Docker 端口就能访问容器环回。
站点清单、版本及撤销状态已通过隔离备份恢复演练，记录见 [实施清单](SPACE_IMPLEMENTATION.md)。
完整生产 Compose/TLS 部署仍待验收。

本地浏览器验收可显式设置 `ZEROAGENT_SITE_ALLOW_LOCALHOST_HTTP=true`，并使用
`http://{site}.localhost:<port>` 和 loopback 主站。远程明文 HTTP 不会因此开放。
桌面托管的本地 Gateway 不启动此内容服务，设备功能和执行目标保持原契约。

## 呈现边界和资源限制

内容监听没有账户或模型 API，也不处理 Cookie/Authorization 认证。签名绑定站点、版本、模式、会话及有效期，
每个资源请求均检查数据库授权和正式原件。ZIP 缓存只保存已验证的不可变字节，最多 64 MiB/64 项；缓存不缓存授权。

压缩包最多 32 MiB、2000 个条目、展开合计 64 MiB、单资源 8 MiB。先检查中央目录再创建 ZIP 读者，
拒绝加密、多卷、ZIP64、路径穿越、符号链接、隐藏配置和不支持的文件类型，不解压到服务器目录。
每个条目的实际长度、CRC 和 SHA-256 均受校验，内容按固定 MIME 返回并设置 `nosniff`。
站点注册/资源展开及响应最多 16 个并发槽，S3 下载另受已有 4 槽限制；缓存命中不绕过展开/响应门禁，
防止多个慢客户端各自保留大资源导致内存无界增长。达到并发上限时返回 429 和重试提示，不无限排队。

iframe 和响应 CSP 使用独立站点来源，可运行本地客户端脚本，阻止访问主站会话、外部依赖、嵌套站点、表单提交和
Service Worker。音视频等可随包作为资源提供；这不授予服务器执行或任意公网请求。
页面使用 `no-store`、`no-referrer`、受限权限及主站 frame-ancestors。分享 URL 不需要主站登录 cookie。

## 验收入口

执行 scripts/cloud-space/verify-site-delivery.mjs，使用 --seaweed-config 参数指向隔离测试的
client.private.json，可创建并最终清理自己标记的 PostgreSQL 容器，执行账户/SDK/站点/服务器回归，
以及真实 Linux 构建和生产打包程序到指定 SeaweedFS 桶的交付。
只接受专用环回测试桶，不读或切换应用存储配置；工作区清除后仍能读取两个固定版本，
默认不分享，显式分享撤销后缓存请求返回 404。Windows 使用 WSL Ubuntu 的 Python；
模型与执行器 HTTP 仍是脚本协议端，不代表真实 E2B 或模型质量。

实际备份恢复还核对两份站点 ZIP、登记清单、分类、签名配置、生效分享及已撤销授权。
恢复后旧登录态/私人预览被阻断，显式分享保持固定版本且仍可撤销。该行为依赖备份中保护的签名配置，
并不通过恢复登录 cookie 来让预览继续有效。

`cloud_site_store_test.go` 使用 Memory 和显式隔离 PostgreSQL 核对版本、账户、CAS 和并发授权上限。
`cloud_site_http_test.go` 核对来源、原件完整性、过期、退出登录、固定版本、缓存撤销、Unicode 资源和范围下载。
`web/test/cloud-chat-sites.test.mjs` 核对响应地址/版本绑定、账户迟到结果、显式分享和未知写入。

显式浏览器夹具可设置 `ZEROAGENT_CLOUDCHAT_SITE_FIXTURE=1`，与已隔离的实际 SeaweedFS 配置一起运行。
夹具仅生成两份合成版本，使用正式元数据/对象接口，结束后清理自己写入的站点对象；不读取用户内容、不调用付费模型。
实际宽窄屏和分享撤销证据见[实施清单](SPACE_IMPLEMENTATION.md)。
