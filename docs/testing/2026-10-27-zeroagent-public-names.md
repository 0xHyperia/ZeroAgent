# ZeroAgent 对外命名与现有数据验证

日期：2026-10-27（Asia/Hong_Kong）。依据 ADR 0042；仅本地修改、测试和构建运行，不推送。

## 改动与保留边界

- 用户可见说明、诊断、路径提示及应用环境变量统一为 ZeroAgent；开发/构建/CI/部署示例同步更新。
- 当前账号后端目录从 `kbrain` 原子改名为 `engine`，构建缓存使用 `.zeroagent`。
  目录冲突、非目录、符号链接及 Windows reparse point 拒绝采用，不覆盖或合并数据。
- 存储身份继续使用原账号的稳定摘要；原生辅助设置、OAuth vault、浏览器持久键、模型启用状态
  和会话映射不重置。新建子代理工作树使用 ZeroAgent 目录/分支，原有工作树仍可管理。
- 内部包/Go module、协议、sidecar 文件名、后端私有启动变量、历史导入来源和五补丁来源保持。
  `patches/kbrain`、锁文件与 proto 未变。既有用户文本、历史事件内的绝对路径不批量改写。

公开变量和运行路径参见 [开发与运行](../operations/development.md#zeroagent-对外命名)。旧公共变量
需要在调用者启动脚本中更新；当前本机的启动脚本已更新。远端 GitHub secret/vars 的既有存储键
保留，只改 workflow 绑定的应用变量名，避免要求重建或泄露密钥。
