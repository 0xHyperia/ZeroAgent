## 本轮验证

- 核验正式发布、旧基线祖先关系和所有权规则。通过 Buf lint、相对合并前 ZeroAgent 的 `WIRE_JSON` 检查及 Go/TypeScript 生成。
- 冻结 pnpm 安装、共享 UI、虚拟列表、桌面及 WebUI 类型检查、UI 边界检查和变更前端源码 Biome 检查通过。桌面前端逐批通过 4660 项并跳过 2 项，WebUI 全量通过 1859 项。设备设置、引用、用量和大文件专项共 184 项通过。
- 生产桌面前端、设备 WebUI 和 Gateway 镜像以合并提交 `fbe2e5d940f7bc73f44b466829a47fcc6cc7bffb` 构建。验证期间更新了布局、云端可用性和设置回执的测试夹具及断言。用量统计文案经 ZeroAgent 品牌测试复验。
- Windows `cargo check --locked -p zeroagent --tests` 通过，原生用量和 SFTP 文本读写专项共 21 项通过。K-brain 和 Computer 从锁定源码与补丁构建，两者哈希与构建记录吻合。使用 Windows 实际引擎和独立数据目录验证健康能力、用量查询和无授权请求拒绝。
- Gateway Go 全量测试、`go vet` 和 Linux 容器内的 `go test -race ./...` 通过。设备控制回归覆盖分块上传期间租约过期、传输拒绝、文件版本冲突与分块阈值。Gateway 容器构建通过，分别停启 Redis 和 PostgreSQL 后正确恢复就绪状态。
- 真实账户下本机桌面、桌面远程与浏览器远程的同设备交互联验、签名安装与跨平台发布验收仍待验证。
