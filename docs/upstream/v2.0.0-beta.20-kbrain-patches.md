## 已撤掉的重复接口

- Go `POST /_zeroagent/mcp/runtime` 和 list/call/status/stop/restart/probe 全部删除；正常配置、
  状态、发现和会话执行继续使用上游路径。
- Native `mcp_runtime.rs`、私有转发专项与四个管理命令注册删除。上游也保留的旧 Native 实现尽量
  保持原样且不注册管理入口；旧 list/call 仍明确拒绝执行，应用不注册旧 manager。
- 私有诊断的 `purpose=probe`、允许停用服务器取得执行凭据的例外删除。Native 宿主只为已保存、
  已启用且与当前 profile/目标/修订相符的接收方返回凭据。
- 显式与推断 Message URL 实现、专属测试及两个对应的 Native 候选验收入口删除。共享编辑器不再展示
  额外输入；GUI 转换和 Native OAuth 对不支持的覆盖明确拒绝，错误不反射私有端点。
- Native facade 拒绝独立 `/v1/mcp/tools/call`，避免无会话审批上下文的原始调用成为旁路。
  编码别名及 OPTIONS 同样拒绝；会话 runs/permissions 与 MCP 发现保持放行。上游 Go 核心无需改动。

完整旧系列和 manifest 存于本地不可变快照：
`.codex-artifacts/mcp-slim-series-1792930329019/previous-series/`。没有清除原有用户数据。
