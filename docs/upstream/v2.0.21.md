# LiveAgent v2.0.21 同步报告

上游 [正式 Release v2.0.21](https://github.com/Stack-Cairn/LiveAgent/releases/tag/v2.0.21) 发布于 2026-11-14 16:02:45 UTC。发布提交为 `d874b4360761d1534f15dd920ab5e912b68dc9b0`，前次上游 v2.0.15 提交和本轮实际合并基线均为 `dab301d1e95f1d28858e9e2054deee35fddd9961`。

现有 main 工作树上的合并提交为 `361e9a660f86df4d1d81c513b3194eebb9e889ff`。第一父提交为合并前的 ZeroAgent `c5092f5d3ff64626d84de70e301ca4101ec06994`，第二父提交为已核验的上游发布。见 [153 个上游变更路径及 29 个冲突的处置](v2.0.21-inventory.json)。

| 上游变化 | 处置 | ZeroAgent 行为 |
|---|---|---|
| 外部 kn 会话与子代理（#1278、#1283） | adapt | 桌面在原会话侧栏显示外部运行状态，跟随后端快照并刷新子代理。外部运行状态由所属进程提供，不能从 ZeroAgent 子代理卡片停止其运行。 |
| 中断历史、后台通知、统计（#1288、#1291） | adapt | 按所属会话核对已接收历史，保留尚未受理输入和附件、已有版本标识及前端草稿。设备 WebUI 修复后台通知错误分组和历史接续。CloudChat 沿用独立运行和存储链路。 |
| 启动等待（#1276） | partial | 桌面设置读取等待 20 秒后可原位重试，晚到的旧读取不能覆盖新尝试。原生连接和账号验证仍使用原超时与恢复。上游重启服务和后台迁移流程未接入，保留显式导入旧版 ZeroAgent 对话。后续若有按 profile 严格绑定的重启入口，验证正在运行的任务、草稿和授权撤销后再评估。 |
| 内置浏览器与加载失败（#1293、#1295） | replace / adapt / reject | 继续使用 Windows WebView2 工作区浏览器。现有标签可显示地址、证书、连接或超时错误并原位重试。页面会话和设备转发仍绑定原授权。独立 Chromium/CDP 浏览器实现由现有浏览器替代，浏览器登录会话导入明确拒绝。 |
| 模型目录（#1281） | adopt | 刷新上游静态模型信息。实际可用模型继续由当前账户的托管目录决定。 |
| 第三方后备联网（#1296） | partial / defer | 采用历史搜索工具行。托管桌面引擎禁用第三方搜索服务，设置层不接收第三方密钥，原生联网和 CloudChat 调研仍走现有授权链。后续需验证当前账号的密钥隔离、并发设置、设备授权撤销以及结果来源，再评估接入。 |
| K-brain v0.107.33、CI | adapt / defer | 固定源码 `2fe44051fd30c91e9ae1abd6317f043239ec05f9`，保留原有运行时补丁和产物校验，适配新版本的会话租约、请求标识和宿主桥。保留 ZeroAgent CI，后续用实际缓存命中和构建耗时评估上游缓存改动。 |
