## 用户价值

本次上游更新重点改善长对话可靠性、上下文压缩、文件与工作区操作以及 WebUI 稳定性。
ZeroAgent 预期可以获得会话移动、Git Worktree、文件变更检查点与代码回退、上下文用量环、
可靠手动压缩、目录拖放导入、增强图片预览、SFTP 编辑、可恢复 Bash 进程、DeepSeek 修复和
大量对话持久化及跨平台修复。

这些能力只有在保留 USA-Zero OAuth、托管 Provider、Cloud Chat 能力边界、设备选择租约、
账户隔离、Android 和双仓库发布规则后，才能视为 ZeroAgent 的用户价值。

- 共享 `agent-ui` 的 Chat Header、Sidebar、Composer、Settings、Skills/MCP 和 Dialog；
- `gateway.proto` 生成物、Cargo/PNPM 依赖与锁文件；
- 上游继续修改但 ZeroAgent 已删除的 Login、Status Dashboard 和 Devices Admin 页面。

冲突必须按语义解决，不能整体选择 `ours` 或 `theirs`。生成的 Proto 和 Lockfile 必须在最终
组合实现确定后由仓库工具重新生成。

## 安全与数据

上游没有直接修改 `crates/agent-gateway/internal/account/**`、ZeroAgent Relay 客户端、
Cloud Chat 后端、Android 配置或生产部署目录，但共享 WebUI、Gateway Server、协议、上传和
历史代码均发生大改，仍需验证以下不变量：

- USA-Zero OAuth 是唯一账户入口，不恢复通用 Gateway Token 登录；
- 托管 Key 保持遮罩，显示或复制仍要求二次认证；
- Cloud Chat 不获得本地终端、文件系统、Git、SFTP 或 Agent 工具；
- 目录导入、多根目录、Worktree、回退和 Shell 进程均绑定到账户、设备、工作区和租约；
- 对话、上传、历史 revision 和 checkpoint hash 不得跨账户或在迁移中丢失；
- 不改变 Android、公开下载仓库、Release Notes 和生产部署边界。

本次没有数据库迁移。协议、历史、上传和工作区结构均通过 Gateway、WebUI、GUI 适配测试，账户、设备、租约和 Cloud Chat 能力边界保持不变。
