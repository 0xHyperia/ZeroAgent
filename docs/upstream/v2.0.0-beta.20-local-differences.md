## 品牌、平台与发布接线

- 用户可见的 ZeroAgent 名称、图标、服务地址、`top.usa0.zeroagent`、更新/签名及 OAuth 客户端身份保留。内部类型、文件名或注释的品牌改名应逐步恢复上游形式，避免无行为收益的冲突。
- Android 保留 WebUI 壳、OAuth、安全存储与更新；移动产物不携带桌面 sidecar，移动和 Gateway WebUI 构建目录隔离。
- Desktop 包含来源匹配的 K-brain、Computer、Gateway 三个 sidecar。Native 凭据能力只给已核验来源；构建/CI/便携包验证必须使用同一补丁 manifest 和摘要。
- 双仓库分发、面向用户的发布说明、私有镜像产物和不可变部署身份仍是 usa0 接线。当前本地镜像验证不等于授权发布或生产部署。
- `deploy/production/validate.sh` 的端口检查改用 POSIX grep，并区分无匹配与读取错误；这是发布验证工具修复，不改变生产 Compose 的运行行为。
- Linux Native 发布 runner 固定 Ubuntu 22.04 并复用既有 GLIBC guard；两个 Native CI job 使用既有 mise Protoc 34.0 声明，避免 apt 工具版本漂移。Gateway Docker 与 WebUI 使用同一标签解析结果传递实际产品版本，避免镜像内退回开发占位版本。
