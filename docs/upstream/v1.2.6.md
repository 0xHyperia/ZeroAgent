## 用户价值

本次更新的主要候选价值包括多会话并列工作台与终端 Pane、会话轨迹视图、桌面和 WebUI
语音输入、配置导入导出与 WebDAV 同步、统一沙箱策略、DeepSeek Responses 与原生搜索、
Claude 原生搜索轮次保留，以及移动端、Mermaid、Provider 选择和公网隧道修复。

这些能力不能直接按上游形态照搬。工作台、轨迹、语音输入和配置同步均跨越 Desktop、WebUI、
Gateway 与协议边界，必须分别确认 Cloud Chat 和设备 Agent 的能力范围、账户隔离、Secret
存储、远程设备路由、Android 行为及 USA-Zero 托管 Provider 契约。

## 安全与数据

上游没有直接修改 `crates/agent-gateway/internal/account/**`、ZeroAgent Relay 客户端、Android
配置、生产部署目录或 Release 工作流，但间接影响仍然很大：

- 新增 STT 服务端点和凭据，必须验证 Secret 遮罩、日志脱敏、请求大小与账户范围；
- 配置备份和 WebDAV 不得导出 OAuth Token、设备凭据或 USA-Zero 托管密钥；
- Workbench 与轨迹新增并行会话状态，必须防止账户、设备、工作区和执行租约串线；
- Gateway 会话、HTTP 路由与 Proto 均变化，必须保留 USA-Zero OAuth 唯一登录契约；
- 沙箱重构不得扩大 Cloud Chat 或远程设备的本地文件、Shell、终端权限；
- 新增历史和设置数据结构时需审查迁移、回滚与旧会话恢复，禁止静默丢失数据。

## 维护成本

优先采用上游 `agent-ui`、Workbench、Trajectory、STT 和沙箱的共享实现，把 ZeroAgent 差异
继续限制在 Adapter、能力协商、Relay、账户服务、移动端和发布边界。对于配置同步和 STT，
若上游实现无法证明 Secret 与账户安全，应在明确接口处适配或部分采用，不复制一套并行实现。
