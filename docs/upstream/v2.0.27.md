## 数据与边界

本轮无数据库迁移、生成协议或依赖锁变更。K-brain 源码和本地补丁清单沿用 v2.0.26。普通桌面与设备 WebUI 继续使用各自的宿主授权，Cloud Chat 继续独立执行并默认关闭。回退应以合并前提交为基准，同时回退对应桌面和网关产物。旧版读取或签名包回退未实测。

## 本轮验证

- 精确 Release、上游祖先、合并双父提交、完整路径清单、产品契约与 Git 差异检查。
- 冻结安装 `pnpm install --frozen-lockfile` 通过。共享 UI、虚拟列表、桌面和 WebUI 类型检查、变更源码 Biome 和 UI 边界检查通过。`pnpm test:gui` 通过 4674 项，跳过 2 项。`pnpm test:webui` 通过 1862 项。`pnpm test:virtual-core` 通过 34 项。
- `pnpm build:webui`、`pnpm build:gui` 及 Android 内嵌前端模式构建通过。Chromium 用对应 WebUI 构建，在 1440、820 和 390px 核对云端停用时的导航、侧栏尺寸和跨页临时预览。浏览器验证使用隔离账号夹具。
- Buf lint、相对合并前 ZeroAgent 的 `WIRE_JSON` 兼容检查、Go 与 TypeScript 重新生成通过，生成物无差异。
- Windows Gateway `go test ./...` 和 `go vet ./...` 通过。Linux 容器 `go test -race ./...` 通过，握手首帧及同步写入授权守卫另做竞态复跑。Gateway 镜像通过隔离健康检查，分别停启 Redis 和 PostgreSQL 后正确恢复就绪。生产 Compose 静态检查通过。
- Windows 原生 `cargo check --locked -p zeroagent --tests --target x86_64-pc-windows-msvc` 和更新模块 Rust 格式检查通过。原调试目录中的应用仍在运行，原生验证使用单独的目标目录。
- Windows 实际 K-brain 与 Computer 二进制匹配锁定源码构建凭据及 SHA-256。使用独立数据目录和本地合成模型，截断普通运行提交回执后，仅一次提交和一次按原请求查找，最终恢复回复。目标创建与恢复、暂停状态读回和停止分支由前端与服务端测试夹具覆盖。
