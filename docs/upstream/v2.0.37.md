## 从 v2.0.27 继续跟踪

- 设备工作台继续采用共享 `agent-ui` 与授权宿主适配器。账户、源设备、工作目录与设备租约在现有边界内处理。
- 云端工作区默认维持暂未开放，沿用现有公开目录与切换设备入口。云端执行和托管凭据策略保持独立。
- 旧会话继续使用显式 ZeroAgent 导入，保持导入目录与原配置隔离。上游 Pi 历史导入不接入当前产品。
- 桌面、Android 和 Gateway 发布仍由 ZeroAgent 的渠道、运行时打包、签名和分发规则控制。

## 差异核对

- v2.0.27 至 v2.0.37 的发布记录逐项映射到上面的功能处置。路径清单由 Git 核对变更状态与唯一性。当前源码中采用上游原样的路径与固定发布树一致。
- 工作区相对发布树的差异按所有权规则核对。ZeroAgent 专有差异主要涉及账户和设备协议、云端开放策略、文件阅读器与发布管线。上游未进入当前工作区的文件包含 PR 演示素材，以及需要适配授权与配置边界的测试和交互宿主。逐路径的状态及命中规则以[工作区差异清单](v2.0.37-fork-diff.json)为准。

## 验证与限项

下列结果记录最初的 v2.0.37 合并。后续能力接入与验收见[实施记录](../design/liveagent-v2.0.37-capability-adoption.md)。

- 产品契约 23 项功能、151 条所有权规则通过，清单覆盖整段上游变更。冻结依赖安装、前端类型检查、UI 边界检查、WebUI 全量 1,879 项测试通过。桌面全量回归按批运行，4,801 项通过，3 项按测试配置跳过。
- 桌面和 WebUI 生产构建通过。Chromium 与 WebKit 均完成生产 WebUI 启动及全体分块加载。首次并行运行构建和回归测试时桌面构建内存不足，单独重试通过。上游包体预算用于参考，待以 ZeroAgent 的账户启动流程建立基线。
- Gateway 通过 Go 全量测试、`go vet`、Linux 全量竞态和 Docker 冒烟。验证了 Redis、PostgreSQL 各自不可用时健康与就绪状态的区分，以及恢复后的就绪状态。Buf 通过协议格式、生成与 `WIRE_JSON` 兼容检查。
- Windows x64、Linux x64 和 Android arm64 的 Tauri `cargo check --locked --tests` 通过。Windows 使用已有的 v0.107.37 补丁组件。Linux 的缓存组件用于源码编译验证。Android 检查发现四项桌面图片预览测试缺少平台条件，限定为桌面后复验通过。
- 发布脚本、工作流语法、生产部署资产和 Windows 安装器契约检查通过。真实账户与三入口同设备验收、macOS 原生编译和全平台签名安装、离线运行环境与回滚验收仍待执行。

### 接续验证

- 当前依赖锁离线校验通过。产品契约、UI 边界、共享虚拟列表及 Buf 生成复现、格式、协议和 WIRE_JSON 兼容检查通过。
- 桌面前端分批覆盖 4,830 项，4,827 项通过，3 项按条件跳过。设备 WebUI 覆盖 1,884 项，均通过。较慢的工作簿滚动用例在并发执行中超时，单独复验通过。桌面定时任务复验确认工具审批立即拒绝，错误分类保留工具权限与模型鉴权的区别。
- 桌面与独立 WebUI 完成生产构建及双浏览器启动检查。Chromium 和 WebKit 分别加载桌面 845 个分块、独立 WebUI 775 个分块。抽样构建的首屏静态 JavaScript 压缩体积为桌面 100.0 KiB、WebUI 267.1 KiB，符合 ZeroAgent 的预算。Android 内嵌 Web 资产构建通过。
- Windows x64 与 Android arm64、x86_64 的 `cargo check --locked --tests` 通过。Android 使用已准备的 SDK、NDK 和独立编译缓存。
- Gateway 通过 Windows Go 全量测试、`go vet` 和 Linux 全量竞态测试。精确锁定的 Windows 引擎另通过 Gateway 的队列、中断和类型化错误用例，以及引擎的失败、停止和重启专项。Linux 夹具核对新增编辑器探测与执行位检查。
- 隔离的 Chromium 夹具验证窄窗的只读预览、图片标记和撤销作用域后的清理。没有当前版本下实际账户三条设备入口联验、macOS 真机运行或签名安装记录。Linux 原生登录前冒烟已加入 CI。
- 本机权限入口补验通过 24 项前端专项、双端类型检查及锁定 K-brain 的权限规则 HTTP 测试。入口回归覆盖本机导航、缺少宿主授权的深链接、项目切换和切号后的迟到请求。
