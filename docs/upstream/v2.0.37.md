## 从 v2.0.27 继续跟踪

- 设备工作台继续采用共享 `agent-ui` 与授权宿主适配器。账户、源设备、工作目录与设备租约在现有边界内处理。
- 云端工作区默认维持暂未开放，沿用现有公开目录与切换设备入口。云端执行和托管凭据策略保持独立。
- 旧会话继续使用显式 ZeroAgent 导入，保持导入目录与原配置隔离。上游 Pi 历史导入不接入当前产品。
- 桌面、Android 和 Gateway 发布仍由 ZeroAgent 的渠道、运行时打包、签名和分发规则控制。
