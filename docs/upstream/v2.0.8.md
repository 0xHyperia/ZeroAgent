## 本地验证

- 正式发布来源、两条祖先链、真实双父提交、逐路径清单、产品契约（18 项功能、136 条所有权规则）和 `git diff --check` 已核对。
- `pnpm install --frozen-lockfile`、GUI/WebUI/shared UI/virtual-core 类型检查、共享 UI 边界、196 个变化路径的 Biome 严格检查通过。桌面与 WebUI 生产构建、Android 嵌入 WebUI 构建均通过；仅剩已有动态导入、包体提示。
- 桌面前端分批测试：4,197 通过、0 失败、4 条有条件跳过；WebUI：1,543 通过、0 失败。一次构建并行运行时 Edge 队列几何夹具读到未布局的页面；构建结束后该夹具和同一完整分批均通过。图像默认未配置、双语文案、真实工作台请求与恢复夹具保留。
- Windows Native：`cargo check --locked --tests`、格式检查、库测试（1,374 通过、16 个默认 ignore）及健康协议集成（3 通过）。按准备产物提供明确测试环境后，10 个条件原生后端夹具通过，覆盖启停、认证、托管发现、缓存、生图、MCP 刷新和脱敏、代码审查；没有使用线上账号或真实供应商密钥。
- K-brain 与 Computer 用固定源码和八个补丁构建 Windows 产物，安装脚本验收来源收据。真实合成模型权限测试通过可运行用例；这台 Windows 机器没有可用的后端 OS 沙箱能力，两条实际沙箱运行用例因此跳过。Windows 上游 K-brain 全量测试另有 7 个平台夹具失败；在未修改的同一上游 commit 逐项复现，未计为通过。
- Gateway Windows `go test ./...`、`go vet ./...` 通过；WSL Linux `go test -race ./...` 通过，包括账号、会话、设备、上传与权限边界。竞态初轮发现账号回放测试在标题线程启动后交换测试存储；改为提前安装钩子，保留注销拒绝断言，完整重跑通过。
- Buf lint、与 ZeroAgent 基线的 wire/JSON 兼容检查、Go/TS 两次生成结果一致。Native Proto 由 Cargo 构建生成并通过检查。
- 正式 Dockerfile 生产构建通过。补齐冻结安装需要的表格补丁和许可证文件。隔离 Compose 探针对 Redis、PostgreSQL 分别验证 `readyz=503` 且 `healthz=200`、依赖恢复后 `readyz=200`；探针容器和专用数据卷已清理。
- 65 项脚本测试（63 通过，2 条原有平台条件跳过）；桌面与 Android 发布契约测试 22 项通过。没有生成、签署或发布安装包。

- WSL Linux 使用官方校验的 Go 1.27.0 测试适配后端源码。首轮其余包通过，工具包因源码和测试临时目录同处 /tmp 而不能区分授权根，TUI 诊断子进程超过测试期限；分开 TMPDIR 和源码并停止并行构建后，两包整包重跑通过。

验证范围不包括 macOS/Android 实机、真实 USA-Zero 账户和线上模型、签名安装及生产发布。涉及这些环境的行为仍需独立验收。

### 公开模型目录接入验证

桌面和 WebUI 默认使用 LiveAgent 公开目录。按 ADR 0075 保留 ZeroAgent 内置快照更新 PR，运行时直接使用上游发布产物。Gateway 提供公开同源代理及 ETag，K-brain 派生限额经现有规范配置事务持久化。已保留用户和供应商声明优先级。

目录、原生配置事务及 K-brain 适配回归 39 项通过，相关设置与会话边界回归 38 项通过，Cloud 模型控件测试 2 项通过。Gateway 全量 Go 测试、vet 和 WSL 目录相关竞态测试通过，桌面与 WebUI 构建及 UI 边界检查通过。实际请求 LiveAgent 与本地 Gateway / 5174 WebUI，三份目录 SHA-256 一致，同源接口返回 200，带 ETag 的条件请求返回 304。规范设置写入使用隔离夹具，真实托管账户的限额变更未做端到端验证。

### Windows 安装包复核

逐路径清单拒绝了上游递归删除 `%USERPROFILE%\.liveagent` 的卸载钩子和专用夹具。Windows 打包时发现公共 Tauri 配置仍保留该钩子的引用，导致 NSIS 读取不存在的文件。移除残留引用，继续沿用 ZeroAgent 原有的 Tauri 安装及升级行为。更新 Windows 说明，补充普通与发布配置的回归检查。
