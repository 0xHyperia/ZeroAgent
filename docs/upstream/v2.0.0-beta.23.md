## 失败与环境修正

- Native 首轮带本地开发 Gateway/平台地址，5 个官方默认值用例失败；第二轮 PowerShell 空
  环境值被编译成空来源也失败。第三轮使用显式官方默认来源、隔离测试数据目录，完整库通过；
  没有修改这些断言。新记忆测试的类型/构造调用问题已修复后再验证。
- Native available ignored 的先行探针缺少显式二进制或 source artifact 收据，原日志保留。
  最终补验绑定实际新构建 artifact 和 receipt，没有用缺环境失败或跳过充当通过。
- Windows checkout 的 CRLF 导致 Biome 格式诊断，工作副本按仓库 LF 规则规范化，不引入大批
  内容差异；ChatHeader 仅补齐一处断行。已有发布脚本测试仍要求按 release_tag checkout，
  修正为当前候选/正式流程共用的不可变 source_sha，保留构建来源与补丁校验断言。
- Windows CGO 缺少兼容 GCC，改用 owned Linux 容器运行竞态；初次容器复制 node_modules
  过慢而终止，登录 shell PATH 和 Go 自动工具链的配置错误保留。首份 K-brain Linux 快照省略
  `.git` 导致一个依赖当前仓库的 TUI 用例失败，最终使用含精确 Git 元数据和相同源码的快照重跑。
- K-brain 首轮竞态在 `TestRunningTaskViewReplaysThenStreams` 的 5 秒时限超时，无数据竞态报告；
  相同源码、补丁和资源条件下隔离完整 TUI 732/0/0、最终全包 3,944/0/26 通过。保留首轮
  3,943/1/26，不声称已修复间歇超时或为其改代码/增加 skip。
- 协议先行探针无法 clone 子模块 `.git` 文件，随后对本地导出的基线目录检查；上游旧协议不含
  既有 usa0 字段，不作为产品兼容基线。最终使用集成前产品提交，未改 wire 字段或放松规则。
- Git Bash 将容器内 `/dev/null` 转成 Windows 路径导致 curl 23；仅在验证进程设置
  `MSYS2_ARG_CONV_EXCL=/dev/null` 后原 smoke 脚本通过，没有改运行时或降低检查要求。

## 2026-10-27 生图后续验收修复（合并后的工作副本）

真实桌面验收发现 Native facade 未转发标准 `Idempotency-Key`，且托管模型代理未放行
图像生成/编辑接口。补齐预检、请求头及平台绑定下的两个精确 POST 路由，保持原有凭据、
来源、账户和路径限制。完整本地模拟出图验证通过后，用户截图已出现真实成功图片。

随后发现上游删除规则漏掉 `result_unknown`，与 UI/调度器终态定义不一致，导致无后台
执行的记录永久返回 409。分类为 `adapt`：新增最小补丁
`0005-image-unknown-history-deletion.patch`，复用上游终态函数；前四补丁字节保持不变。
真实后台 lease 继续阻止删除，既有软删除、账户边界和原请求幂等收据不变。UI 对终态记录
的短暂 409 提示收尾，不再要求取消已结束任务。无存储格式、自动清理或重复收费重试变化。
上游具有等价修复并通过同组回归后撤第五补丁，见 ADR 0041 和补丁 README。

私有日志位于 `.codex-artifacts/image-studio-fix-20261027` 及
`.codex-artifacts/image-delete-fix-20261027`。新增 Go 回归先复现记录/项目的错误 409，
修复后生图、直接/异步适配器和 backend 四包测试通过；Native 完整库 1,331 通过/0 失败/
12 原 ignored，另显式运行真实固定后端加本地供应商测试 1 通过，覆盖成功出图、未知结果

测试 36 通过，来源/打包、UI 边界、产品契约及格式检查通过。Native 首次新增测试因项目
