## v2.0.8 待办复核

- 目标栏、后台提醒与默认过程展开已有设备入口。编辑重发仍在原会话内执行。命令面板、快捷键、Git 行批注及持久审批规则继续按前次报告的宿主边界验收，未把共享源码的存在视为全部端都可用。
- 远程配置继续使用版本化快照和已提交回执。跨标签、设备切换和重新授权需进一步做设备验收。公开模型目录继续使用已采用的上游发布源和内置快照。
- 后续上游若提供带 profile 生命周期的宿主桥、支持已确认的配置事务，或等价覆盖 ZeroAgent 后端补丁，再评估删除对应适配。

- 使用 Release 校验器确认正式 Release、精确引用与提交。执行产品契约、Git 空白检查、冻结依赖安装和 Windows Native `cargo check --locked --tests`。Windows SDK 使用本机含 UCRT 头的 10.0.22621。

- K-brain Windows 后端和 Computer 均从锁定源码和补丁清单构建，记录产物摘要。MCP、技能、图像、协议和 CLI 包测试通过。发现普通 Chat 可见计划工具，收紧后原失败用例通过。
- 桌面、WebUI、共享 UI 和 virtual-core 类型检查通过，桌面和 WebUI 生产构建通过。桌面 75 项、WebUI 7 项合并相关专项通过。全量前端有未清项。桌面全量初次检查仍有输入布局的源码断言以及需要构建样式的 Edge 几何夹具。WebUI 全量初次检查有表格滚动夹具和云端任务的两项断言。UI 边界扫描报告两个本次未改动的弹窗组件，分别为会话图像预览和共享警告弹窗。
- 未执行签名、正式安装、生产部署、真实托管账号／模型和外部 SSH 验收。Windows 沙箱提权、真实设备租约和断线、macOS 原生及 Android 实机另行验收。
