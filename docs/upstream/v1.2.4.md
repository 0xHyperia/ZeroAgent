## 安全、数据与维护

本次没有数据结构迁移。旧 `selectedSystemTools` 只在读取归一化时被忽略并不会再次持久化；
不会恢复 `HttpGetTest`。OAuth、托管密钥二次认证、设备会话、租约、历史和上传文件的账户隔离
保持不变。共享功能优先采用上游实现，ZeroAgent 差异集中在 Adapter、Relay、Gateway 账户和
发布工作流，后续同步通过 `.github/upstream-ownership.yaml` 和本报告逐项审查。

## 未完成的环境检查

宿主 openEuler 仅提供 WebKitGTK 2.38.2，低于 Tauri 要求的 2.40，因此宿主机上的
`verify-adaptation.sh --full` 会在系统依赖探测阶段失败；这不是源码编译失败，Rust 矩阵已由
上述隔离环境补齐。创建 PR 后仍需由 CI 验证 Windows Tauri、Android、OAuth、托管 Key
二次认证、设备注册/选择/重连/撤销等平台链路；创建 PR 和触发 Actions 前必须单独获得批准。
