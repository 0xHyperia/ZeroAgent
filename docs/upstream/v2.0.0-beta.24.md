## 用户价值与决策

采用上游的会话摘要增量同步、固定截面的分页恢复和资源回收，减少健康连接下的重复
全量读取；桌面、完整远程 WebUI 和 Gateway 使用共同的水位与恢复协议。生产入口
仍是 USA-Zero 账号与设备选择，不提供上游的 token-only 管理入口。

## 安全、数据与维护成本

详见 ADR0047。保留当前 v2 数据路径、存储身份、托管模型与缓存继承、Native 凭据保管、
账号和设备授权、配置 CAS、完整远程 UI，以及本地后台宿主和慢模型请求异步处理修复。
没有自动导入旧产品数据、公开原始 token、放开外部供应商或引入第二套执行器。

新的摘要通道原本是同一 Store 的完整数据，合并后先过滤账号设备和工作空间再分页。
范围外变更使用现有恢复协议，不添加私有 wire 扩展。Native 仅接受可信 main window
并验证当前数据根。现有发送前授权检查继续拒绝退出、过期和撤销之后的输出。

撤销 0005 的实现与重复测试，采用上游更完整的未知结果删除及资源回收测试；保留八项
补丁的原字节和编号。额外长期差异集中在 Native 来源绑定和 Gateway 选择投影，未 fork
侧栏协调器。旧映射迁移断言改为产品要求的隔离断言，保留批量落盘、删除与数据根分离验证。
