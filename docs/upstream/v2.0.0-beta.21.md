## 用户本轮要求

1. 上一轮按 ADR 0034 新安装范围撤下了旧会话迁移入口。本轮按用户要求恢复桌面显式旧 ZeroAgent 会话导入，复用上游转换、幂等、失败清单和删除意图；不启动其他旧配置迁移。
2. 账号入口集中到侧栏底部的头像和昵称菜单。菜单提供账号、设置和退出；资料、邮箱、余额、用量、设备和安全继续使用原账号页，Android 更新入口保留。原退出等待与失败重试逻辑保持。
3. 真实合并精确 beta.21。MCP、Skills、提示词、Loop、记忆和文件能力采用上游；Native 仍通过已认证 profile、规范配置快照、版本/CAS 与设备落盘 ACK 进入后台。
4. usa0 固定连接与可配置模型分开。复用上游模型编辑器，开放模型 ID、别名、启停排序、上下文、输出上限、模态和已有协议/缓存提示字段；不开放外部端点、凭据或任意请求头。实际模型权限由平台校验。
5. 以模型名称识别厂商，复用现有图标系统；无法识别时保留原供应商图标回退。

范围与安全决策见 [ADR 0035](../product/decisions/0035-platform-model-settings-and-history-import.md)。本轮不清除任何旧用户数据。

## 实现选择与冲突处理

- 共享设置页采用上游去除无效图像服务 tab，但继续调用两端受保护的 Provider renderer。
- Skills 采用上游统一传输恢复，保留当前读取版本/条件写入与错误状态。
- Web project prompt 投影与 Native 规范快照合并，不能恢复多来源并行写入或过期保存。
- 三处 STT modify/delete 和一个新增孤立测试保持删除：该 Gateway 旧运行器已无底座与消费者，不为接受上游改动重建第二套语音实现。
- 不启用新加入的旧 MCP 自动配置导入。当前 MCP 显示由规范后端读取负责，原私有字段与凭据保护保留。上游辅助文件保持来源形态，不作为生产入口。
- 标准 SSE 传输保留，不把 SSE 配置静默转换成另一种 HTTP 协议；不恢复 messageUrl 覆盖、URL 推断或私有 runtime 管理端点。
- K-brain 锁采用上游 `af5ebe7f28dbdbb7a753e25e968a3c19f2b6e497`（v0.107.6-beta.19）。既有四个最小补丁在官方完整 checkout 顺序 check/apply 通过，补丁字节未变；manifest 仅更新基准。Windows/Linux 新源码产物均已构建，Windows prepare 验证通过。
- 账号设备的Skills桥改走当前profile的公开配置入口，保留读取ETag与条件保存；不回到旧Native SkillsManager。目录发现同时绑定当前托管Provider，首方请求使用真实托管ID，不能把调用者提供的地址或凭据用于外部探测。
- 验证中发现Windows卷根的安全路径谓词使用组件数误判；改为明确要求正常路径组件，保留原根目录/HOME拒绝断言并加入C盘/D盘根回归。这一Windows分支仅在测试编译中使用，未新增生产沙箱实现。
