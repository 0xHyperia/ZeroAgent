# Explore design directions

Keep the user goal, core content, and constraints consistent across directions. Vary information hierarchy, interaction, or tone where it changes the experience. Explain how each direction handles the same key task and state its tradeoff. Use the configured image tool for useful visual concepts. For an interactive direction, use the existing project or the ZeroAgent prototype workflow. Keep each result separately identifiable so the user can choose, compare, or refine it.
