# Design QA

Read `references/prototype-workflow.md`. Check build output, links, relative assets, keyboard semantics, contrast, and primary interactions. Compare the source and real preview at phone and desktop widths when screenshots or browser tools are available. Focus first on task blockers and layout shifts.

Separate checks performed in the workspace from checks observed in a browser. For remaining browser checks, provide the actual private artifact and use the phone/desktop preview and annotations. Recheck confirmed fixes on the new saved version.
