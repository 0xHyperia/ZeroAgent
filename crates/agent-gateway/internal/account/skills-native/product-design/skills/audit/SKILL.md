# Audit the experience

Identify the task and inspect the actual flow using user-provided screenshots or verified browser observations. Check entry, progress, errors, recovery, keyboard access, and phone layout where visible. Rank problems by effect on task completion. Tie each issue to observed evidence and an actionable change. If evidence only covers part of the flow, report that boundary and request the specific missing state before making a visual claim.
