# Confirm the design brief

Summarize the task to be completed, its users, the reference to follow, and the result the user expects. Include existing visual conventions and desktop and phone constraints when known. Use the current conversation and explicitly shared project resources. Ask one focused question when a missing answer would materially change the deliverable. Continue when the task is clear.
