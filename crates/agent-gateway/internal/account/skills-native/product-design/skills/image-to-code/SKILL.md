# Visual reference to prototype

Read `references/prototype-workflow.md`. Inventory the source's layout, type, colors, components, density, and key interactions. Identify which behavior the reference proves and infer only what the user's task requires. Use accessible semantic controls and show real focus, selected, empty, and error states when relevant.

Deliver the actual runnable files. If the site tool is available, save the build privately and use its artifact citation. Ask the user to inspect and annotate the real preview when automated visual verification is unavailable. Label any unresolved fidelity differences.
