# Visual reference to prototype

Read `references/prototype-workflow.md`. Inventory the source's layout, type, colors, components, density, and key interactions. Identify which behavior the reference proves and infer only what the user's task requires. Use accessible controls and cover relevant focus, selected, empty, and error states.

Create runnable files and use the private site tool for a reviewable preview when available. Then read `design-qa` and compare the rendered implementation with the source. If a rendering cannot be inspected, give the user the preview for review, identify the missing screenshot or interaction check, and record a blocked handoff.
