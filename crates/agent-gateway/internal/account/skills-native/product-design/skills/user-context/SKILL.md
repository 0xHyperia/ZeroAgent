# Use product context

Start from current project instructions, explicitly associated files, and the user's stated conventions. Identify which version or screenshot is authoritative. Distinguish project constraints from temporary task decisions. When the user wants a reusable design reference, make it an explicit project resource through the host's available actions or provide the text for the user to save. Keep references scoped to their account and project.
