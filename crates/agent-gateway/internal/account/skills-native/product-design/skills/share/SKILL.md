# Deliver a prototype

Use the built output directory with local assets and a relative base. Read `references/prototype-workflow.md`. When `publish_site` is available, save a private version and cite the returned artifact. Continue the existing site using its owned family ID when the user requests a revision.

Give the user the private preview and relevant checks. Public sharing is available through the site's share controls after the user reviews the preview. If site delivery is unavailable, provide a verified downloadable build when an artifact tool is available.
