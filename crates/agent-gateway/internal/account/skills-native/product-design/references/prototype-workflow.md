# ZeroAgent prototype workflow

1. Define the primary task, source evidence, desktop and phone layout, and key states. Keep uploaded screenshots and published versions distinct.
2. Start with project components where possible. For a standalone design, read `references/prototype.html` and write the adapted content into a fresh output directory as `index.html`. Bundle CSS, scripts, fonts, and images locally. A generated image can be loaded into the isolated workspace by its saved artifact version.
3. Use workspace commands to check the entry point, relative asset targets, build output, and application tests that actually run. Compare the primary task and keyboard path against the brief.
4. Save only the build directory with `publish_site`. Cite the saved version. The preview provides Fit, Phone, and Desktop widths and annotation tools. Keep public sharing in the user-controlled site UI.
5. Report what was verified. If this session cannot drive a browser, keep visual verification open for review and request screenshots or annotations for the next iteration.
