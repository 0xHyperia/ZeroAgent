# Design and prototype checks

Trace the user through entry, the primary action, an empty or failed state, and recovery. Review how the layout responds at phone and desktop widths. Check control labels, keyboard reachability, focus, contrast, reading order, and the tap targets important to the task.

Compare the actual result against the brief and any rendered reference. Record the viewport, interaction, and evidence for each material issue. Keep actual browser observations separate from checks performed on source code.
