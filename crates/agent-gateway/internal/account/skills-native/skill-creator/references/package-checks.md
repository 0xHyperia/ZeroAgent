# Skill review checklist

- The name is stable and the description identifies when to use the skill.
- The instructions explain important decisions, inputs, expected results, and recovery.
- The workflow has a normal example, a missing-input example, and a request that should not activate it.
- References and scripts have a clear purpose and avoid private credentials. Draft preparation checks structure. Run a script separately in the isolated workspace when execution is available and relevant.
- The user reviews the files and explicitly saves the draft into personal skills.
