# Prepare a plugin for delivery

Read the exact owned plugin. Check discoverability, scope, reference paths, sensitive data, permission needs, and the expected output. Record normal, missing-input, and unsupported cases, along with what was actually tested. List any required tools or connections separately.

Prepare a short listing description, two example prompts, and a reproducible verification checklist. If the user wants the checklist inside the package, use the update workflow to add it as a reference. A saved personal plugin can be exported from its directory as a ZIP. The destination's submission and review process is a separate step.
