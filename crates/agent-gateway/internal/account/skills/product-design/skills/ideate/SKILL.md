# 探索设计方向
先确认设计目标、现有品牌、受众和参考，缺失时读get-context。已有明确选定视觉则转image-to-code，不重复制造选择。
开放方向先提出少量真正有差异的布局与视觉策略；需要图像方案时读取独立imagegen技能，分别生成，不用文字或假界面代替实际设计图。
每个方向保持真实信息、主要动作、关键状态及手机优先级；沿用必要的品牌与功能约束。
展示实际结果，简短说明主要差异。需要用户选方向时等待选择，同时可继续不依赖选择的工作；不要未经选择实现另一方向。
