# 验证设计
准备同一视口、主题、内容和状态的参考与实现截图，先看完整页面，再看关键局部。
核对字体/字重/行高、对齐/间距、颜色/层级、真实资产、文案与响应式；检查菜单、选择、保存、返回、键盘和关键错误状态。
把明显错位、裁切、无作用操作和数据丢失修复后再捕获；旧截图与构建日志不能替代本次结果。
逐步列出健康度、已修复问题、剩余问题及证据。浏览器、触控、读屏或真实模型未执行的部分单独说明，不扩大通过范围。
代码检查和体验检查都完成后交付；工具不足时明确具体边界，不伪造通过。
