# 从选定设计实现
确认实际选中的图片及状态，检查完整图和关键局部；不要根据缩略图或另一方案猜测。
先看工程的AGENTS、设计规范、字体、颜色、布局和组件。按区块测量层级、宽度、间距、字号、圆角及资产槽位。
优先使用源资产和现有组件；需要新的位图时使用可用生图能力，现有矢量图标系统沿用原工具，不随意换一套品牌。
接通导航、菜单、选择、表单、主要动作、加载/空/错误/忙碌与返回，保持已有状态。手机按任务重新排列，不只缩小桌面。
执行类型与必要回归，再读design-qa对照实际渲染。没有渲染工具就标明限制，不能把构建通过当成视觉一致。
交付真实工程文件或用户要求的私人静态站点，保留原稿。
