# 从网站参考实现
先确认用户要忠实复刻还是重新设计。读取目标页面的真实内容；有浏览器时记录关键页面、交互状态和截图，没有浏览器时说明视觉证据不足并使用用户提供图。
只读取可用工具允许的地址；不能将本机私有地址送给公开网页抓取器。登录页和无权限内容不伪装成已读。
记录信息架构、内容、布局、资产、字体、间距和主要路径；实现时沿用image-to-code与既有工程规范。
不复制其它用户数据、凭据、服务端身份或受保护连接。不凭静态HTML承诺拥有原网站后端能力。
用design-qa核对参考及实现，交付可运行文件并清楚列出实际接通的交互。
