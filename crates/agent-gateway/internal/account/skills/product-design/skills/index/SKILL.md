# 产品设计

先判断用户这次要完成的设计任务，只加载相关工作流。面向当前产品、用户目标与已有参考，默认中文。

## 选择工作流
需要审查现有产品时先读audit；研究用户问题读research；产品目标或设计产出缺失时读get-context，已有目标就概括后继续，不逐步索取确认。
探索视觉方向读ideate；实现截图读image-to-code；复刻可访问网站读url-to-code；交付前读design-qa；用户要求保存或分享读share。
需要使用用户已有的产品资料或长期设计约定时读user-context。用read_skill并明确package_id=product-design读取同包技能。
创建或修改独立技能属于skill-creator包；创建、更新插件属于plugin-creator包，不能把它们列为本插件的设计工作流。

## 能力与交付
先检查本轮可用工具、上传资料及现有工程。设计图和真实位图通过已安装的imagegen技能与generate_image完成；源码与参考文件通过隔离工作区工具读取。
没有实际浏览器/设计服务时，说明渲染或外部操作的验证边界；用户提供的截图仍可作为视觉依据。只有实际工具存在时使用联网、Figma或其它外部连接。
复用现有设计系统与工作流程；工作流或技能文件不授予额外权限，不把工具调用成功当作体验完成。
按需读取references/quality.md。保留当前草稿、文件、项目和已有成果。
