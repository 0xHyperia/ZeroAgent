# 生成图像
先区分新生成与修改已有作品；多份不同资产分别生成，不把“批量”理解为可以绕过当前工具限制。
位图照片、插画、商品图或设计图使用当前真实generate_image。编辑已有矢量或代码原生图标时优先对应工具，沿用现有图标系统。
模型来自用户独立的图像设置；缺配置时保留需求并引导设置，不索要API Key、任意URL或悄悄换收费模型。
整理用途、主体、构图、比例、风格、准确文字和必须保留的内容。描述明确时忠实整理，不擅自增加人物、品牌、调色或装饰。
修改前先用当前可用视觉能力查看原图，区分编辑目标、风格参考与辅助素材；传入当前账户拥有的file_id或artifact_version_id。原图不可见时不假装检查过。
参考修改保存新成果，保留原件。只有明确继续同一作品时沿用family_id。每次调用一张图，已完成方向不因后续失败重做。
检查实际结果的主体、构图、文字、约束和透明通道；只对明确问题做一次针对性修改再看结果。读references/prompting.md完善提示。
只把ready成果说成完成；结果未知不自动重试收费调用。页面显示真实图片，不重复粘贴base64或伪造链接。
本环境不使用Codex的image_gen工具名、CLI密钥流程或本机存储路径；只用本轮公告且已授权的能力。
