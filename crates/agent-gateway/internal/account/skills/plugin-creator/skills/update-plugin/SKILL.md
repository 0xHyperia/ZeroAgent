# 完善插件
先读取用户提供或当前账户有权编辑的插件内容，确认现有用途、技能、资料及想改变的结果。
只修改用户拥有或获授权的内容；公开插件只能阅读，不能伪造编辑权限。保留原始包和有用方法，不顺手重构无关能力。
按manifest的实际技能目录发现入口；references和普通Markdown是辅助资料。按需读references/package-format.md，检查新增或修改技能的触发、相对路径、交付和失败处理。
用新包交付修改，说明主要差异和可直接尝试的任务；安装更新走现有账户版本校验，不假装对话中写了文件就完成安装。
变更后重新打包并检查真实ZIP，不交付与当前源码不一致的旧压缩包。
