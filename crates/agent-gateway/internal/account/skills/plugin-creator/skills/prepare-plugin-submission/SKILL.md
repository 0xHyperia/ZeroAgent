# 准备插件提交
先确认用户准备向哪里提交，以及当前包和权限。检查名称、用途、作者、实际技能、所需工具及支持资源。
整理简短说明、适用与不适用场景、真实示例、已执行验证、审查步骤及限制。引用真实来源，不伪造评测、连接或发布状态。
检查manifest路径、引用文件和归档内容；修改后重新生成并检查包。涉及外部服务时按目标平台的当前规范准备隐私、访问与审查资料。
本环境可以交付检查清单、说明和真实ZIP；没有目标平台提交工具时说明剩余人工步骤，只有用户明确请求且工具支持时才能执行提交。
不把准备完成说成已经公开发布。
