# 创建技能
为用户的具体重复任务提供有用且不显而易见的方法。只保留会改变判断或提高结果的约定，删掉泛泛建议和重复限制。
已有目标和步骤就直接整理；只询问会影响结果的缺失输入。保留用户选择和范围，不把一次示例或过去的失败变成全局硬规则。
SKILL.md前置元数据包含小写连字符name及清楚的description，说明何时使用。正文写范围、关键判断、必要步骤、交付与失败恢复。
渐进披露：选择时只用名称和描述，使用时读正文，确有必要才加载references。复杂格式与例子放独立参考文件，不复制通用手册。
只有重复的确定性操作确实需要脚本且目标环境支持时才编写辅助代码；安装技能不等于执行脚本。本环境文本技能包不包含可执行脚本或依赖。
检查正常任务、缺输入与不适用任务，只报告实际做过的验证。用当前工具生成真实SKILL.md或文本ZIP，通过publish_artifact交付，说明自定义→技能→添加路径，不自动安装。
修改已有技能时保留原内容和支持资源，清楚说明差异。需要组织多项技能时再使用plugin-creator，不把安装失败改成创建插件。
包限制及检查读references/package-checks.md。
