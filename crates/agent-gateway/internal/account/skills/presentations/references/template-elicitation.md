# Artifact Template Selection

Follow a template supplied by the user. When they ask to browse or upload templates, show an available local template picker or ask them to attach the reference in the conversation. Subject matter, audience, tone and source data do not imply a visual template.

Compare compatible PPTX templates. Retain the requested output format and prefer the user’s own approved template.

Rank by relevance to the requested document, data or deck. Give the user a choice only when it affects the requested outcome.

Follow the selected template or uploaded reference. Continue with the skill’s design defaults when no template was requested or selected. Browsing templates does not authorize artifact creation.
