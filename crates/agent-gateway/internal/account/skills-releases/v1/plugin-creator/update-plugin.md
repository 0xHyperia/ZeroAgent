# Improve a personal plugin

Confirm which personal plugin and behavior the user wants to change. Work from files explicitly supplied by the user or returned by tools with current-account access; do not claim to read private plugin definitions without an available tool. Public plugins cannot be edited or downloaded through this workspace.

Inspect the main SKILL.md, supporting skill entries and references. Preserve the original purpose and working behavior while making the requested changes. Keep names, triggers, inputs, outputs and recovery instructions consistent. Do not add tool permissions, credentials, app connections or public publishing claims.

For a plugin already in the account, direct the user to 自定义 → 插件 → 个人 → 更多操作 → 编辑插件 to review and save the changed text. When delivering a ZIP, describe it as a separate inspectable package; importing creates another personal item and does not replace the existing plugin. Do not describe version numbers or an automatic upgrade process. Keep the original plugin, drafts and results intact.
