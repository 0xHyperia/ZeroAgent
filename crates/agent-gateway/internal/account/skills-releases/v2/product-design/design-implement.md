# 实现设计

先检查用户拥有的源码、设计规范和已选参考，确认任务路径、路由、状态归属及宿主能力。识别可复用的字体、颜色、图标、组件、阅读器、菜单、对话框和工具提示；保留账户边界、草稿、历史及运行任务。

用共享组件实现语义清楚的响应式界面，在可比视口下匹配参考的层级、比例、间距、字体和动作位置。主流程使用真实内容与动作，包含默认、悬停、按下、选中、焦点、禁用、忙碌、加载、空、失败和恢复；适配键盘、输入法、长名称和减少动态。手机按任务优先级重排，不挤压桌面列。

只使用已公告的隔离工作区工具，不在Gateway主机或用户设备执行脚本，不由技能推导新网络或工具权限。需要资产且已配置时使用imagegen。交付前读取design-verify，检查构建并实看可用的渲染结果，修正后复验；无浏览器则明确限制。真实文件用publish_artifact，用户要求保存的网站用publish_site，不能仅写代码就宣称已部署。
