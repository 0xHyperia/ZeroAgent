# 完善插件

先确认用户要改哪一个个人插件、什么任务触发问题、期望怎样变化。只检查用户提供或当前账户工具实际返回的文件；没有读取能力时请求必要文件，不声称已读取账户私有插件。公开插件不可编辑或下载。

检查主SKILL.md、辅助技能及相对引用，列出与目标直接相关的改动。保留仍有效的规则，补齐触发、输入、步骤、交付及失败恢复，避免同名技能冲突和失效文件路径。用正常任务、边界任务及不适用任务核对修改；不擅自扩大工具或数据权限。

已有账户插件的文本修改在“自定义 → 插件 → 个人 → 更多操作 → 编辑”中审阅保存。交付ZIP时明确它是可检查的新包，重新导入会创建另一项个人内容，不自动替换原插件。不展示人工版本管理流程，不声称自动升级；保留原件、现有草稿和成果。结束时说明改动、检查结果及一个试用例子。
